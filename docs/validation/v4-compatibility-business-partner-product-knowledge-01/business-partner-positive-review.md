# 긍정 자료 검토

긍정은 수익·동업 지속 예측이 아니라 확인 가능한 사업 질문의 가능성이다.

- bppr:material:CH04.P1:shared-proof-before-investment: 투자 전에 가정을 좁힐 가능성. 조건: 조사 응답을 실제 매출로 환산 금지. 실질 정보: 공통 성향의 시장 검증 접점.
- bppr:material:CH04.P1:shared-scope-repeatability: 반복 가능한 제공 조건을 만들 여지. 조건: 법적 효력·허가·이행 능력 미확인 시 보류. 실질 정보: 시장 증거와 다른 제공 약속의 접점.
- bppr:material:CH04.P2:exploration-delivery-interface: 제안과 실제 제공 사이의 빈칸을 찾을 여지. 조건: 각자의 실제 역량·역할은 별도 확인. 실질 정보: 서로 다른 정보의 제안 인터페이스.
- bppr:material:CH04.P2:trial-and-contract-boundary: 과도한 고객 약속을 줄일 여지. 조건: 법적 의무·안전 검증은 임의 면제 불가. 실질 정보: 보완을 전문 자격 대신 경계 정보로 한정.
- bppr:material:CH04.P3:customer-signal-product-adjustment: 같은 지원 부담을 줄일 가설 발견. 조건: 각자의 고객·개발 역할 고정 금지. 실질 정보: 공동 장면에서 서로 다른 작업의 연결.
- bppr:material:CH04.P3:crisis-information-two-views: 추측 대신 복구 선택지를 좁힐 여지. 조건: 안전·법률 의무는 성향 조율보다 우선. 실질 정보: 좋은 협업의 위기 정보 구조.
- bppr:material:CH04.P4:repeatable-operation-value: 보이지 않는 유지 기여를 드러낼 여지. 조건: 반복 수입·실제 안정성 보장 금지. 실질 정보: 좋은 가치의 반복 운영 조건.
- bppr:material:CH04.P4:contribution-recognition-without-shares: 가려진 기여를 확인할 여지. 조건: 기여의 법적 평가·비율·가격 결정 금지. 실질 정보: 공동 가치와 경제 합의의 분리.
- bppr:material:CH05.P1:a-alternative-b-standard: 새 문제와 기준을 함께 찾을 여지. 조건: 실제 방향 십성·각자 유형·사업 맥락 없으면 보류. 실질 정보: A 제안을 B가 받는 조건.
- bppr:material:CH05.P1:a-resource-b-obligation: 자원 종류와 책임을 드러낼 여지. 조건: 실제 자산·상환 능력·권한 추정 금지. 실질 정보: A의 제안이 B에게 만드는 경제 조건.
- bppr:material:CH05.P2:a-prototype-b-service-cost: 판매 전 제공 가능 범위를 좁힐 여지. 조건: 실제 기술·고객 서비스 역할 고정 금지. 실질 정보: A의 산출이 B에게 주는 확인 자료.
- bppr:material:CH05.P2:a-meaning-b-allocation: 경제 합의 밖의 누락 기여를 확인할 여지. 조건: 실제 배분 비율·세금·법률 판단 금지. 실질 정보: A의 인정이 B의 확인에 주는 정보.
- bppr:material:CH05.P3:a-client-promise-b-cost: 고객 가치와 수행 범위를 함께 확인할 여지. 조건: 실제 고객·피해·반복 이력 생성 금지. 실질 정보: A의 외부 약속과 B의 실행 부담.
- bppr:material:CH05.P3:a-expand-b-cash-timing: 확장의 실행 조건을 드러낼 여지. 조건: 실제 잔고·부채·투자 적합성 추정 금지. 실질 정보: A의 자원 방향과 B의 유동성 질문.
- bppr:material:CH05.P4:a-change-small-safe-trial: 새 방식의 확인 범위를 좁힐 여지. 조건: 법정·안전 검증을 작은 시험으로 우회 금지. 실질 정보: A의 변화 제안이 B와 확인할 절차.
- bppr:material:CH05.P4:a-risk-disclosure-before-consent: 서로 다른 위험 이해를 드러낼 여지. 조건: 강요·착취·불법 의심 시 협의 지속 강요 금지. 실질 정보: A가 B의 수락을 확인하는 방향.
- bppr:material:CH06.P1:b-operation-a-support-question: 제안을 실행 가능한 단위로 확인할 여지. 조건: 실제 방향·업무 맥락 없으면 보류. 실질 정보: B가 A에게 주는 실행 정보.
- bppr:material:CH06.P1:b-boundary-a-resource-choice: 수행 가능한 범위를 좁힐 여지. 조건: 실제 전문 능력·근무량 추정 금지. 실질 정보: A의 자원 제안과 다른 B의 용량 신호.
- bppr:material:CH06.P2:b-customer-issue-a-hypothesis: 작은 변화의 시험 질문을 만들 여지. 조건: 실제 고객 이력·매출 영향 생성 금지. 실질 정보: B의 관찰이 A에게 주는 가설 자료.
- bppr:material:CH06.P2:b-cost-log-a-commitment: 감당할 약속의 조건을 좁힐 여지. 조건: B의 자격·계좌·실제 관리 권한 추정 금지. 실질 정보: B가 A의 약속에 주는 현금 정보.
- bppr:material:CH06.P3:b-contract-risk-a-delay: 확인과 결정의 순서를 나눌 여지. 조건: 법적·안전 확인을 마감으로 생략 금지. 실질 정보: B의 검토가 A에게 주는 결정 시간 부담.
- bppr:material:CH06.P3:b-maintenance-a-direction: 아이디어를 감당할 형태로 바꿀 여지. 조건: 실제 피해·반복 갈등 이력 생성 금지. 실질 정보: B의 운영 신호를 A의 방향 질문으로 연결.
- bppr:material:CH06.P4:b-small-trial-before-expansion: 확장 전 모르는 범위를 좁힐 여지. 조건: 안전·인허가·법률 검토 대체 금지. 실질 정보: B가 A에게 제안하는 확인 순서.
- bppr:material:CH06.P4:b-hold-with-decision-question: 침묵과 동의를 구분할 여지. 조건: 강요·불법 의심이면 전문 지원·중단 우선. 실질 정보: A의 동의 확인과 다른 B의 보류 정보.
- bppr:material:CH09.P1:recall-market-and-scope: 도입된 접점을 반복 가능한 질문으로 남길 여지. 조건: 표시 이력·호환 source group 없으면 보류. 실질 정보: 핵심 접점의 실제 표시 기반 지속.
- bppr:material:CH09.P1:recall-customer-and-risk: 다른 기여를 연결할 질문을 남길 여지. 조건: 실제 표시·owner·과제 일치 없으면 보류. 실질 정보: 공동 장면의 표시 기반 가치.
- bppr:material:CH09.P2:recall-directional-contribution: 한쪽 기여를 상대가 활용할 조건을 남길 여지. 조건: 실제 양방향 근거·표시·호환 group 없으면 보류. 실질 정보: CH04 공동 가치와 다른 방향별 활용.
- bppr:material:CH09.P2:recall-contribution-without-value-price: 기여를 누락하지 않는 질문을 남길 여지. 조건: 미표시·실제 기여 미확인 시 보류. 실질 정보: 긍정 의미를 경제 권리로 승격하지 않는 회수.
- bppr:material:CH09.P3:recall-consent-principle: 빠른 결정과 합의의 경계를 남길 여지. 조건: 선행 actuallyDisplayed·같은 과제·호환 source group 필수. 실질 정보: CH08 조정 이후의 표시 기반 원칙.
- bppr:material:CH09.P3:recall-scope-and-stop-principle: 친분과 사업의 경계를 지킬 질문. 조건: 표시 이력·owner·과제·root 없으면 회수 보류. 실질 정보: 마찰 조정 후의 수행·중단 조건.
- bppr:material:CH09.P4:recall-business-value-with-boundary: 긍정과 경계를 함께 남길 여지. 조건: 실제 표시·호환 조건 없으면 긍정 결론 보류. 실질 정보: 긍정 종결을 수익·지속 약속과 분리.
- bppr:material:CH09.P4:recall-hold-and-safe-exit: 동업 유지 강요 없이 관계의 선택을 남길 여지. 조건: 실제 표시·안전·동의가 없으면 조정 강요 금지. 실질 정보: 종결에서 남기는 선택·안전의 가치.

특히 제안↔실행, 관찰↔가설, 실물 시험↔제공·계약 경계, 수주↔현금 시점, 초기 기여↔반복 운영을 서로 다른 기여로 구성했다. A/B 고정 영업·운영·재무 배역을 만들지 않았다.
