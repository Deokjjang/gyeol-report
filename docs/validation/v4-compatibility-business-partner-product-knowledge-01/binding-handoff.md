# 후속 Evidence binding 인수 — 이번 구현 없음

새 연구 ID는 bppr: namespace이며 CalculatedEvidenceId와 타입상 구별한다. runtimeImplemented/customerApproval/connectedToRuntime은 모두 false. import·lookup·barrel·resolver·selector·ledger를 추가하지 않았다.

1. businessPartner와 정확한compatibility-fixed-ab-v1, 실제 두person ID를 확인한다. A/B는 대칭 슬롯이며 동일 지분·권한·자본·위험·경력을 뜻하지 않는다. 과거 저장본을 보충·재생성하지 않는다.
2. 각자 실제 natal/MBTI source·조건·sourceCoverage·hash를 검증한다. 개인 Fusion은 같은 사람의 두 실제root·rule·축·방향·context·source assignment를 확인한다. 상대의 source나 연구 정의만으로 허가하지 않는다.
3. source JSON→semantic node→SCORING/REFERENCE→domain projection→actual candidate eligibility→sentence provenance→customer approval의 각 경계를 별도 확인한다. 현재 WORK/CAREER/THINKING/MONEY/INVESTMENT는 비연애 projection 미허용. 연구 보강은 domain 승인이 아니다.
4. 모든 ancestor의 person/owner·classification·domain·context·조건·source path/hash·sourceCoverage·rule·same-person Fusion 두root·중복을 검토한다. mixed side/comparison/claim/Fusion/recall의 일부 허용ID로 전체를 허가하지 않는다. CHILDREN 문제는 현재 런타임에 남아 있으며 이번 고치지 않았다.
5. canonical은 실제kind/ID·양쪽person refs·기둥·기호·성립 조건을 사용한다. 지원34membership과 미지원30definition을 구분한다. 원국 내부·기간 관계·없던 시주로 채우지 않는다.
6. AB: viewer B.dayMaster,target A.dayMaster. BA: viewer A.dayMaster,target B.dayMaster. 같은 십성은 그대로 두며 권한·성공·사기 의미를 생성하지 않는다.
7. Pair는 원천의 방향별 generic reference뿐. reportLine·love/marriagePattern·Socionics 명칭은 전문 사업 증거가 아니다. 256방향 존재는 전문 원고 전수 완성 아님.
8. 실제 사업 상태/구조/당사자/단계/과제/산출/시간/기여/출자/지분/자산/부채/매출/비용/현금시점/계약/결정권/대리권/IP/손실/중단/종료/안전 정보가 필요하다. 현재 입력은 이를 수집하지 않는다. 새 연구의 VerifiedBusinessContext는 후속 검토용 타입이며 payload 변경이 아니다. UNKNOWN을 추측하지 않는다.
9. direct sourceGroup 내부는 모두 AND. 회수는 실제 표시한 호환 group/subset만 선택한다. incompatible A/B type 그룹을 전체 AND로 묶거나 다른 후보의 근거를 동시에 개인화하지 않는다.
10. CH08/CH09는 같은 두사람·task·owner·direction·실제root와 actuallyDisplayed를 확인한다. 실제 소개된 긍정·주의·조정의 호환 의미만 회수한다. 후보 존재는 표시이력이 아니다. ledger는 구현하지 않았다.
11. 같은 fact root·공통축·Fusion·Pair·역할·뷰·회수를 독립 근거로 중복 집계하지 않는다. MBTI미상은 해당 source/Fusion/Pair 보류, 시각미상은 시주 관계 보류.
12. 개별 법률·금융·세무·자격·책임 판단은 별도 전문 검토. 사기·강요·경제적 착취·위험한 협의는 일반 궁합 조율·동업 유지로 강요하지 않는다.

현재 bindingProposalTypes.ts는 검토 계약만 제공한다. 어떤 실제 생성기에도 연결하지 않았고 고객 적용 승인도 없다.
