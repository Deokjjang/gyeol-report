# 후속 Evidence Binding 인수 조건

이번에는 타입·연구 규칙만 작성했다. 실제 연결·선택·검증 엔진은 구현하지 않았다. 신규 runtime import·lookup·barrel·score·발행 경로는 없다.

1. 실제 personId와 A/B 슬롯을 먼저 고정한다. 개인 MBTI·natal·Fusion은 자기 owner의 근거만 사용한다. 관계 이력·동창·같은 직장·연락·돈거래·비밀·질투·단절·우정 기간은 입력이 없으면 UNKNOWN이다.
2. 각 문장에 실제로 필요한 source system만 검토한다. MBTI 미상은 해당 개인 MBTI·Pair·Fusion의 보류이며 유효한 natal 전체를 삭제할 이유가 아니다. 상대 유형·기본 유형·가짜 시주로 채우지 않는다.
3. 교차 관계는 기존 producer가 계산한 kind·양쪽 기둥 refs·구성을 검증한다. 정의가 있다는 이유로 새 관계를 만들거나, 미지원 형·파·원진·천간합을 비슷한 지원 관계로 바꾸지 않는다. 전통 해석의 검증 상태는 별도로 유지한다.
4. AB는 B 일간이 A 일간을, BA는 A 일간이 B 일간을 본 기존 방향 ID다. Pair 참고도 해당 방향의 실제 primary row와 원래 direct/inferred 상태를 보존한다. 같은 의미라면 인위적 방향 차이를 만들지 않는다.
5. 허용 source 하나가 있다는 이유로 다른 ancestor를 허용하지 않는다. 모든 source node·annotation·mixed side·comparison·Fusion root의 owner/domain/context/조건을 확인한다. INTP CHILDREN ID가 친구 원고의 provenance에 남는 현상은 새 자료의 승인 근거가 아니다.
6. 같은 개인의 실제 명리·MBTI 두 root와 facet의 역할·sign·상황을 확인한 뒤에만 개별 Fusion을 검토한다. 연구 facet을 관찰 사실로 바꾸지 않으며, Fusion을 제3의 독립 사실로 중복 집계하지 않는다.
7. generic MBTI Pair·전통 상징·외부 우정 문헌·현대 편집 질문은 서로 다른 자료다. Pair로 개인 성격을 확정하거나, 합·충·십성·유형으로 실제 신뢰·친구 수·우정의 기간·건강·재물을 예측하지 않는다.
8. CH08은 실제로 표시한 CH07의 같은 사람·사건·문제·source group만 회수한다. A/B의 행동 변경은 별도 동의가 필요하다. 사과·용서·접촉·신뢰·친밀감 복원은 서로 다른 선택이며 직접 화해를 강요하지 않는다.
9. CH09는 실제 표시 이력을 검증한다. group 내부의 필요한 roots는 AND, 서로 호환되는 표시 group 중에서만 선택한다. 후보 존재를 읽은 이력으로 취급하거나 서로 배타적인 타입·장면을 합치지 않는다. 특히 CH09.P2의 명리 회수는 CH01.P2의 실제 표시·동일 relation refs 없이는 사용하지 않는다.
10. 원천 연결이 부족한 문장은 보류한다. 이번 32조건부 질문과 4회수 후보는 승인된 고객 원고가 아니며, 전체 타입×문단의 전문화가 끝났다는 뜻도 아니다. 실제 기존 fallback·저장본·원고는 그대로 유지한다.

후속 과제는 CHILDREN 전체 ancestry 경계, domain별 적용 승인, 문장별 정확한 source 역할·성립 조건 연결, 실제 표시 ledger, 관계 맥락 입력의 적법한 수집 범위, 미지원 명리 관계와 계보별 검증이다. 이번 작업에서 해결·구현·활성화하지 않았다.
