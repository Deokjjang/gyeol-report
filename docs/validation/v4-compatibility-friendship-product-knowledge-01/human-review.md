## 가까운 주제의 중복 검토

- CH01.P1 / CH02.P1 / CH05.P1 / CH04.P3: 시작의 상호 선택, 제안하는 개인의 방식, 수신자 B에게 남는 영향, 만남 중의 참여 강도를 구분한다. 초대 장면을 반복해 네 독립 과학 사실로 집계하지 않는다.
- CH01.P2 / CH07.P2 / CH09.P2: 계산된 관계 구성의 설명 범위, 그 기호로 실제 갈등을 단정하는 오류, 이미 표시된 같은 근거의 제한된 회수를 나눈다. 검토 중 CH09.P2를 사적 정보 경계의 일반 후보로도 회수할 수 있던 조건을 제거하고 CH01.P2의 실제 표시로 한정했다.

- CH02.P2 / CH04.P4 / CH08.P2: 개인이 공개를 정할 조건, 제3자 자리에서 정보를 사용할 허락, 실제 위반이 확인됐을 때의 책임·정정을 구분한다.
- CH02.P4 / CH05.P2 / CH05.P3 / CH07.P3: 개인의 과도한 개입, 요청과 도움 종류의 맞물림, 수신자가 느낄 보답의 부담, 반복 비용의 미합의를 나눈다. 공통 CARE/BOUNDARY 개념은 정당하게 재사용하되 같은 호의 장면을 새로운 원천 사실로 세지 않는다.
- CH03.P3 / CH06.P2 / CH09.P3: 기억을 사용하는 개인의 강점, 그 관심을 받는 A의 현재 선택, 생활 변화 이후 실제 표시 조건의 재검토를 구분한다.
- CH03.P4 / CH07.P1 / CH06.P1: 한계의 표현, 실제 연락 건에서의 서로 다른 이해, B의 응답이 A에게 남기는 방향별 정보를 나눈다.
- CH05.P4 / CH06.P3 / CH07.P4: 다른 관계의 통제 요구, 성취를 통한 자기 판단의 평가, 모임의 제3자 사실과 해석을 구분한다. 질투·배신은 실제 발생 사실로 붙이지 않는다.

## 방향과 맥락

A를 늘 적극적인 사람, B를 늘 수동적인 사람으로 고정하지 않았다. CH02와 CH03의 질문은 편집 관찰 위치이며 실제 owner 근거가 그 행동을 지원하지 않으면 사용하지 않는다. 16개 유형별 A/B 기록에 같은 질문이 있는 것은 슬롯 대칭의 정당한 재사용이며 96개 독립 성격 사실을 만들었다는 뜻이 아니다. A→B/B→A는 수신자 기준을 각각 요구하고, 실제 뜻이 같으면 강제 차이를 만들지 않는다.

CH07 네 문단 모두 회복 연구와 연결한다. 13개 구체적 검토는 연락·일정 변경·모임·비밀·농담·조언·호의 부담·공동 비용·성과 비교·대화 간격·생활 변화·반복 위해·명리 기호 오인을 구분한다. 이 중 명리 기호 오인은 실제 문제가 없을 때 사과나 화해를 새로 요구하지 않는 반례를 포함한다.

좋은 발견은 새로운 활동의 접점, 취향의 확장, 부담 없는 동행, 공개 범위의 존중, 요청에 맞는 지원, 기억의 갱신, 조정 가능한 관계 형태로 다양화했다. 위험은 독점·평가·미동의 개입·보답 의무·정보 사용·무통보 기대·낙인으로 구체화했다. 반전은 큰 호의·긴 만남·많은 공개·무조건적 유지가 항상 좋은 조건은 아니라는 방향이며, 특정 고객에게 이미 그런 일이 있었다고 서술하지 않는다.

## 남은 검토 범위

32개 조건부 후보와 4회수는 기본 전문 연구이며 모든 타입×문단의 완성 원고가 아니다. 원천의 정확한 성립 조건·각 문장 의미·전체 ancestor를 실제 고객 근거에 연결하는 검토는 아직 수행하지 않았다. 전통 계보·MBTI 실증·관계 기간·실제 행동을 이 자료로 보장하지 않는다. 근거가 부족한 경우 새 사실 대신 보류하도록 설계했다.
