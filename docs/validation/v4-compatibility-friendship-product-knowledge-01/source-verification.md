# 실제 접근 출처와 적용 제한

확인일 2026-10-14. 논문 원문을 대량 저장·복제하지 않고 짧은 자체 요약과 locator만 기록했다. 아래 문헌의 결과가 곧 MBTI·명리·특정 두 사람의 우정을 검증하는 것은 아니다. 각 생활 장면과 조정 행동은 조건부 편집 적용이며 문헌의 검증된 처방이라고 표기하지 않는다.

| 출처 | 확인 범위 | 사용한 구분 | 제한 |
|---|---|---|---|
| [Hall, How many hours does it take to make a friend?](https://journals.sagepub.com/doi/pdf/10.1177/0265407518761225) | 논문 abstract, Study1 limitations, discussion pp15–17 | 알고 지낸 기간·선택한 상호작용·활동의 종류를 구별 | 회상 추정·생존 편향·첫해 대학생 표본. 일정 시간 뒤 친구가 된다는 기준이나 고객 지속 예측 없음 |
| [Deci et al., Mutuality in Close Friendships](https://selfdeterminationtheory.org/SDT/documents/2006_DeciLaGuardiaetal_Friendships_PSPB.pdf) | abstract, 자율성 지지 정의·peer mutuality 논의 pp1–3 | 상대 관점·선택·주고받는 지원 | 한정된 표본·연관 결과를 개인 인과나 보장으로 확대하지 않음 |
| [Khullar et al., Relationship dissolution](https://journals.sagepub.com/doi/pdf/10.1177/02654075211026015) | abstract·정의·응답 범주 | 종료·거리 두기·활동/주제 제한을 구분 | 주로 대학생인 청년의 가상 상황 응답. 실제 장기 결과나 모든 연령의 최선 절차가 아님 |
| [Laurenceau et al., Intimacy as an interpersonal process](https://pubmed.ncbi.nlm.nih.gov/9599440/) | PubMed abstract | 공개량과 지각된 반응성을 구분 | 원문 전체 미확인; 친구 전용 결과·비밀 공개의 권한·우정 효과 보장 아님 |
| [Feeney & Collins, A new look at social support](https://pubmed.ncbi.nlm.nih.gov/25125368/) | PubMed abstract·figure captions | 어려움 대처와 성장 기회의 지원을 구분 | 이론 모형·초록 범위. 특정 고객의 회복·건강·성장 효과 실험으로 사용하지 않음 |
| [Krems & Williams, 저자 연구 해설](https://www.hbes.com/differences-in-mens-and-womens-friendships-cause-some-differences-in-mens-and-womens-friendship-jealousy/) | 저자 해설의 대체 위협·다른 관계 맥락 | 다른 친구와의 시간과 대체된다는 지각을 구분 | 원 논문 전체 분석 검증 아님. 성별별 규칙·질투 진단·소유와 감시 정당화 제외 |
| [Lewicki et al., Effective Apologies](https://onlinelibrary.wiley.com/doi/abs/10.1111/ncmr.12073) | publisher abstract | 사과 구성의 평가와 실제 신뢰 회복을 구분 | 우정 전용 아님. 여섯 요소의 세부 목록·순서 미확인; 용서·재친밀감 보장 없음 |

접근 실패도 숨기지 않는다. Feeney 원문의 PMC 페이지와 Sage PDF, UCSB 저자 페이지의 원문 PDF 링크는 CAPTCHA 또는 도구 접근 오류로 전체 내용을 확인하지 못했다. Feeney는 성공적으로 확인한 PubMed 초록 범위만 사용했다. Khullar의 PMC 페이지도 CAPTCHA였지만 출판사 PDF에서 위 구간을 확인했다. 검색 snippet만 확인한 Krems 원 논문은 별도 전문 검증 출처로 집계하지 않았다.

명리의 계보별 검증 상태, MBTI source-local direct/inferred, Pair의 미확립 Socionics mapping은 기존 자료 그대로다. 외부 우정 논문으로 이 상태를 승격하지 않는다. 출처 없는 관찰이나 개인정보는 만들지 않았다.
