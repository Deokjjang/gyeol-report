# 분야별 독립 질문과 조건부 응용 비교

모든 행은 현대적 편집 후보다. 전통 사실·확정 성향·예언이 아니다. 동일한 상징을 공유하는 다른 요소에 적용할 수 있으며, 각 대상의 구조·전체 원국·실제 생활 맥락과 반례를 먼저 확인해야 한다. 아래 질문/활용/위험은 새로 작성한 묶음이고 구조·기본 의미의 재사용은 신규 독립 의미로 세지 않는다.

일주 甲子의 저장 구성은 癸(正印)이고, 같은 일간의 비교 일주 甲戌의 저장 구성은 戊(偏財)·辛(正官)·丁(傷官)이다. 지지와 일간 대비 장간의 관계가 다르며 성격의 우열을 뜻하지 않는다.
甲子 / 丙子: 지지 子의 저장 집합은 같지만 기준 일간이 달라 각각 癸(正印) / 癸(正官)로 읽는다. 동일 지지를 동일 십성으로 취급하지 않는다.
