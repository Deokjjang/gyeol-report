## 분류와 자료의 충분성

A는 실제 열람한 역사적 전사에 있는 주장, B는 현행 저장소 정의·구성·지원, C는 제한 조건을 명시한 연구 추론, D는 실제 장면이 있을 때 검토할 현대 생활 질문, E는 확인하지 못한 직접 주장, F는 반려다. 전통 명리와 과학적 예측의 타당성을 동일시하지 않는다.

9개의 일반 설명만 작성한 것이 아니다. 각64조합에 구성·성립·제한·전승·다른 조합과의 차이를 보유한다. 예를 들어 申辰은 수국의 생고 두 자리로 子가 없으며, 申子·子辰과 왕지 유무가 다르다. 巳申은 육합·형·파가 겹치지만 동일 실제 쌍이고 협력→고통→배신의 사건 순서를 제공하지 않는다. 辰辰은 실제2자리 반복이고 辰 하나로 성립하지 않는다.

분야별 차이는 [domain-review.md](domain-review.md)와 [content-review.md](content-review.md)에 전수 제시했다. 각 칸의 추가 질문은 별도 판단 문제를 다루지만 새로운 명리 사실로 집계하지 않는다. 파·원진의 조합별 고유 성격·사건을 채우기 위해 창작하지 않았다. 모르는 부분은 구성·전승 차이와 구체적 추가 출처 요구를 남겼다. 원진의 '긍정'은 원진이 좋은 효과를 낸다는 주장이 아니라 실제 오해를 확인할 때만 사용할 수 있는 일반 소통 점검이다.

6상품 회귀는 실제 생성과 고정 digest를 확인하는 오프라인 테스트다. Production 고객의 Book을 조회하거나 재생성한 것이 아니다. 계산·MBTI·Fusion·근거·원고와 Book 소스는 모두 기존929파일 해시 검증에 포함된다. 실제 고객의 저장본을 수정하지 않았다.

## 완료 판정과 남은 항목

독립 연구 DB의9종·64조합·72분야 자료 구축, 출처/계보/범위/충돌 분리와 기존 결과 보존은 검증했다. 직접 생활 예측72칸은 미검증 경계가 유지되며 자동 고객 승인0건이다. 파·원진의 고전 직접 계보, 반합/형의 학파별 기준, 교감·학술 전문, 조합별 효력 검증은 후속 연구의 남은 항목이다. 기존 계산 경로의 한계와 알려진 테스트 실패도 그대로 남겼다.

다음 근거 연결의 검토 자료로 넘길 준비는 됐으나 runtime 연결·고객 사용·판매·배포 승인은 하지 않았다. 기간 상호작용 DB·MBTI·Fusion·표현 DB·생성기는 시작하지 않았다. 신규 작업 브랜치에만 관련 자료를 커밋·푸시하며 원격 SHA 일치는 최종 실행 결과에서 확인한다.
