# 후속 연결 전 필요한 계약

이번 자료는 계산 규칙·고객 원고가 아닌 독립 연구다. 모든 레코드는 `connectedToRuntime=false`, `approvedForCustomer=false`, `runtimeEvidenceIds=[]`다. 연구 ID를 기존 Evidence ID로 변환하거나 lookup/barrel로 공개하지 않았다.

1. 관계 이름보다 먼저 실제 producer, owner, 기둥, 참여 간지, 확정 여부, 기간을 제공해야 한다. 연구 자료의 `scopeRefs`는 검토할 수 있는 범위의 목록이다. 실제 지원을 승인하는 필드가 아니다. 각 자료에는 실제 지원 `producerScopeRefs`와 미지원 `unsupportedProducerScopeRefs`를 별도로 기록했다. 전체 삼형2건은 producer 지원이 없다. 적용 가능한 관계는 `relationScopes.ts`와 `support-matrix.json`의 producer별 지원표로 제한된다. `unsupported` 범위에서는 계산 결과를 만들지 않는다.
2. 원국과 두 사람 사이의 관계를 분리한다. 두 사람의 십성 방향성은 관계쌍의 대칭성과 별도다. 중복 지지에서 첫 ref만 선택하는 현행 궁합 정책의 한계는 별도 검토가 필요하다. 이번에 수정하지 않았다.
3. 합 쌍의 존재·합의 작용·합화는 각각 다른 판단이다. 새로운 합화·강도·용신·점수 계산을 이 자료에서 얻었다고 주장하지 않는다. 삼합은 실제3자 구성과 반합의2자 구성을 분리하고 빠진 지지를 채우지 않는다.
4. 형은 쌍11개, 전체 삼형2개, 실제 동일 지지 반복4쌍을 구분한다. 역사적 방향·명칭 이견을 현행 대칭 검출에 강제로 병합하지 않는다. 고전의4지지 토국은 현행3지지 삼합 밖의 별도 전승으로 보존했다.
5. 원진 원국 투영은 실제 일치 쌍을 노출하지 않는다. 원진살을 독립 위험으로 추가 집계하지 않는다. 월운 확장 경로는 실제 anchor/target/기간 ref가 있어 원국 투영과 다르다. 현재 교차 원진은 미지원이다.
6. 대운·세운·월운은 서로 다른 출처다. 원국과 기간 지지의 동일값은 실제로 서로 다른 자리일 수 있다. 적용 구간과 전환의 certainty를 유지해야 하며 한 해 전체로 확장하지 않는다. 월운 관계와 기간간 쌍 비교를 혼동하지 않는다.
7. `majorFortuneEvidence.ts`의 레거시 보조 경로는 대운 지지를 원국 배열 앞에 넣는 부분이 있다. 그 결과의 ordinal 위치를 실제 원국 위치로 읽을 수 없다. 최신 `majorFortuneDecadeReading.ts`의 분리 경로와 같은 provenance 계약으로 취급하면 안 된다. 실제 고객 영향·수정 여부는 별도 작업에서 판단해야 한다.
8. 분야별 자료는 실제 해당 장면·동의·정보가 있을 때만 검토할 편집 연구다. D 응용의 타당한 생활 질문이 A 전통 예측이나 실증 효력을 승인하지 않는다. E 경계와 F 반려를 반드시 함께 검토한다. 안전 문제·법률·금융·의료 판단은 관계 기호로 대신하지 않는다.
9. 해·파·원진의 겹친 쌍, 완성 삼합과 부분 반합, 원진살의 재투영을 독립 사건·확률·효과로 더하지 않는다. 같은 정의에서 장면만 달라진 경우는 새로운 명리 사실로 집계하지 않는다.
10. 미검증 고전 기원·학파별 성립 조건·조합별 고유 생활 효력은 추가 일차 전거와 반례 검토가 필요하다. KCI는 초록·서지정보만 열람했으며 전문·인용 원전은 읽은 출처가 아니다.

대운·세운·월운 기간 상호작용 DB, MBTI, Fusion, 표현 DB, 의미 축, 상품 생성기 연결은 이번 작업에서 시작하지 않았다.
