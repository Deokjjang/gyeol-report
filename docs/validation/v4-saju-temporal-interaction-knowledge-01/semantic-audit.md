# 의미 다양성 감사

문자열 차이만으로 의미 품질을 PASS 처리하지 않았다. 다음 비교는 실제 근거의 참가자·기능·기간·질문의 차이를 읽은 결과다. 전통 사실의 수와 현대 응용 질문의 수는 다르다.

- 대운 정재: 여러 해 유지할 자원 운영 체계. 세운 정재: 올해 확정한 자원과 기대를 분리. 월운 정재: 현재 구간 안의 확정 지출·가용 시간 점검. 같은 역할을 공유하되 운영의 지속성과 검증 단위가 다르다.
- 대운 편인×세운 식신: 탐색한 관점을 반복 산출로 시험. 대운 식신×세운 편인: 기존 생산 품질을 유지하면서 다른 관점을 넣을 조건 확인. 순서를 바꾸면 유지할 기반과 새로 처리할 과제가 바뀐다.
- 비견×겁재와 겁재×비견: 전자는 독자 역할의 공동 사용 권한, 후자는 공유하던 자원 안에 개인 책임을 남기는 질문이다. 같은 peer군으로 수렴하지만 기준 역할은 다르다. 100칸은 25기능군 비교와 10개 동일역할 재등장, 군 안의 역할 차이를 검토하는 공간이다. 이를 100독립 사실로 집계하지 않는다.
- WOOD→FIRE는 목의 공급이 화의 산출로 이어지는 방향을, FIRE→WOOD는 화가 목의 공급을 받는 방향을 나타낸다. 생성 관계를 공유하지만 기준 소유자와 비용 질문이 다르다. 두 기간 오행의 존재는 B, 실제 생활 기능 비유는 C/D다. 강약·길흉은 산출하지 않는다.
- 충은 배치 수정, 형은 반복 압박, 해는 드러나지 않은 기대 차이를 검토하는 서로 다른 C 질문이다. 어느 하나도 사건 발생을 뜻하지 않는다. 같은 실제 상황에 셋이 겹쳐도 세 사건으로 세지 않는다.

## 같은 인물의 다른 연도

A 2028: 戊寅 편인 배경 + 戊申 편인. `major:4:戊寅:year:2028:戊申:cycle:충:寅申:cycle`, `...:cycle:형:申寅:cycle`와 `...:natal:반합:申子:day`는 장기 배치/반복 부담/원국 일지의 부분 연결이라는 다른 비교를 제공한다. 2029 己酉 정인은 기초 지원의 역할이고 cycle 관계는 없으며 원국 시지 卯酉 충 등이 남는다. ‘확인하라’의 어미를 바꾼 것이 아니라 확인할 기능·참가자가 달라졌다.

A 2025와 2035는 둘 다 정재지만 장기 배경은 편인→정관이고 2025 cycle 해·형은 2035에 없다. 같은 십성만으로 같은 연도 해석을 복제하지 않도록 질문을 따로 작성했다. 반대로 A 2023과 2035의 원국 접점이 같아지는 부분은 새 사건 차이라고 과장하지 않는다.

## 중복 집계 기준

정의9종·조합64개는 이전 DB를 rr ID로 참조하고 복제하지 않았다. 54개 scope칸은 같은 정의의 기간 적용 조건이다. 동일 출처 규칙의 원진/원진살 재투영, 완성 삼합 안의 부분 반합, 같은 쌍의 다중 source는 관찰 provenance를 보존하되 영향·확률을 더하지 않는다. source별 중복을 합칠 때 owner·position·기간·rule을 보존해야 한다.

연구의 긍정·위험·반전 필드는 조건을 바꾸어 비교하는 C 후보다. 48분야 질문과 78실제 기간 질문은 D 응용이며 독립 명리 사실이 아니다. 반복되는 안전 문구는 의도적 계약 재사용으로 분류하고 의미 다양성의 성과로 집계하지 않는다. 자동 중복검사는 누락 방지이며 이 독해를 대체하지 않는다.
