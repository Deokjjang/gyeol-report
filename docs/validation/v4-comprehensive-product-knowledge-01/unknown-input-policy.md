# 입력·미상 안전성

- 실제 직업 enum은 빈 값 포함10개, 관계 enum은 빈 값 포함6개다. 관계 other는 지원하지 않아 반려 목록에 기록했다. provided는 16개 MBTI 입력의 연구 그룹이며 새 enum이 아니다.
- 실제 입력의 MBTI 모름은 빈 문자열이며 기존 semantic 경계의 null 정규화를 보존한다. 56개 명리 단독 후보는 실제 원국·개인 적용 조건이 있을 때만 검토한다. MBTI·Fusion이 필수인 CH01.P3·CH03 등의 역할은 보류하고 유형을 만들지 않는다.
- 35개 회수 자료는 실제 도입한 선행 의미의 가용성을 따른다. 후보 풀에 다른 유형이 있어도 동일 개인의 실제 입력에 맞는 부분만 회수한다. 모든 후보를 한 사람에게 합치지 않는다.
- 정확·추정·미상은 기존 precision 계약을 따른다. 추정 시간은 stable·candidates·confirmed를 이용할 요구만 기록한다. 시주·전체 부재·완성 구조를 임의 확정하지 않는다.
- 가족 구성·상대 MBTI·현재 직무·소득·자격·교제 경험은 원국과 유형에서 생성하지 않는다. 실제 입력이 없으면 일반 질문 또는 보류 상태다.
- 새 입력 validator·캐시·발행 fallback은 구현하지 않았다. 이 문서는 후속 연결의 조건이고 기존 고객 흐름을 바꾸지 않는다.
