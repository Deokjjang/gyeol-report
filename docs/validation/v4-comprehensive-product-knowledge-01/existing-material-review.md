# 기존 종합 자료 감사

기존 15facet·각 11생활 맥락·별도 positive와 20개 export 묶음을 모두 보존했다. 원문·hash·키는 existing-material-inventory.json에 있다. 아래는 15개 기능을 직접 비교한 정성 감사이며 모든 기존 문장을 독립 새 사실로 세지 않는다.

- 일반화 위험: 같은 첫 행동 조언을 여러 장에 쓰기 쉬움
- 추가 질문: 누가 시작할 권한을 갖고 어떤 첫 단계가 안전한가?
- 장 사이 재사용: CH01 소개·CH05 재능·CH08 업무에서 실제 새 조건을 요구
- 보존: 11맥락의 적용·위험·장면은 이미 존재하며 삭제하지 않음
- 기존 맥락: identity, inner, strength, stress, work, learning, money, love, family, social, direction
