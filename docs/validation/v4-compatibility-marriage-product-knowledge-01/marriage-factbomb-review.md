# 팩폭의 역할

- cmpr:material:CH05.P1:ab-rule-with-revision: 정관으로 보인다고 상대를 지휘할 권한이 생기는 것은 아니다. 조건: 규칙 제안을 B의 생활 전체를 관리할 권한으로 바꿈 반례: B 기준 결과가 정관이 아니면 그 십성의 자극으로 설명하지 않는다.
- cmpr:material:CH05.P1:ab-resource-explanation: 비용을 잘 설명해도 상대의 동의까지 대신 계산할 수는 없다. 조건: 계산을 더 자세히 했다는 이유로 B의 우선순위를 배제 반례: 정재 결과나 실제 공동 비용 전제가 없으면 돈 관계의 사실로 배정하지 않는다.
- cmpr:material:CH05.P1:ab-opportunity-with-maintenance: 좋은 기회여도 유지할 시간을 함께 고르지 않았다면 공동 계획이 아니다. 조건: 기회라는 말로 검토와 동의를 앞질러 확정 반례: 실제 편재가 아니거나 B가 검토를 원하지 않으면 긍정 효과를 확정하지 않는다.
- cmpr:material:CH05.P1:ab-standards-without-performance-review: 잘하자는 말이 많아질수록 쉴 수 있는지부터 확인해야 할 수 있다. 조건: 집을 모든 행동이 평가받는 공간으로 만듦 반례: 편관 결과가 없으면 해당 긴장을 실제 방향 근거로 쓰지 않는다.
- cmpr:material:CH05.P2:ab-advance-plan-information: 계획을 알려주는 것과 함께 정하는 것은 다른 행동이다. 조건: 초안부터 최종 일정처럼 공유 반례: B가 실제로 계획 정보를 원하지 않는다면 더 많은 일정 공유를 무조건 요구하지 않는다.
- cmpr:material:CH05.P2:ab-care-with-whole-task: 실행만 맡아도 모든 설명이 상대에게 남으면 업무는 아직 나뉘는 중이다. 조건: 돕는 과정에서 확인과 지시를 B에게 계속 요구 반례: B가 직접 하기를 원하거나 A의 여력이 없으면 대신 맡기를 장점으로 강요하지 않는다.
- cmpr:material:CH05.P2:ab-expense-purpose-dialogue: 숫자가 자세하다고 다른 목적이 사라지는 것은 아니다. 조건: 필요 비용을 낭비라거나 즐거움을 무책임으로 단정 반례: 실제 비용이 없으면 구체 금액·저축률·구매 결과를 생성하지 않는다.
- cmpr:material:CH05.P2:ab-support-before-family-contact: 설명을 대신해 줄 수 있어도 공개할 내용을 대신 고를 수는 없다. 조건: 잘 조율하려고 B의 개인 사정까지 공개 반례: 실제 가족 정보나 동의 없이 간섭한 친족·피해 경험을 만들지 않는다.
- cmpr:material:CH05.P3:ab-unilateral-budget: 고르라고 말해도 이미 비용이 확정됐다면 선택은 뒤늦게 온다. 조건: 상대의 개인 재량까지 공동 기준으로 통합 반례: 위협·필수 자원 차단이 있으면 절약 방식 차이로 공동 조율하지 않는다.
- cmpr:material:CH05.P3:ab-holiday-finality: 답할 시간을 주지 않았다면 동의가 늦다는 말부터 다시 봐야 한다. 조건: 대답이 느리다는 이유로 A가 전체 결론을 냄 반례: 법적 계약·실제 부동산 거래의 자문으로 쓰거나 특정 거래를 지시하지 않는다.
- cmpr:material:CH05.P3:ab-care-as-debt: 혼자 맡았다는 사실만으로 상대가 그 담당에 동의한 것은 아니다. 조건: 미리 한 수고를 나중에 같은 양의 빚으로 청구 반례: 실제 수고·착취·희생의 과거를 입력 없이 만들지 않는다.
- cmpr:material:CH05.P3:ab-standard-remakes: 기준이 매번 끝난 뒤에 생기면 책임을 맡겨도 끝낼 수 없다. 조건: 수정이 반복되며 B는 A의 확인만 기다림 반례: 실제 위생·안전 문제를 취향이라며 그대로 두라는 조언은 아니다.
- cmpr:material:CH05.P4:ab-return-choice-before-commitment: 의견을 들었다는 말과 의견 때문에 바꿀 수 있다는 말은 다르다. 조건: 검토 시간은 주지만 결론을 바꾸지 않음 반례: 안전상 즉시 필요한 임시 조치와 장기 공동 결정을 구분한다.
- cmpr:material:CH05.P4:ab-own-one-whole-process: 담당을 바꿨는데 기억하는 사람은 그대로라면 조정은 끝나지 않았다. 조건: A가 모든 지시를 계속 제공하며 분담됐다고 끝냄 반례: 실제 담당 변경에 동의하지 않았거나 B가 접근할 수 없으면 이전됐다고 쓰지 않는다.
- cmpr:material:CH05.P4:ab-joint-cost-private-discretion: 투명하자는 말이 상대의 모든 선택을 허락제로 만들 수는 없다. 조건: 공동생활을 이유로 모든 내역을 요구 반례: 위협·경제적 통제가 있으면 정보 공유를 더 잘하라는 화해 처방으로 끝내지 않는다.
- cmpr:material:CH05.P4:ab-check-impact-before-correction: 말투를 바꿔도 기준이 계속 늘어나면 끝낼 수 없다는 부담은 남는다. 조건: 부드러운 말투로 같은 재작업을 계속 요청 반례: 실제 안전 위험을 늦추거나 타협할 이유로 쓰지 않는다.
- cmpr:material:CH06.P1:ba-receivable-help: 도움받을 여지가 있다고 누구에게 무엇을 맡길지가 정해지는 것은 아니다. 조건: B가 보호해 준다는 뜻으로 A의 선택을 먼저 끝냄 반례: A 기준 정인 결과나 실제 수락 조건이 없으면 도움받은 사실로 사용하지 않는다.
- cmpr:material:CH06.P1:ba-question-hidden-upkeep: 왜 하는지 묻는 말에는 지금까지 누가 했는지도 들어가야 한다. 조건: 이유를 묻는 질문이 A의 수고를 불필요하다고 평가 반례: 편인 결과가 없으면 해당 명리 자극으로 설명하지 않으며 실제 업무 누락도 만들지 않는다.
- cmpr:material:CH06.P1:ba-enjoyment-with-maintenance: 좋은 시간을 제안해도 그 뒤의 정리가 저절로 끝나지는 않는다. 조건: 즐거우니 시간·비용·뒷정리는 설명하지 않아도 된다고 여김 반례: 식신 결과나 A의 참여 의사가 없으면 좋은 효과를 확정하지 않는다.
- cmpr:material:CH06.P1:ba-peer-voice-not-identical-needs: 같은 오행 분류가 같은 생활 기준을 뜻하지는 않는다. 조건: 같은 답을 해야 대등한 관계라고 강요 반례: 양방향이 같은 비견이면 다른 명리 효과를 임의로 만들어 구별하지 않는다.
- cmpr:material:CH06.P2:ba-update-family-information: 누군가 부탁했다는 사실과 우리가 맡았다는 약속은 다른 단계다. 조건: 외부의 기대를 확정된 의무로 전달 반례: 특정 가족의 요구·경제 사정·성격을 입력 없이 생성하지 않는다.
- cmpr:material:CH06.P2:ba-prepare-changed-work-window: 다음 계획이 생겨도 이전 일의 끝은 아직 남아 있을 수 있다. 조건: 새 계획만 말하고 이전 약속의 처리는 생략 반례: 실제 직업·근무·수입 변화가 확인되지 않으면 일어난 사건으로 쓰지 않는다.
- cmpr:material:CH06.P2:ba-quiet-maintenance-report: 말없이 했다는 장점에도 아직 남은 일은 알려야 한다. 조건: 아무 말 없이 일부만 끝내고 전체를 맡았다고 여김 반례: A가 보고를 원하지 않거나 합의 범위가 다르면 소통량을 무조건 늘리지 않는다.
- cmpr:material:CH06.P2:ba-new-routine-small-test: 시도는 새로워도 뒤처리를 늘 같은 사람이 한다면 같은 분담이다. 조건: 실험을 계속 바꾸어 A가 모든 예외를 수습 반례: 해당 Fusion이 현재 결혼 projection에 허용된다는 사실로 자동 승격하지 않는다.
- cmpr:material:CH06.P3:ba-visible-only-finish: 눈에 보이는 일이 끝나도 다음 일을 기억할 사람이 남을 수 있다. 조건: 도와줬다는 말로 이후 확인을 모두 A에게 남김 반례: 실제 업무를 입력 없이 배정하거나 이미 불공평했다고 판정하지 않는다.
- cmpr:material:CH06.P3:ba-kinship-commitment: 이미 하겠다고 말했다면 상대의 선택은 나중에 도착한다. 조건: 가족을 위한 뜻으로 A의 시간·지출을 미리 배정 반례: 가족의 실제 권리·법적 의무·간섭 사실을 이 자료로 판단하지 않는다.
- cmpr:material:CH06.P3:ba-change-without-handover: 바뀐 일정이 알려져도 누가 남은 일을 맡는지는 별도다. 조건: 남은 일을 말하지 않고 새 일정으로 이동 반례: 현재 일·소득·시간 제약이 확인되지 않으면 발생한 전환으로 서술하지 않는다.
- cmpr:material:CH06.P3:ba-unanswered-plan: 부드럽게 넘긴 답이 합의로 남으면 다음 선택이 먼저 움직인다. 조건: 괜찮다는 말 뒤에 실제 반대 조건을 모두 남김 반례: B가 이미 분명히 거절했다면 A가 존중하지 않은 문제를 B의 표현 탓으로 돌리지 않는다.
- cmpr:material:CH06.P4:ba-state-completion-boundary: 매번 무엇을 할지 물어야 한다면 맡은 범위를 다시 정할 필요가 있다. 조건: 기준만 받아 적고 계속 A에게 다음 지시를 요구 반례: 실제 접근·기술·시간이 없는 업무를 무리하게 맡으라는 조언은 아니다.
- cmpr:material:CH06.P4:ba-confirm-before-external-promise: 확인 없이 한 약속의 수습을 상대의 배려 의무로 만들 수는 없다. 조건: A가 거절하면 체면을 잃게 했다고 책임을 돌림 반례: 실제 친족의 요구가 없으면 갈등이 이미 생긴 것으로 회고하지 않는다.
- cmpr:material:CH06.P4:ba-handover-before-new-schedule: 변화를 지지한다는 답이 남은 모든 일을 맡겠다는 약속은 아니다. 조건: 새 계획의 좋은 점만 말하고 부담을 감수하라고 기대 반례: 학업·이직·사업·소득 변화가 실제로 일어났다는 사실은 생성하지 않는다.
- cmpr:material:CH06.P4:ba-name-pending-answer: 답이 미정이어도 언제 무엇을 더 볼지는 함께 정할 수 있다. 조건: 아직 모르겠다는 말만 반복하고 검토 통로를 닫음 반례: 거절의 안전이 없으면 표현 훈련으로 책임을 B에게 전가하지 않는다.
- cmpr:material:CH07.P1:money-purpose-difference: 가격을 논의하다 사람의 성실함을 채점하면 바꿀 항목이 사라진다. 조건: 같은 비용을 인격의 우열로 평가 반례: 실제 재정 상황이 없으면 과소비·빈곤·자산 격차를 만들지 않는다.
- cmpr:material:CH07.P1:cleanliness-and-comfort-criteria: 내게 편한 집이라는 말이 상대에게도 편하다는 답은 아니다. 조건: 모든 공간에 한 사람의 기준만 적용 반례: 실제 위생·건강·주거 조건이 없으면 의학적 위험이나 생활 습관을 추론하지 않는다.
- cmpr:material:CH07.P1:rest-order-and-waiting: 나중에 쉬면 된다는 말은 그 시간까지 비어 있다는 약속이 아니다. 조건: 내 휴식만 먼저 확정하고 상대는 남은 때에 쉬게 함 반례: 실제 자녀·돌봄 대상·근무 시간을 입력 없이 배정하지 않는다.
- cmpr:material:CH07.P1:family-request-vs-common-consent: 가족을 생각한다는 말에도 누구의 자원을 쓰는지가 들어가야 한다. 조건: 가족을 위한 선택이니 설명 없이 따라야 한다고 여김 반례: 친족의 성격·간섭·요구나 법적 의무를 추정하지 않는다.
- cmpr:material:CH07.P2:detected-clash-shared-timing: 충을 설명해도 이번에 바뀐 약속은 별도로 확인해야 한다. 조건: 한 관계로 모든 생활 차이를 설명 반례: 기간의 충이나 원국 내부 관계를 교차 관계로 바꿔 쓰지 않는다.
- cmpr:material:CH07.P2:clash-not-decision-cause: 계산된 충을 근거로 상대의 반대를 틀린 답으로 만들 수는 없다. 조건: 충을 상대가 내 말을 안 듣는 이유로 고정 반례: 실제 寅申 충이 없으면 검출 사실로 쓰지 않는다.
- cmpr:material:CH07.P2:harm-unsupported-wonjin: 한 쌍의 글자에 이름을 더 붙여도 새 계산 근거가 생기지는 않는다. 조건: 같은 글자라는 이유로 위험 관계를 두 번 집계 반례: 원진 연구표를 actual ID로 만들거나 관계의 불행을 예언하지 않는다.
- cmpr:material:CH07.P2:no-pair-relation-no-hidden-defect: 빈 관계 목록은 숨은 불화의 목록이 아니다. 조건: 특별한 관계가 없으니 일반적 갈등을 실제 문제처럼 삽입 반례: 근거 부족을 완벽한 궁합이나 나쁜 관계의 증거로 승격하지 않는다.
- cmpr:material:CH07.P3:criteria-revision-loop: 기준을 늘리는 사람과 변경을 알리지 않는 사람이 만나면 일의 끝이 사라질 수 있다. 조건: 끝난 일마다 전체 생활 태도를 평가 반례: 누가 먼저 잘못했는지나 실제 반복 갈등을 source만으로 판정하지 않는다.
- cmpr:material:CH07.P3:budget-permission-loop: 공동생활비를 묻다가 모든 개인 선택을 허가하면 질문의 목적이 달라진다. 조건: 투명성 명목으로 개인 선택을 계속 심사 반례: 실제 경제적 통제는 양쪽 소통 문제라는 설명으로 축소하지 않는다.
- cmpr:material:CH07.P3:care-manager-loop: 시키면 한다는 말에는 무엇을 시킬지 기억하는 사람이 남아 있다. 조건: A는 기억하고 B는 요청받은 순간만 돕는 구조를 당연시 반례: 이미 불공평한 분담이 있었다고 추정하거나 책임을 성별로 배정하지 않는다.
