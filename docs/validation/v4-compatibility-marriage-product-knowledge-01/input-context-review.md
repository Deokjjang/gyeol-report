28개 시나리오, Q/R/S/T 각2변형으로 총32결과다. 기준 SHA archive와 새 worktree에서 동일하게 생성했다. case-digest-preservation.json의 계산/fullEvidence/narrative/integration/personA/personB/Book 일곱 digest가 전부 일치한다.

A 양쪽 유형, B A만, C B만, D 양쪽 미상, E/F 각 시간 미상, G 양쪽 시간 확정, H 동일 유형, I 다른 유형의 기존 안전 계약을 확인했다. J 합, K 충, L 둘 다는 실제 관계 kind·refs로 검증했다. M은 교차 branch 근거 없음, N은 미지원 원진 정의만 참조하되 실제 관계를 만들지 않는 사례다. N은 정의를 실제 계산 입력에 추가한 사례가 아니다.

O 실제 AB/BA 십성 다름, P 같음을 검증했다. Q 전체 역할 교환은 개인 digest와 방향을 뒤집고 실제 refs의 슬롯을 대응시켰다. R 이름만 교환은 개인 digest/십성을 유지하지만 person ID는 바뀐다. S A의 MBTI만 변경하면 계산 digest와 B 개인 digest는 같고 A 개인 digest는 다르다. T 카테고리만 love→marriage로 바꾸면 양쪽 개인·관계·방향은 같고 원고는 다르다.

U 실제 상태 미확인, V/W/X/Y/Z의 돈·가사·가족·근무/소득 변화·갈등 맥락은 별도 hypotheticalContext다. 실제 payload에 없는 필드를 넣지 않았다. 이 사례의 현재 생성 결과가 같다는 것은 입력 계약을 보존했다는 뜻이며 새 장면이 실제 binding됐다는 뜻은 아니다.

AA는 실제 원천/관계가 풍부한 입력이지 행복·생활 능력이 확인된 사람이 아니다. AB는 기존 fallback 재현이다. M/N/AB 모두 reader draft 9장36문단, hard error0, shortage0이나 REPEATED_LONG_PHRASE Major로 이전 edition을 선택한다. BODY_LENGTH는 진단이며 이 자체가 fallback gate는 아니다.

새 연구 후보가 생성기에 연결되지 않았으므로 이 실행은 새 원고의 판매 품질 평가가 아니다. 112개 의미의 독해·출처·조건 검토는 materials-review.md와 human-review.md에 별도로 남겼다.
