CH02/03은 개인별 독립적인 생활 필요, CH05/06은 실제 수신자 관점의 도움·남은 비용, CH07은 반복되는 조건의 순서, CH08은 완료 기준·동의·권한·준비·확인·다시 볼 때를 정하는 절차다. 같은 책임 주제라도 각 문단이 전달하는 정보가 다르다.

예: A의 일방 예산(CH05.P3)은 A의 편의가 B의 선택권을 줄이는 조건이다. 허락 반복(CH07.P3)은 확인→결정권 독점→응답 위축의 반복 조건이다. A 조정(CH08.P2)은 확정 전 수정 항목과 답할 시간을 B에게 남기는 행동이다. 공동 재정 합의(CH08.P4)는 공동/개인 항목·공개 범위·검토 계기를 장기 규칙으로 정한다. CH09.P3은 실제 도입된 이 의미만 회수한다. 서로 독립적인 계산 사실 네 개로 세지 않는다.

보이지 않는 일: 필요를 알아차림, 준비, 실행, 결과 확인, 예외, 다음 발생 기억을 구분했다. 실행 횟수나 타입만으로 공평함을 판정하지 않는다. 책임을 맡기려면 정보·권한·가능한 시간도 있어야 한다.

가족: 요청의 출처와 두 사람의 수용 결정은 다르다. 가족 성격을 꾸미지 않고 시간·비용·정보를 외부에 약속하기 전 동의 범위만 질문한다. 자녀나 양육 사실은 새로 만들지 않는다.

긍정: 공통 예산 관심, 세심함, 자율성은 각각 수정 권한, 완결 책임, 공동 유지 조건이 있을 때의 가능성이다. 위험을 줄였다고 행복·성공을 보장하지 않는다. 반전은 더 엄격한 관리가 아닌 수정 가능한 기준, 더 많은 도움 대신 끝까지 맡는 책임, 모든 공개 대신 동의한 정보 경계처럼 실제 선택 구조의 차이를 제공한다.

안전: 통제·폭력은 취향 차이로 정당화하지 않는다. 공동 조율 질문을 가해·피해의 같은 책임으로 읽지 않으며 강제 화해·동거를 요구하지 않는다.

수량 한계를 임의로 정한 것은 아니다. 이번에 근거와 조건을 독립적으로 서술할 수 있었던 112개를 등록했으며 자료가 없는 방향·source context·실제 생활 사실은 아래 보류 목록에 남긴다. 고객 적용 승인·판매 품질 승인은 아님.
