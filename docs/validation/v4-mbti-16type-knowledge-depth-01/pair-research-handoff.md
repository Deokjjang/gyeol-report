# MBTI 페어 연구 인수 — 실행하지 않음

현재 작업은 개인 16유형의 256영역 조건부 자료만 추가했다. 다음 과제를 자동 시작하지 않는다.

- 원천 관계 정보는 원본 relationshipHints, comfortableTypes, challengingTypes, notablePairs 그대로다. pair-inventory.json은 256방향의 원문 경로·양방향 명칭·reportLine·coverage·hash를 제공한다.
- direct158/inferred98은 원천 범위 표지다. 원문 계보·실증 근거를 입증하지 않는다.
- label 차이148방향, 역방향 같은 문구40방향, 이름 없는 일반 reportLine72방향을 우선 확인할 수 있다. 모든 페어에 길이가 있다고 상세 출처가 있는 것은 아니다.
- Socionics 계열 관계명과 MBTI 입력을 임의 동치화하지 않는다. 명칭의 번역 차이, 서로 다른 분류 모형, 실제 의미 충돌을 구분할 자료가 필요하다.
- 설명이 대칭이어야 한다고 가정하지 않는다. 양쪽 입장의 필요·행동·조건을 독립적으로 추적한다. 개인 자료에서 상대의 실제 행동·결과를 만들어내지 않는다.
- 현재 신규 비교는 개인 trait의 유사점·조건 차이이며 페어 궁합의 증거가 아니다. 기존 개인 점수나 관계 점수에 합산하지 않는다.
- 전문 상품 DB·Fusion·의미 축·후보 선택·Book·DB·Production 연결은 포함되지 않는다.
