# 의미 자료 직접 읽기

새 자료는 고객 사실·실증 성격·새 계산 결과가 아닌 조건부 편집 연구다. 정의와 반례를 함께 읽는다.

109개 하위 개념은 36축을 세분한 것이며 109개의 독립 근거가 아니다. 축별 2~4개는 개수 목표가 아니라 아래 행동 차이로 정했다. CHARISMA/STATUS_DRIVE는 확인할 수 없는 새 차이를 늘리지 않고 각각 2개로 제한했다. PRECISION/CARE/BOUNDARY는 각기 다른 대상과 동의를 분리해 4개씩 작성했다.

모든 facet의 상품·관계 적용은 부모 축의 서로 다른 질문과 그 facet의 고유 조건의 교집합이다. 각 질문을 복제해 별도 전문 해석으로 세지 않는다. 반전·반례는 부모 축 참조이며 신규 109개로 다시 세지 않는다.

## ACTION_TEMPO (bipolar)

기존 정의 보존: {"positive":"결론이 나면 빠르게 움직이는 쪽","negative":"충분히 보고 생각한 뒤 움직이는 쪽"}

- 정의: 판단 뒤 행동을 시작하기까지의 상대적 속도
- INITIATIVE와 차이: 누가 먼저 제안하는지와 얼마나 빨리 착수하는지는 다르다
- 행동 후보: 결론 뒤 첫 단계를 언제 할지 알림
- 긍정: 빠른 시험으로 피드백을 얻거나 검토 시간으로 재작업을 줄임
- 과용 위험: 상대의 준비를 생략하거나 검토 종료를 알리지 않음
- 약한 신호의 한계: 느림은 능력 부족이 아니며 시급한 역할 때문에 빨라질 수도 있음
- 반전: 일찍 정한 검토 시간이 오히려 실제 착수를 앞당길 수 있음
- 환경: 안전 검토가 필요한 일과 되돌릴 수 있는 실험을 구분
- 공존: PRECISION — 검토 항목을 정한 뒤 신속히 움직일 수 있음
- 긴장: DUTY — 기한과 검토 요구가 충돌하면 중간 공유가 필요
- 반례: 위기 때의 빠름을 평소 속도로 일반화하지 않음
- 가상 장면: 가상으로 회의 후 오늘 할 시험과 내일 검토를 나누는 상황
- 반려할 단정: “느린 사람은 실행력이 없다”

|---|---|---|---|---|---|
| start-latency | 결론과 첫 행동 사이의 간격 | 작은 첫 단계의 시점을 알리면 기다리는 비용을 줄임 | 빠름만 요구하면 필요한 준비가 사라짐 | 결론이 실제로 난 뒤의 간격을 비교 | DECISION_STYLE |
| review-window | 행동 전 검토 시간을 배정 | 확인 항목과 끝낼 시점을 정해 재작업을 줄임 | 검토 종료가 없으면 착수가 계속 밀림 | 오류 비용과 기한이 모두 주어진 상황 | PRECISION |
| paced-handoff | 자기 착수와 타인의 준비 속도를 조정 | 인계 가능한 작은 결과부터 공유 | 상대가 준비됐다고 추측하며 일을 넘김 | 공동 과제의 의존 단계가 있을 때 | LEADERSHIP |

- comprehensive: 결정 뒤 착수 간격이 다른 특성과 어떻게 맞물리는가?
- career: 마감과 검토 비용 사이 첫 작업은 언제 가능한가?
- love: 호감 표현을 시작할 시점과 상대 준비가 맞는가?
- compatibility: 두 사람의 착수 속도 차이는 어떤 대기 비용을 만드는가?
- major_fortune: 장기 전환에서 시험과 검토의 순서를 어떻게 나눌까?
- annual_fortune: 월별 기한 안에서 되돌릴 작은 행동은 무엇인가?

관계 질문:

- love: 데이트 제안에 답할 시간을 어떻게 알릴까?
- marriage: 생활 수리의 착수 시점은 누가 합의할까?
- parentChild: 아이의 준비 시간을 기다릴 수 있는 과제인가?
- coworker: 공동 작업의 첫 산출물은 언제 주고받을까?
- managerReport: 지시 뒤 검토 시간과 착수 기한을 구분했는가?
- businessPartner: 공동 투자 전 검토 기간과 실행일을 합의했는가?
- friendship: 만남 제안에 즉답하지 않아도 약속을 유지할 수 있는가?

## ENERGY_DIRECTION (bipolar)

기존 정의 보존: {"positive":"생각과 에너지를 밖으로 표현하는 쪽","negative":"생각과 에너지를 안에서 정리하는 쪽"}

- 정의: 생각과 에너지를 안에서 정리하거나 밖으로 드러내는 상대적 방향
- RELATION_STYLE와 차이: 표현 방향과 사람에게 얼마나 가까이 다가가는지는 같지 않다
- 행동 후보: 혼자 초안을 쓰거나 대화 중 생각을 정리
- 긍정: 사적 숙고와 공개 교환의 통로를 선택
- 과용 위험: 침묵을 거절로 읽거나 모든 생각을 즉시 공개
- 약한 신호의 한계: 내향 방향은 외로움·사회성 부족의 증거가 아님
- 반전: 밖에서 활발히 말해도 중요한 결정은 혼자 검토할 수 있음
- 환경: 공개 발표와 친한 사람과의 대화에서 다르게 나타남
- 공존: EXPRESSION — 안에서 정리한 내용을 작품으로 활발히 표현할 수 있음
- 긴장: SOCIAL_ATTUNEMENT — 응답을 기대하는 사람과 정리 시간이 어긋날 수 있음
- 반례: 직업상 발표량만으로 사적 에너지 방향을 정하지 않음
- 가상 장면: 가상으로 발표 전 혼자 쓴 메모를 소규모 모임에서 공유
- 반려할 단정: “말수가 적으면 타인에게 관심이 없다”

|---|---|---|---|---|---|
| private-processing | 생각을 먼저 사적으로 정리 | 초안으로 의견을 정돈한 뒤 나눔 | 정리 시간이 침묵의 무기한 연장으로 변함 | 혼자 정리할 접근성과 응답 기한 확인 | RECOVERY_NEED |
| dialogic-processing | 대화 속에서 생각을 발전 | 미완성 생각임을 알리고 피드백을 받음 | 탐색 발언이 확정 약속으로 전달됨 | 대화 상대가 참여에 동의할 때 | EXPRESSION |
| channel-switch | 장면에 따른 정리 통로의 전환 | 발표와 사적 대화의 차이를 설명 | 공적 역할을 사적 성격으로 일반화 | 여러 장면의 실제 관찰이 있을 때 | RELATION_STYLE |

상품 질문:

- comprehensive: 안에서 정리하는 시간과 밖에서 교환하는 때는 어떻게 다른가?
- career: 발표 전 혼자 준비할 시간과 협의 시간을 확보했는가?
- love: 애정은 사적 정리와 공개 표현 중 어디서 편해지는가?
- compatibility: 겉의 활동량과 안의 처리 방향을 구별했는가?
- major_fortune: 역할이 바뀌어도 필요한 정리 통로는 무엇인가?
- annual_fortune: 이번 달 공개 활동 뒤 정리 여백을 둘 수 있는가?

관계 질문:

- love: 대화 후 혼자 생각하는 시간을 어떻게 설명할까?
- marriage: 같은 집에서 사적 정리와 함께 대화를 배분할까?
- parentChild: 말을 바로 요구하기 전에 아이의 처리 시간을 보장했는가?
- coworker: 회의 전 문서와 현장 토론 중 어떤 통로가 필요한가?
- managerReport: 공개 발언을 역량 평가로 오인하지 않는가?
- businessPartner: 협상 전 각자의 검토와 공동 논의가 모두 있는가?
- friendship: 모임 참여와 사적 휴식 중 무엇을 요청하는가?

## STRUCTURE_STYLE (bipolar)

기존 정의 보존: {"positive":"기준과 계획을 정해놓고 움직이는 쪽","negative":"상황을 보며 방법을 바꾸는 쪽"}

- 정의: 기준·계획을 먼저 정하거나 상황에 맞춰 방식을 여는 상대적 선호
- STABILITY와 차이: 계획의 형식과 안정된 결과를 원하는 이유는 다르다
- 행동 후보: 필수 절차와 바꿔도 되는 방법을 표시
- 긍정: 예측 가능한 협업과 상황 적응의 범위를 함께 확보
- 과용 위험: 계획을 목적처럼 지키거나 변경 영향을 남기지 않음
- 약한 신호의 한계: 유연함은 무책임이 아니며 절차를 못 세운다는 뜻도 아님
- 반전: 유연하게 운영하려고 최소 규칙을 먼저 정할 수 있음
- 환경: 표준 작업과 탐색 과제의 요구가 다름
- 공존: ADAPTABILITY — 핵심 기준은 유지하며 수행 방법을 바꿀 수 있음
- 긴장: CREATION — 새 결과물 탐색에 기존 양식이 과도하게 적용될 수 있음
- 반례: 법적 필수 절차는 취향으로 선택할 수 없음
- 가상 장면: 가상으로 팀 일정의 마감은 고정하고 실험 순서는 바꿈
- 반려할 단정: “계획이 적으면 성실하지 않다”

|---|---|---|---|---|---|
| fixed-minimum | 반드시 지킬 최소 절차를 선택 | 필수 규칙을 분명히 해 협업 비용 감소 | 선호하는 양식까지 의무로 만듦 | 법·안전상 필수와 취향을 분리 | DUTY |
| flexible-method | 목적 안에서 방법을 열어둠 | 현장 정보를 반영해 수행을 조정 | 변경이 다른 사람에게 알려지지 않음 | 결과 기준과 변경 권한이 확인될 때 | ADAPTABILITY |
| change-log | 계획 변경을 서로 확인 가능한 기록으로 남김 | 이전 합의와 수정 이유를 연결 | 기록 절차가 불필요한 승인 단계로 커짐 | 공동 일정이나 담당이 바뀔 때 | PRECISION |

상품 질문:

- comprehensive: 계획 선호와 상황 대응은 어떤 조건에서 바뀌는가?
- career: 반복 운영과 탐색 업무에 같은 절차가 필요한가?
- love: 관계의 약속과 즉흥적인 즐거움은 어디서 조율할까?
- compatibility: 서로 다른 계획 수준을 어떤 합의로 연결할까?
- major_fortune: 장기 배경 변화 때 유지할 기준과 바꿀 절차는 무엇인가?
- annual_fortune: 달라진 조건에 일정표를 갱신할 필요가 있는가?

관계 질문:

- love: 데이트 계획에서 필수 약속과 즉흥 구간은 무엇인가?
- marriage: 가사 일정의 고정 항목과 예외를 구분했는가?
- parentChild: 발달 단계에 맞는 일과와 선택 여지를 남겼는가?
- coworker: 공유 일정의 고정 기한과 개인 방법을 나눴는가?
- managerReport: 평가 기준은 고정하되 수행 방법의 재량을 주는가?
- businessPartner: 운영 규칙을 바꿀 승인 절차가 있는가?
- friendship: 정기 만남과 즉흥 연락을 서로 강요하지 않는가?

## COMMUNICATION_STYLE (bipolar)

기존 정의 보존: {"positive":"핵심을 비교적 바로 말하는 쪽","negative":"상대와 상황을 보며 부드럽게 말하는 쪽"}

- 정의: 핵심을 바로 말하거나 맥락과 관계를 거쳐 전달하는 상대적 방식
- CARE와 차이: 직설성과 배려의 유무는 별개다
- 행동 후보: 요청·사실·해석을 구분해 표현
- 긍정: 명료한 합의 또는 관계에 맞춘 전달
- 과용 위험: 명료함을 무례의 허가로 삼거나 완곡함에 요청을 숨김
- 약한 신호의 한계: 간접 표현은 거짓말이나 판단 능력 부족이 아님
- 반전: 부드럽게 말해도 거절은 분명할 수 있음
- 환경: 공개 피드백과 사적 위로에 필요한 전달 방식이 다름
- 공존: BOUNDARY — 표현은 완곡해도 거절할 항목은 명확할 수 있음
- 긴장: SOCIAL_ATTUNEMENT — 즉시 고칠 오류와 상대가 받아들일 맥락을 함께 봄
- 반례: 언어 숙련·권력 차이 때문에 말하기가 달라질 수 있음
- 가상 장면: 가상으로 동료에게 관찰한 오류와 요청을 따로 말함
- 반려할 단정: “직설적인 사람은 공감하지 못한다”

|---|---|---|---|---|---|
| direct-request | 원하는 행동을 명시 | 상대가 요청의 범위를 알 수 있음 | 요청을 명령처럼 전달 | 거절 가능한 실제 선택권이 있을 때 | BOUNDARY |
| contextual-delivery | 맥락과 관계를 고려해 전달 | 공개 망신 없이 수정점을 나눔 | 배경 설명에 핵심 요청이 가려짐 | 민감한 피드백의 장소와 수신자 확인 | SOCIAL_ATTUNEMENT |
| intent-check | 표현과 이해된 뜻을 다시 확인 | 서로 다르게 읽은 부분을 수정 | 상대에게 내 의도를 수용하도록 강요 | 해석 차이를 당사자가 확인할 때 | CARE |

- love: 이견과 애정 요청이 상대에게 알아듣게 전달되는가?
- compatibility: 직설·완곡 차이가 실제 뜻의 차이인가?
- major_fortune: 오래된 소통 방식이 새 역할에도 적합한가?
- annual_fortune: 민감한 협의에 메시지와 대면 중 무엇이 맞는가?

관계 질문:

- love: 거절과 호감을 추측에 맡기지 않았는가?
- marriage: 돈과 가사 이견의 요청을 분명히 했는가?
- parentChild: 아이의 이해 수준에 맞게 요청을 설명하는가?

## CHANGE_ORIENTATION (bipolar)

## INITIATIVE (strength)

- 정의: 외부 지시 전에 시작점을 만드는 성향 후보
- LEADERSHIP와 차이: 먼저 시작해도 타인을 지휘할 권한은 없다
- 행동 후보: 작은 제안과 첫 단계를 자발적으로 제시
- 긍정: 정체된 일을 시작하고 도움 요청을 구체화
- 과용 위험: 상대의 동의 없이 공동 일을 시작
- 약한 신호의 한계: 신호가 작으면 주어진 역할을 잘 수행하는지 별도 확인
- 반전: 도움을 먼저 요청하는 것도 시작점을 만드는 행동
- 환경: 재량이 허용된 일에서만 자발적 시작을 평가
- 공존: GOAL_DRIVE — 시작 제안을 합의된 목표에 연결할 수 있음
- 긴장: BOUNDARY — 타인의 담당 영역에 선제 개입할 수 있음
- 반례: 권한이 없어 기다린 행동을 소극성으로 보지 않음

## GOAL_DRIVE (strength)

기존 정의 보존: 목표가 생기면 끝까지 가고 싶어 하는 성향

- 정의: 목표를 향해 자원과 행동을 모으려는 성향 후보
- PERSISTENCE와 차이: 목적 달성의 추동과 같은 행동을 오래 반복하는 것은 다르다
- 행동 후보: 중간 결과를 목표와 비교해 우선순위를 조정
- 긍정: 중요한 일에 집중하고 진행을 구체화
- 과용 위험: 목표 밖 필요나 중단 신호를 무시
- 약한 신호의 한계: 신호 부족은 삶의 목표나 의지가 없다는 뜻이 아님
- 반전: 목표를 지키려면 덜 중요한 일을 포기해야 할 수 있음
- 환경: 자기 목표와 조직이 부과한 목표를 구분
- 공존: STRATEGY — 경로를 바꾸어도 목적은 유지할 수 있음
- 긴장: RECOVERY_NEED — 쉬어야 할 때까지 목표 압박이 이어질 수 있음
- 반례: 성과 결과를 의지의 크기로만 설명하지 않음
- 가상 장면: 가상으로 마감 전 필수 작업과 미룰 작업을 나눔
- 반려할 단정: “목표 의지가 강하면 성공이 보장된다”

## EXPANSION (strength)

기존 정의 보존: 지금보다 더 키우고 넓히고 싶어 하는 성향

- 정의: 범위·규모·연결을 넓히려는 성향 후보

- 과용 위험: 확장 속도가 관리 자원보다 앞섬

- 긴장: RESOURCE_SENSE — 관심 영역의 증가가 자원 분산을 만들 수 있음

## PERSISTENCE (strength)

기존 정의 보존: 한번 시작한 것을 오래 붙드는 성향

- 정의: 선택한 과제나 관계를 일정 기간 유지하는 성향 후보
- STABILITY와 차이: 유지하는 노력과 안정 상태를 원하는 선호는 다르다
- 행동 후보: 진행이 느려도 반복 기준을 정해 이어감
- 긍정: 축적이 필요한 과제에서 중단 없는 개선
- 과용 위험: 효과가 없는 경로를 투입 비용 때문에 계속함
- 약한 신호의 한계: 신호 부족을 끈기 부족으로 바꾸지 않음
- 반전: 그만둘 조건을 정하면 필요한 일은 더 오래 지속 가능
- 환경: 지연 보상이 있지만 피드백을 확인할 수 있는 상황
- 공존: LEARNING — 반복 연습에 피드백을 반영할 수 있음
- 긴장: ADAPTABILITY — 지속할 목적과 바꿀 방법을 혼동할 수 있음
- 반례: 중단에는 자원·건강·권한 등 정당한 이유가 있음
- 가상 장면: 가상으로 연습 기록을 남기며 한 달 뒤 방법을 재검토
- 반려할 단정: “오래 버티면 어떤 일도 해결된다”

## DEPTH (strength)

기존 정의 보존: 겉만 보고 넘기지 않고 깊게 생각하는 성향

- 정의: 한 문제의 맥락과 원인을 층위 있게 탐색하는 성향 후보

- 행동 후보: 표면 결과 뒤의 과정과 예외를 추적
- 긍정: 복잡한 문제를 성급히 축약하지 않음
- 과용 위험: 설명이 계속 깊어지며 전달·결정 시점을 놓침
- 약한 신호의 한계: 신호가 적다고 사고가 얕거나 지능이 낮은 것은 아님
- 반전: 짧은 답을 만들기 위해 먼저 깊게 검토할 수 있음
- 환경: 추가 탐색이 실제 판단을 바꾸는 상황
- 공존: PRECISION — 원인의 범위와 자료 오류를 함께 점검
- 긴장: DECISION_STYLE — 더 볼 맥락과 닫아야 할 선택의 비용이 다름
- 반례: 깊은 생각과 반추·고통은 자동 동치가 아님
- 가상 장면: 가상으로 반복 오류의 표면 수정과 원인 조사를 나눔
- 반려할 단정: “깊이 축이 높으면 지능이 높다”

## PATTERN_SENSE (strength)

기존 정의 보존: 서로 떨어진 정보에서 연결과 반복을 보는 성향

- 정의: 떨어진 정보의 반복·연결을 찾아 비교하는 성향 후보

- 과용 위험: 우연한 반복에 인과·예측 의미를 붙임

## STRATEGY (strength)

기존 정의 보존: 지금뿐 아니라 다음 수까지 생각하는 성향

- 정의: 목적·경로·제약·다음 선택을 함께 배치하는 성향 후보
- STRUCTURE_STYLE와 차이: 계획을 선호하는 방식과 경로를 비교하는 내용은 다르다
- 행동 후보: 여러 경로와 실패 시 대안을 검토
- 긍정: 자원을 중요한 순서에 배치
- 과용 위험: 사람과 휴식을 수단처럼 다루거나 계획만 늘림
- 약한 신호의 한계: 근거가 없으면 즉흥적·비전이 없다고 단정 불가
- 반전: 예비 경로가 있으면 현재 선택에 더 집중 가능
- 환경: 목적과 제한 자원이 명시된 상황
- 공존: PRACTICALITY — 실행 가능성을 확인하며 장기 경로를 세움
- 긴장: CARE — 효율의 명분이 상대 선택을 지울 수 있음
- 반례: 계획이 있다는 사실은 미래 결과의 증거가 아님
- 가상 장면: 가상으로 프로젝트의 주 경로와 중단 시 대안을 작성
- 반려할 단정: “전략적이면 타인을 조종한다”

|---|---|---|---|---|---|
| route-comparison | 목적에 이르는 여러 경로를 비교 | 한 가지 방법의 실패에 대비 | 비교만 하며 실행 비용을 누락 | 목적·자원·기한이 명시된 상황 | DECISION_STYLE |

## CREATION (strength)

기존 정의 보존: 생각을 실제 결과물로 만들고 싶어 하는 성향

- 정의: 생각을 외부에서 확인 가능한 새 결과물로 만드는 성향 후보
- EXPRESSION와 차이: 새 산출의 생성과 기존 생각을 전달하는 것은 다르다
- 행동 후보: 초안·시제품·작업물을 실제로 만들기
- 긍정: 머릿속 가능성을 시험 가능한 형태로 전환
- 과용 위험: 만드는 재미가 목적·사용자의 필요를 덮음

- 반전: 제약이 분명할 때 결과물이 더 독창적일 수 있음

- 긴장: PRECISION — 초기 초안에 완성본 수준 검증을 요구할 수 있음
- 반례: 예술 직업·재능·저작 성과를 자동 판정하지 않음
- 가상 장면: 가상으로 아이디어를 한 장짜리 시제품으로 만들어 확인
- 반려할 단정: “창작 신호가 있으면 예술가가 적성이다”

## EXPRESSION (strength)

기존 정의 보존: 생각과 감정을 밖으로 보여주려는 성향

- 행동 후보: 말·글·행동 중 전달 통로를 선택
- 긍정: 뜻을 확인 가능하게 하여 오해를 줄임

- 긴장: CARE — 도움의 뜻이 드러나지 않으면 상대가 알아차리지 못함
- 반례: 표현 신호를 언어·창작 능력의 측정치로 보지 않음

- 반려할 단정: “표현 신호가 작으면 애정이 없다”

## SOCIAL_ATTUNEMENT (strength)

기존 정의 보존: 사람의 표정과 반응을 빨리 알아차리는 성향

- 정의: 타인의 반응과 사회적 맥락을 살피는 성향 후보
- CARE와 차이: 반응을 알아차림과 도움을 제공할 의사는 별개다
- 행동 후보: 관찰한 신호를 질문으로 확인
- 긍정: 전달 방식과 참여 조건을 상황에 맞춤
- 과용 위험: 타인의 마음을 추측하고 자기 요구를 계속 지움
- 약한 신호의 한계: 신호가 약하면 공감 결여라고 말할 수 없음
- 반전: 상대 반응을 잘 살필수록 추측을 확인하는 질문이 중요
- 환경: 표정·말의 정보가 제한된 온라인에서는 추가 확인
- 공존: BOUNDARY — 상대의 반응을 이해해도 자신의 한계를 말할 수 있음
- 긴장: AUTONOMY — 평가를 지나치게 따라 선택 기준을 잃을 수 있음
- 반례: 표정 하나에서 감정·동의를 확정하지 않음
- 가상 장면: 가상으로 회의에서 침묵한 사람에게 의견을 선택적으로 묻기
- 반려할 단정: “상대 마음을 정확히 읽는다”

- 긴장: RESOURCE_SENSE — 남을 돕는 비용과 자신의 지속 가능성이 충돌
- 반례: 성별·유형에 돌봄 책임을 자동 부여하지 않음
- 가상 장면: 가상으로 지친 동료에게 조언과 실무 도움 중 원하는 것을 묻기
- 반려할 단정: “배려 신호가 강하면 모두를 돌봐야 한다”

## CHARISMA (strength)

기존 정의 보존: 사람 눈에 들어오고 기억되는 존재감

- 정의: 타인의 시선과 기억에 남는 존재감이라는 해석 후보
- STATUS_DRIVE와 차이: 눈에 띄는 현상과 인정받고 싶은 동기는 다르다
- 행동 후보: 상대가 실제로 주목한 표현·상황을 확인
- 긍정: 전달에 관심을 모아 참여 통로를 만들 수 있음
- 과용 위험: 관심을 유지하려 과도한 노출이나 역할 수행
- 약한 신호의 한계: 신호 부족은 매력이나 인간적 가치가 낮다는 뜻 아님
- 반전: 조용하고 일관된 태도도 특정 상황에서 기억에 남을 수 있음
- 환경: 실제 관찰자·매체·문화와 장면이 필요
- 공존: EXPRESSION — 표현이 구체적일 때 관심이 전달 내용으로 이어짐
- 긴장: BOUNDARY — 주목을 기대하는 환경이 사적 경계를 침범
- 반례: 타인의 호감·연애 성공을 존재감으로 예측하지 않음
- 가상 장면: 가상으로 발표의 특정 사례가 청중에게 기억되는 상황
- 반려할 단정: “매력 신호가 있으면 누구나 좋아한다”

## DUTY (strength)

기존 정의 보존: 맡은 일과 약속을 책임지려는 성향

- 정의: 맡은 역할과 합의한 약속을 이행하려는 성향 후보
- PERSISTENCE와 차이: 책임의 대상과 단순한 지속 행동은 다르다
- 행동 후보: 담당·기한·못 할 범위를 명확히 알림
- 긍정: 협업의 예측 가능성과 신뢰를 유지
- 과용 위험: 동의하지 않은 일까지 자기 책임으로 떠안음
- 약한 신호의 한계: 신호가 작아도 실제 약속 이행은 확인해야 함
- 반전: 책임의 범위를 줄여 말하는 것이 더 책임 있는 행동일 수 있음
- 환경: 역할·권한·인수인계가 확인된 상황
- 공존: BOUNDARY — 자기 담당과 타인 담당을 구분하며 이행
- 긴장: RECOVERY_NEED — 끝없는 의무감이 쉬는 조건을 지울 수 있음
- 반례: 권한 없는 일의 실패를 개인 책임으로 환원하지 않음
- 가상 장면: 가상으로 휴가 전 담당 업무와 대체 담당을 명시
- 반려할 단정: “책임감이 강하면 모든 일을 맡아야 한다”

## LEADERSHIP (strength)

기존 정의 보존: 방향을 정하고 사람을 이끄려는 성향

- 정의: 공동 방향과 조율을 이끌려는 성향 후보
- INITIATIVE와 차이: 혼자 먼저 시작함과 공동 의사결정을 이끄는 것은 다르다
- 행동 후보: 목적·역할을 제안하고 이견을 들을 통로 확보
- 긍정: 분산된 행동을 공동 목표에 연결
- 과용 위험: 합의를 대신해 상대 결정을 일방적으로 정함
- 약한 신호의 한계: 신호 부족은 지도 능력이나 가치의 부족이 아님
- 반전: 스스로 물러나 다른 사람의 판단 공간을 여는 것도 조율
- 환경: 실제 권한과 참여자의 동의가 필요한 환경
- 공존: CARE — 부담을 확인하며 방향을 조율할 수 있음
- 긴장: AUTONOMY — 공동 방향과 개인 재량의 경계가 충돌
- 반례: 관계명·십성으로 상사나 부모 역할을 배정하지 않음
- 가상 장면: 가상으로 모임 계획의 결정권과 반대 의견을 먼저 확인
- 반려할 단정: “리더십 신호가 있으면 지휘할 권리가 있다”

## AUTONOMY (strength)

기존 정의 보존: 중요한 것은 직접 고르고 결정하고 싶은 성향

- 정의: 중요한 선택을 자신의 기준과 권한으로 정하려는 성향 후보

- 행동 후보: 선택 가능한 범위와 협의할 범위를 구분
- 긍정: 자기 판단을 세우며 공동 책임에 동의
- 과용 위험: 공동 영향이 있는 선택까지 단독으로 정함
- 약한 신호의 한계: 약한 신호로 의존적·판단력이 없다고 말할 수 없음
- 반전: 도움받을 방법을 직접 고르는 것도 자율성
- 환경: 선택권과 실제 제약을 분리해 확인할 때
- 공존: CARE — 도움의 수용·거절을 자기 기준으로 선택
- 긴장: DUTY — 개인 선택이 공동 약속과 충돌할 수 있음
- 반례: 권력에 막힌 선택을 성향의 문제로 보지 않음
- 가상 장면: 가상으로 협업 결과는 합의하되 수행 방법은 맡기는 상황
- 반려할 단정: “독립적이면 타인의 도움이 필요 없다”

## STABILITY (strength)

기존 정의 보존: 오래 유지되고 안정적인 상태를 중요하게 보는 성향

- 정의: 예측 가능하고 오래 유지되는 상태를 중시하는 성향 후보
- STRUCTURE_STYLE와 차이: 안정된 결과를 바라면서 방법은 유연할 수 있다
- 행동 후보: 안정에 필요한 최소 조건을 명시
- 긍정: 생활·협업의 불필요한 변동을 줄임
- 과용 위험: 손상된 상태를 익숙하다는 이유로 계속 유지
- 약한 신호의 한계: 약한 신호는 불안정한 인격의 증거가 아님
- 반전: 일부 변화를 받아들여야 장기 안정이 가능할 수 있음
- 환경: 유지할 가치와 실제 안전이 구분된 상황
- 공존: ADAPTABILITY — 핵심 안정 조건을 지키기 위해 방법을 변경
- 긴장: EXPANSION — 범위 증가가 유지 가능성을 흔들 수 있음
- 반례: 결혼 지속·직장 보장·건강 안전을 예언하지 않음
- 가상 장면: 가상으로 변경 전 반드시 유지할 생활 조건을 적음
- 반려할 단정: “안정 신호가 크면 관계가 오래간다”

| 하위 개념 | 새로운 정보/대상 | 긍정 행동 | 위험 | 적용 조건 | 구별 축 |

## STATUS_DRIVE (strength)

기존 정의 보존: 인정, 명예, 높은 직책을 중요하게 보는 성향

- 정의: 인정·명예·공식 위치를 중요하게 여기는 성향 후보
- CHARISMA와 차이: 주목받는 현상과 인정받으려는 동기는 다르다
- 행동 후보: 인정받고 싶은 기여와 평가 기준을 확인
- 긍정: 성과를 설명하고 역할에 필요한 책임을 배움
- 과용 위험: 외부 평가가 자기 가치의 유일한 기준이 됨
- 약한 신호의 한계: 신호 부족은 야망·성취 동기가 없다는 뜻 아님
- 반전: 공식 직함보다 구체적 기여의 인정이 더 중요할 수 있음
- 환경: 평가 권한·공정성·경력 맥락이 필요
- 공존: DUTY — 공식 역할에 따른 책임을 구체화할 수 있음
- 긴장: AUTONOMY — 인정의 기준을 따르다 자기 선택을 잃을 수 있음
- 반례: 직급·승진·명예의 실제 획득을 예측하지 않음
- 가상 장면: 가상으로 평가 면담에서 맡은 기여와 원하는 역할을 설명
- 반려할 단정: “인정 욕구가 강하면 높은 자리에 오른다”

## MEANING (strength)

기존 정의 보존: 돈이나 결과뿐 아니라 왜 하는지도 중요하게 보는 성향

- 정의: 행동과 선택의 이유·가치를 확인하려는 성향 후보

- 과용 위험: 모든 작은 일에 완전한 이유를 요구해 시작을 막음
- 약한 신호의 한계: 신호 부족을 가치관·삶의 의미 부재로 해석하지 않음
- 반전: 작은 일상의 유지도 중요한 가치의 실천일 수 있음
- 환경: 개인이 말한 가치와 실제 선택 맥락이 필요
- 공존: PRACTICALITY — 가치를 실행 가능한 행동으로 옮길 수 있음
- 긴장: STATUS_DRIVE — 남의 평가와 스스로 중요하게 여기는 이유가 다를 수 있음
- 반례: 가치관·종교·도덕 수준을 원천 신호로 추정하지 않음
- 가상 장면: 가상으로 제안받은 일의 보상과 하고 싶은 이유를 따로 적음
- 반려할 단정: “의미를 찾는 사람이 도덕적으로 우월하다”

## 복합 의미와 신규 축 후보

- **검토를 배정한 신속한 시작** (PRECISION + ACTION_TEMPO): 필수 검토 항목을 미리 정하고 작은 시험을 시작할 수 있음 조건: 정확성과 빠른 실행의 신호가 같은 과제에 독립적으로 있음. 반례: 검토되지 않은 즉흥 행동은 반례. 금지: 빠르므로 꼼꼼하다는 추론 금지.
- **지속 가능한 지원** (CARE + BOUNDARY): 필요와 동의를 확인하고 가능한 지원 한도를 정함 조건: 지원 요청과 실제 여력이 확인됨. 반례: 한도를 말해도 도움을 전혀 제공하지 않을 수 있음. 금지: 돌봄을 거절했으므로 냉정하다는 판단 금지.
- **안에서 정리한 뒤 밖으로 표현** (ENERGY_DIRECTION + EXPRESSION): 사적 초안과 공개 전달을 다른 단계로 사용할 수 있음 조건: 에너지 방향과 표현 통로의 출처가 각각 있음. 반례: 직업상 발표량만으로 사적 정리를 알 수 없음. 금지: 내향이면 표현력이 약하다는 추론 금지.
- **기반을 남기는 조정** (STABILITY + ADAPTABILITY): 지켜야 할 기반과 바꿀 방법을 나눔 조건: 실제 변경 조건과 유지할 자원이 있음. 반례: 강제 변경에 따름은 자발적 적응과 다름. 금지: 안정과 적응이 상쇄된다는 처리 금지.
- **확장 속의 집중** (GOAL_DRIVE + EXPANSION): 확대할 범위와 끝낼 목표를 구분 조건: 현재 자원과 목표가 명시됨. 반례: 범위를 줄여 완수하는 선택도 가능. 금지: 크게 벌이면 목표 달성도 높다는 추론 금지.
- **위임할 수 있는 책임** (DUTY + LEADERSHIP): 역할을 분명히 하고 타인의 결정권을 남김 조건: 실제 조율 권한과 책임 범위가 확인됨. 반례: 실무 책임만 있고 위임권은 없을 수 있음. 금지: 모두 떠안는 일을 좋은 리더십으로 미화 금지.
- **질문을 연습으로 연결** (CURIOSITY + LEARNING): 관심 질문을 과제와 피드백으로 확인 조건: 실제 학습 자료와 연습 기회가 있음. 반례: 탐색만 하고 연습하지 않을 수 있음. 금지: 질문이 많으면 성적이 높다는 추론 금지.
- **직설과 상대 신호의 공존** (COMMUNICATION_STYLE + SOCIAL_ATTUNEMENT): 핵심 요청을 말하고 이해 여부를 확인 조건: 발언 내용과 실제 반응 확인의 자료가 있음. 반례: 불편을 읽어도 무시할 수 있음. 금지: 명확한 말은 항상 상처 준다는 추론 금지.
- **여력 안에서 보는 기회** (OPPORTUNITY_SENSE + RESOURCE_SENSE): 새 선택의 필요 자원과 감당 한도를 확인 조건: 기회와 자원 흐름이 각각 확인됨. 반례: 외부 제안이 있어도 실행 여력이 없을 수 있음. 금지: 기회를 보면 재물이 늘어난다는 추론 금지.
- **이유를 가진 지속** (MEANING + PERSISTENCE): 계속할 가치와 바꿀 조건을 말할 수 있음 조건: 본인의 가치 진술과 실제 지속 조건이 있음. 반례: 의무 때문에 원치 않게 지속할 수 있음. 금지: 오래 했으므로 가치 있는 일이라는 역추론 금지.
- **책임을 남기는 자율성** (AUTONOMY + DUTY): 개인 방법을 고르되 공동 약속을 갱신 조건: 선택권과 합의된 공동 역할이 확인됨. 반례: 권한 없이 책임만 떠안을 수 있음. 금지: 독립이면 협업을 싫어한다는 판단 금지.
- **제작과 회복의 배분** (CREATION + RECOVERY_NEED): 제작 구간과 쉬는 구간을 구별 조건: 실제 부하와 제작 목표가 있음. 반례: 회복 필요 신호가 현재 피로 사실은 아님. 금지: 창작자이므로 번아웃이라는 진단 금지.

신규 축 후보는 불확실성 보정과 상호성 협의 2개다. 독립성은 미입증이며 후자는 개인 축보다 관계 조건으로 두는 편이 적절할 수 있다. 권력 불균형은 개인 점수 축으로 처리하는 제안을 반려했다.
