# 의미 비교 및 정보 밀도 검토

## 검토 방법

문자열 유사도는 의미 동등성을 증명하지 않는다. 각 구분에서 행동 대상·주체·조건·관찰 가능한 차이를 비교했다. 새 축의 심리 실증이나 기존 명리의 예측 효력은 검증하지 않았다. 자료 수가 충분하다는 이유로 고객 원고 승인을 주지 않는다.

## 직접 비교한 차이

1. **PRECISION 4개**: 숫자 오타 발견, 규칙 간 일관성, 산출물 완료 수준, 설명의 논리 모순은 검토 대상·종료 기준이 다르다. 같은 검토 근거를 4개 독립 근거로 세지 않는다.
2. **CARE 4개**: 필요를 묻기, 실제 도움, 지속할 여력, 개입하지 않기로 하는 존중은 각기 다른 선택이다. 비개입이 무관심이라는 결론은 반려했다.
3. **BOUNDARY 4개**: 거절·담당 범위·사적 정보와 시간·경계 재협의의 적용 대상을 구분한다. 정확성과 같은 단어인 기준으로 합치지 않는다.
4. **DUTY/LEADERSHIP/STATUS_DRIVE**: 약속 이행·방향 조율·인정 기준은 다른 정보다. 직함 없는 책임과 책임 없는 주목을 반례로 유지했다.
5. **INITIATIVE/ACTION_TEMPO/DECISION_STYLE**: 발의자·착수 간격·대안 종료는 다른 관찰이다. 천천히 검토하는 사람이 먼저 제안할 수 있다.
6. **LEARNING/CURIOSITY/DEPTH/PATTERN_SENSE**: 연습 전이·질문 폭·원인 탐구·반복 관찰은 성적이나 지능의 대체 지표가 아니다.
7. **CHANGE_ORIENTATION/ADAPTABILITY**: 변화 선호와 실제 조건 대응을 나눴다. 바뀌는 것을 싫어해도 대응 방법은 잘 수정할 수 있다.
8. **RESOURCE_SENSE/wealth**: 관리 행동과 전통 재물 상징·실제 수입은 서로 다른 층위다.
9. **MEANING/GOAL_DRIVE**: 왜 할 가치가 있는지와 무엇을 완료할지는 다르다. 오래 한 일의 의미를 역으로 꾸며내지 않는다.
10. **RECOVERY_NEED/solitude**: 부하와 회복 여백은 내향·관계 거리·탐구 깊이와 다르다. 질병 진단을 만들지 않는다.

## 압축이 남기는 손실

16 Theme의 축 멤버십 중복은 **0**이다. 그러나 의미 중복은 있다. PRECISION_AND_STANDARDS는 동의·오류·계획·말투를 한 묶음으로, SOCIAL_ATTUNEMENT_AND_CARE는 신호 읽기·지원·연결을 한 묶음으로 압축한다. 따라서 멤버십 중복 0을 고객 의미 중복 0으로 해석하지 않는다.

`broadTheme([])`는 현재 ACTION_AND_INITIATIVE, 동률은 사전순이다. 이것은 실제 함수로 확인한 분류 동작이며 고객 원고의 모든 중복 원인을 입증한 것은 아니다. 중복 점수는 0.5 Theme +0.3 축 Jaccard +0.2 max(근거 Jaccard, family Jaccard)이며 연결 성분 그룹의 모든 문장이 동의어라는 뜻은 아니다. 반대 양극 방향을 배제하는 기존 보호도 유지된다. 이번에는 변경하지 않았다.

MBTI CARE annotation 158개와 CHARISMA 2개는 분포 차이다. CARE에 필요 감지·지원·갈등 회피·역할 이행 등이 수렴할 위험을 아래 하위 개념으로 분리했으나 빈도만으로 결함·가중치 변경을 결론 내리지 않는다. 원천의 143개 미점수 trait와 18,671 reference-only leaf는 점수 신호가 없는 이유를 보존하고 새 근거로 승격하지 않는다.

## 충분성 판단과 보류

36축 모두 정의·행동·긍정·과용·약한 신호 한계·반전·환경·공존·긴장·반례·가상 예시를 검토했다. 109개 개념의 차이는 materials-review에 공개한다. 좁은 축에 억지로 동일 개수를 채우지 않았다. 양극 방향별 세부 행동의 실증, 관계별 실제 반응, 명리의 개인 적용 조건, 신뢰도와 독립 축 검증은 보류다. 2,991개 연구 기록 전수 목록은 분류 가능성/출처 상태 감사이며 모든 원문의 새 축 대응을 승인한 작업이 아니다.

## 반려 사례

- CARE 값이 낮으니 배려가 없다: 관측 경로의 신호 약함은 반대 성격 증거가 아님
- 느리므로 실행 능력이 없다: 속도 방향과 능력은 다름
- 현침이 있으므로 정밀 분석가다: 자형 상징에서 실제 능력으로 건너뛴 추론
- wealth가 강하니 투자 수익이 난다: 행동·상징으로 금전 결과 예측 불가
- 관계 페어에 마찰이 있어 A는 배려가 없다: 상대·역할·조건이 사라진 개인 평가
- 세운 충 때문에 타고난 불안정 성격이다: 기간 관계와 원국 출처 혼동
- source direct이므로 실증적으로 검증됐다: 원천 수록 여부와 경험적 검증은 다름
- 권력 불균형을 개인 성향 축 점수로 해결한다: 권한·거절 불이익은 관계의 적용 조건으로 우선 다룸
