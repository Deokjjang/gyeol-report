# Major Specialist → 후속 Global Planner 인수 계약

상태는 **OFFLINE_IMPLEMENTED**다. 고객 Writer·Book·발행·저장본 경로에는 연결하지 않는다. 실제 연구의 rank는 null, selectionRun은 false, 승인·eligible·claim은 0이다.

1. `MajorFortuneSpecialistEngine.diagnose`는 이미 만들어진 동일 Graph/Input을 받는다. 기존 Foundation/Binder를 재사용하며 Graph와 packet seal·원본 파일 SHA를 검증한다. `observeInput`은 생성 불가능·활성 주기 미확정 입력도 WITHHELD로 진단한다.
2. `MajorPeriodQuestionIndex`는 기존 Foundation 질문 ID/locator/hash에 실제 연도를 붙인 View다. 14슬롯×12질문은 REFERENCE_ONLY이며 고객 해석 승인이나 168개 계산 사건이 아니다. 자연어 요구는 원문을 유지하고 기계 계약 미확정으로 남긴다.
3. Cycle Identity의 owner/producer/version/index/ganji와 Annual Evidence ID, Relation Reason ID, Graph Node ID, Canonical Root, Research ID, Question ID를 서로 대체하지 않는다. 새 canonical root는 발급하지 않는다.
4. 기간 관측은 YEAR_SCOPE_OBSERVATION이다. 원래 Graph의 UNKNOWN_INTERVAL·부분 ancestry를 자체 계산 결과로 덮어쓰지 않는다. 정확 시간 주장이 필요하면 기존 TIME_INTERSECTION Gate와 실제 참가자·주기·경계 검증을 모두 충족해야 한다.
5. 기존 십성 selector는 유지한다. 기존 normalizer에 빠져 있던 natalRequired/elementRequired 등은 원문 unresolved 조건으로 추가한다. 자연어를 새 계산 predicate로 만들지 않는다. Documentary sourceRefs는 실제 필수 AND/OR로 변환하지 않는다.
6. 실제 89개 연구의 의미 승인 0을 유지한다. 11,748개 쌍은 세 fixture의 의미 검토 쌍이며 확정된 11,748개 충돌이 아니다. 같은 Root/다른 연도/다른 표현만으로 의미 독립성을 확정하지 않는다.
7. 14년 비교는 두 실제 연도 packet의 차이·지속·교운·관계 참가자를 보존한다. 확인된 계산 차이와 승인된 새 생활 응용은 별도다. 현재 JobStatus와 MBTI를 과거·미래 상태로 확대하지 않는다.
8. 합성 모드는 별도 registry/file hash/owner/facts/cycles/meanings/approval 및 private session을 사용한다. 실제 Binder 12 Gates를 재실행하며 실제 연구를 복제·승인하지 않는다. FIRST_ELIGIBLE, YEAR_LOCAL_GREEDY, GLOBAL_CONSTRAINT_AWARE를 같은 14년/168질문에 실행한다.
9. Global 선택은 교운·비교 질문 예약, 전체 coverage, 독립 정보, Root/Meaning 재사용을 함께 고려한다. 연도별 탐욕 선택과 구별한다. SEARCH_LIMIT_NO_OPTIMALITY_CLAIM이면 최적성을 주장하지 않는다. Continuity는 독립 새 Fact가 아니며 recall은 실제 등록된 표시 ledger를 요구한다.

후속 producer 작업은 문서 제안만 있다. 기존 계산값·버전·전환 시각·reason ID를 보존하면서, 원래 누락된 cycle-specific natal/annual 관계 packet과 Graph endpoint를 노출하는 별도 승인된 작업이 필요하다. 정확/범위·참가 위치·before/uncertain/after를 보존하고 미상 시주·3층 판정·전환 전 관계를 만들어내지 않아야 한다. 원래 calculateCustomerDayun의 경계와 V4/Graph 노출 한계도 구별한다.

다음 세운 Specialist Engine, 고객 Planner/Writer 연결, 판매 승인·Production 배포는 이번 산출물에 포함하지 않는다.
