## 원인과 수정 경계

`majorComposer.ts`는 실제 대운의 십성으로 `MAJOR_MEANINGS`를 선택했다. 그러나 `contentSynthesis.ts`의 `planChapter → explanation / synthesis → extend`는 원국 재료를 선택해 대운 문단 사이에 삽입했다. 원국 근거 자체는 유효했지만, 다음 대운의 십성을 본문에서 명시하지 않고 서로 다른 출처를 섞어 읽게 했다.

공통 `contentSynthesis.ts`는 수정하지 않았다. 대운 조합부에서만 기존 할당 결과를 `majorEvidenceReading.ts`로 정리한다.

- 현재·다음 대운 도입에 실제 간지와 십성을 명시하고 기존 쉬운 설명을 유지한다.
- 도입부, 현재 맥락, 관계, 다음 대운에서 시기 설명 뒤에 원국 설명을 모은다. 첫 문단에 실제 원국 근거 이름을 넣고, 기존 해석 문장은 보존한다.
- MBTI/Fusion 문단은 원국과 평소 행동의 해석임을 구분한다. 원래 문장과 proof, 선택한 node/rule을 유지한다.
- 현재/다음 대운의 활용 문장은 해당 장에 이미 배정된 유효한 원국 십성만 사용한다. 기존 `TEN_GOD_SEMANTICS`에서 공통 생활 영역(돈·일·학습)이 있을 때만 조건형 조언을 만든다. 대운 proof가 없거나 공통 영역이 없으면 추가하지 않는다.
- 공통 영역은 실생활 적용 질문을 만들 근거다. 생극·합충·상승효과·인과관계를 새로 계산하거나 주장하는 근거로 쓰지 않는다. B는 돈, C는 일에서 기준을 비교하도록 안내한다.
- 새 활용 문단에는 실제 원국 proof, 실제 대운 proof, 사용한 의미 정의 참조를 함께 남긴다. `next-boundary`와 `next-work`도 실제로 비교하는 양쪽 대운 참조를 갖도록 보완했다.
- 연도별 원고, 전환 문단, 계산·개인화·공통 엔진은 수정하지 않았다.
