## 구조별 독립 정보와 성립·배제

전체 조건은 `structure-study.md`에 있다. 모든 프로필에서 강약·위치·월령·투출·통근·지장간·생극제화·추가 전제를 따로 기록했다.

- **신강·신약**: 득령과 강약, 천간 동류 수와 지지 통근, 인성 지원과 비겁 지원을 구별한다. 종격·전왕·합화·용신을 완성한 것처럼 설명하지 않는다. 강약을 체력·의지·능력·성공으로 바꾸지 않는다.
- **식상생재·재생관**: 식상→재성과 재성→정관은 다른 단계다. 공존과 실제 연결, 산출과 회수, 자원과 책임을 구별한다. 재성이 편관을 생하는 경로를 V4 재생관으로 오인하지 않는다.
- **관인·살인상생**: 정관/편관→인성 및 인성→일간의 두 경로가 필요하다. 인성 존재만으로 완성하지 않는다. 월령의 주객, 재극인·상관·식상제살과 중개 흐름의 차이를 남긴다.
- **상관견관·관살혼잡**: 출력이 정관을 제어하는 경로와 두 제어 방식의 미정리는 다르다. 인성·재성 중개, 거류, 금수상관의 계절 예외를 함께 기록한다. 갈등·범죄·실직·부정직·복수 연애를 예언하지 않는다.
- **많음·없음**: 가중 우세는 가족 비중이지 실제 능력·자산이 아니다. 무인성·무식상은 확정 네 기둥의 천간·장간에서 0을 확인한 범위다. 미상 시주는 부재 확정 금지이며 학습·표현·부모·자녀 부재를 뜻하지 않는다.
- **토금·금목·수목·화금**: 상생/상극 자체와 과도·적절한 작용을 구별한다. 계절·대상의 여력·뿌리·건습·다른 작용을 요구한다. 다른 구조의 설명을 이름만 바꿔 성립 전거로 삼지 않는다.
- **월령·부억·한난·조습·통관**: 계절 권한 / 여력 조절 / 한난 환경 / 건습 환경 / 작용 사이 연결이라는 다른 판단 목적을 기록한다. 월령·조절 원리를 직접 직업·돈·연애 성격으로 환산하지 않는다.
