5. Pair 일반 참고는 실제 양쪽 유형·각자 trait·현재 과제 확인 뒤에만 참고. direct는 실증 성과 검증이 아니며 reportLine·lovePattern·marriagePattern·관계명은 managerReport 전문 필드가 아니다. 개인 Fusion을 새 Pair 점수로 합산하지 않는다.
