# 관리 비대칭과 안전

96개 후보는 모두 조건부 편집 연구이며 실제 경험·권한·성과가 아니다. 지시와 위임, 재량과 승인, 수행과 관리 책임, 보고와 감시, 평가와 인격 판단, 칭찬과 업무 수락을 구별한다. 관리자는 목표·기준·변경·자원·자기 권한 안의 결정·응답을 먼저 설명할 책임을 남긴다. 팀원은 실행 상태·위험·소요·선택지를 제공하고 안전한 통로에서 질문할 수 있다. 실제 업무상 의무를 지우지도 않고, 권한 밖 판단·감정 노동·과로·공개 망신 수용을 팀원 책임으로 만들지도 않는다.

CH07의20개 구체 문제는 CH08에 각각 선행 ref를 가진 조정이 있다. 상호 오해와 보복 우려·강압·인격 판단을 같은 수준의 반반 잘못으로 환원하지 않는다. 질문할 안전·동의·조직 절차를 확인하고 직접 대면 화해를 강요하지 않는다. 앱은 안전·비보복·익명성·법률 결과를 보장하지 않는다. 실제 문제·이력·직급·평가권이 없으면 질문·가상 장면만 남긴다.
