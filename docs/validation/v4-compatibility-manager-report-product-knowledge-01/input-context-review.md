# A–AN 입력·맥락 범위

40시나리오를 정의했다. 실제 궁합42변형(40성공+역할버전 정상거부2), 별도6상품 고정suite로 AM을 확인한다. A–O는 MBTI·출생시간·실제 합/충/미검출/미지원/방향 십성 조건, P–U는 역할 버전·전체 순서·이름 교환, V/W는 실제 직급·평가권 미확인, X–AG는 모호한 목표·재량·새 방법·상사 변경·보고시점·문제공유·피드백·좋은 위임·과통제·기여 인정의 가상 맥락이다. AH/AI는 동료·사업 파트너의 실제 카테고리 비교, AJ/AK는 현재 CHILDREN ancestry, AL은 기존 fallback, AN은 재실행이다.

실제 궁합 payload는 기존 productKey/productSlug/relationshipType/compatibilityRoleVersion/personA/personB만 쓴다. Q는 버전 누락, R은 오기입이라는 의도된 invalid fixture다. 직무·직급·평가권·성과·회사·과거·실제 지시·권한을 생성기에 강제로 넣지 않았다. X–AG 가상 조건은 input-cases의 별도 hypotheticalContext에만 있으며 실제 원고가 그 사실을 입력받았다고 주장하지 않는다. 이 항목들의 새 연구 적용은 runtime 미연결 상태다.

전체 교환 S는 A상사/B부하·팀원이라는 선언도 바뀐 관리 관계다. 이름 교환 T와 같지 않다. AB는 B 일간 viewer/A target, BA는 A viewer/B target. 같은 십성은 그대로 보존한다. 시간 미상은 hour refs를 새로 채우지 않고 MBTI 미상은 Pair·해당 개인 trait/Fusion으로 추측 보충하지 않는다.

L/M/AL은 기존 editorial Major REPEATED_LONG_PHRASE로 legacy published edition을 유지했다. 기존 reader draft는10130자이며 CH01.P3/CH02.P1, CH02.P2/CH03.P2, CH02.P3/CH03.P3의 중복 지적이 있다. 이를 신규 생성 성공의 판매 품질 승인으로 해석하지 않는다. 계산·본문·Book·fallback 경로는 전후 동일하다. 이번 source DB 작업에서 원고나 gate를 고치지 않았다.
