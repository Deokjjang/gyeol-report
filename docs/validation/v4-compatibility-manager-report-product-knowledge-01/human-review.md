# 의미 차별성·독해 검토

96개 후보의 원문 역할·긍정·위험·팩폭·반전·가상 장면·A 책임·B 질문은 materials-review.md에 전수 표시했다. 작성 후 36개 질문의 정보 기능을 비교했다. CH01은 대표 접점, CH02/03은 각자 원천, CH04는 조건부 공동 기여, CH05/06은 수신자·영향·정보의 방향, CH07은 구체 공백, CH08은 앞선 사실·행동·지원·재확인, CH09는 실제 표시된 호환 의미의 회수다. 같은 일반 원칙을 쓰더라도 다른 정보를 주지 않으면 독립 근거로 세지 않는다.

- mrpr:material:CH05.P1:manager-to-report-constraint: 부모 기대·보답의 빚이 아니라 관리자의 필수 결과·방법 재량·실제 승인권을 분리한다. 수신 B 기준 십성은 지시의 정당성을 증명하지 않는다.
- mrpr:material:CH06.P1:report-to-manager-customer-observation: 가까운 마감의 몰입이 아니라 제한된 고객 반응의 관찰·해석·표본 범위를 A의 결정 정보로 전달한다.
- mrpr:material:CH06.P2:report-propose-bounded-method: 새 대안·변경 비용이라는 공통 주제는 있지만 A가 검토 기준·시험 승인·자원을 결정하고 B가 가정·검증·되돌림을 제안하는 관리 인터페이스다.
- mrpr:material:CH03.P2:report-private-feedback-space: 이유 질문을 좁히는 일이 아니라 공개 판단을 중단하고 수정 공간·시간·기준을 제공할 A 책임을 남긴다.
- mrpr:material:CH08.P2:manager-close-revision: 추가 요청의 동료 인계 영향이 아니라 A가 기준 변경과 오류 수정을 구분하고 수정 종료선을 설명하는 책임이다.
- mrpr:material:CH05.P2:manager-resource-removal: 지원 범위라는 공통 주제는 있지만 대신 처리의 침범보다 필요한 접근·연결 담당·응답 시점을 A가 확인하는 지원 책임이다.
- mrpr:material:CH08.P2:manager-set-report-time: 생활 책임 합의가 아니라 실제 관리 판단 시한·잠정 정보 수용·응답을 A가 먼저 명시하는 보고 조건이다.
- mrpr:material:CH02.P3:manager-correct-own-error: 개인의 수정 버전만이 아니라 A의 잘못된 지시·기준 변경이 B의 실수 기록으로 남지 않도록 원인·일정·자원을 정정한다.
- mrpr:material:CH06.P1:report-to-manager-reality-check: 최소 자료 전달과 공통 정보 주제는 있지만 B의 계획 반례를 A의 변경·지원 판단으로 연결하고 최종 책임은 A에게 남긴다.
- mrpr:material:CH05.P4:manager-feedback-recheck: 수정 시간이라는 공통 주제는 있지만 A가 관찰·영향·종료 기준·검토 응답을 명시하고 B는 이해·가능 시간을 확인한다.
- mrpr:material:CH06.P4:report-feedback-clarification: 내부 논리 공유가 아니라 A가 설명할 모호한 평가어를 B가 안전한 통로로 수정 조건 질문으로 바꾸는 과정이다.
- mrpr:material:CH09.P2:recall-personal-fusion: 자녀 지원 필요가 아니라 동일 B의 실제 원국·MBTI Fusion 두 root·BA방향·실제 표시 이력을 요구하는 회수다.

권한 비대칭: 목표·지시·배분·평가 기준의 공백을 B의 성격·감정 관리 문제로 돌리지 않는다. B에게도 실제 수행·보고 범위는 남긴다. 실제 권한·과거·성과·직무는 UNKNOWN이며, 지시·평가·보복·기여 누락 장면은 hypothetical_only다. 안전·조직 절차를 확인하고 강요된 화해를 배제했다.

적용 한계: 본 연구는 16유형 업무 원천을 전수 감사했지만 메인 후보의 A/B 유형 조합은 일부다. 256방향 crosswalk는 256×36 완성 원고를 뜻하지 않는다. 고객에게 표시할 source binding·selector·도메인 승인은 구현하지 않았다. 전문 직업·법·의료·심리 판단 또는 고객 판매 품질 PASS를 선언하지 않는다.
