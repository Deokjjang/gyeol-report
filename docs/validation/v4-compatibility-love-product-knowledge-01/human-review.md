# 실제 의미 독해 검토

80개 후보의 핵심·조건·장면·조정·반례·독립 정보 위치를 읽고 검토했다. 테스트의 문자열 중복 0과 글자 수는 의미 품질 판정의 충분조건이 아니다. 고객 원고 판매 품질을 승인한 검토가 아니다.

## CH01 vs CH04

대조: response-and-thought / curiosity-and-continuity

CH01은 표현과 정리의 대표 접점을 설명한다. CH04는 새 질문·기억한 취향을 실제 만남의 선택에 보탤 조건을 제시한다. 도입을 칭찬으로 바꾼 문장으로 세지 않았다.

## CH02 vs CH03

대조: a-deliberate-affection / b-reaction-as-participation

A의 신중한 관심 선택과 B의 반응으로 참여를 확인하는 통로를 구분했다. 둘의 원천을 서로 대체하지 않고, B가 실제로 서운했다는 사실은 만들지 않았다.

## CH04 vs CH09

대조: shared-trust-not-same-rule / recall-trust-as-choice

공통 신뢰의 구체적 합의를 발견하는 단계와, 조건이 바뀌었을 때 약속을 수정할 질문은 다르다. CH09에서 새 강점은 도입하지 않는다.

## CH05 vs CH06

대조: ab-care-debt / ba-care-erases-choice

A→B의 미리 맡은 수고에 대한 상환 기대와 B→A의 직접 선택을 대신하는 도움은 서로 다른 비용이다. 이름 교환으로 만든 방향 차이가 아니다.

## CH05 vs CH07

대조: ab-reaction-pressure / mismatched-response-time

A의 표현이 B의 응답 의무가 될 조건과, 확인 요구·정보 없는 보류가 상호 추측을 키우는 악순환 조건을 나눴다.

## CH06 vs CH07

대조: ba-explanation-too-late / assumption-grows-with-meaning

B가 늦게 말할 때 A에게 남는 정보 공백과, A의 의미 부여가 커질 때 생길 양쪽 악화 조건은 별도다. 침묵만으로 회피를 판정하지 않는다.

## CH07 vs CH08

대조: correction-and-retreat / repair-correction-loop

교정·침묵으로 실제 이유가 사라질 조건과, 한 가지 행동을 수정하며 다시 설명할 기회를 만드는 절차를 구분했다. 실제 다툼이 있었다는 전제를 두지 않는다.

## CH01 vs CH09

대조: steady-and-new / closing-new-and-held

안정·새로움의 출발점 대비를, 마지막에는 현재 가능한 준비와 변경 통보의 선택으로 회수한다. 같은 형용사의 반복으로 긍정 수량을 늘리지 않는다.

같은 돌봄·자율성·반응 의미는 여러 장에 정당하게 재사용된다. 새로운 사실이 아니라 기여→비용→조정→회수로 질문을 바꾼 것이다. 따라서 80은 서로 다른 계산 사실 수가 아니라 편집 적용/회수 항목 수다. 8개 회수는 원천 의미를 다시 쓴 항목이며 독립 원천 수에 더하지 않는다. 전 인구의 후보 선택 편중과 모든 유형×모든 문단의 충분성은 runtime 연결 전이므로 UNVERIFIED다.
