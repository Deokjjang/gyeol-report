# 직무 범위의 외부 자료 확인

다음 6개 공식 자료의 Tasks 부분을 실제로 읽었다. 짧은 한국어 요약만 기록하며 원문을 대량 복제하지 않았다. 이후의 가상 업무 장면·비용·학습 질문은 편집 연구이며 출처의 문장·검증된 개인 행동으로 표시하지 않는다. 미국 직무 분류를 국내 자격 제도·시장 전망·개인 적성의 정답으로 사용하지 않는다.

- [Photographers](https://www.onetonline.org/link/summary/27-4021.00): 촬영 목적·장비·조명·선별·편집·전송의 과제 범위를 확인. 사진 분야와 고용 형태가 다양하며 이 자료는 개인 실력·시장 수요·한국 법률·사용권 계약의 검증이 아니다.
- [Software Developers](https://www.onetonline.org/link/summary/15-1252.00): 사용 요구 분석·구현·테스트·문서·기존 기능 수정의 과제 범위를 확인. 특정 언어 숙련·채용 조건·개인의 적성·생산성을 증명하지 않는다.
- [Instructional Coordinators](https://www.onetonline.org/link/summary/25-9031.00): 교육 자료·교육과정·교육자 훈련·내용 갱신의 일부 과제 범위를 확인. 모든 강사·교사 직무와 동일한 분류가 아니다. 국내 자격·학습 효과·시험 결과로 이전하지 않는다.
- [Food Service Managers](https://www.onetonline.org/link/summary/11-9051.00): 재고·제공 품질·일정·고객 문제·운영 자원의 과제 범위를 확인. 한국 카페의 손익·면허·고용 관계나 특정 규모를 증명하지 않는다.
- [Registered Nurses](https://www.onetonline.org/link/summary/29-1141.00): 관찰·기록·보고·팀 조율을 포함하는 직무 범위만 확인. 의료 행위를 권하는 자료가 아니다. 국내 자격·권한·안전·진단·건강 결과는 별도이며 본인 입력으로 만들지 않는다.
- [Management Analysts](https://www.onetonline.org/link/summary/13-1111.00): 작업 정보 수집·분석·대안·문서·운영 절차 검토의 범위를 확인. 소규모 사업자의 모든 일을 규정하거나 현재 직원·성과·자격을 증명하지 않는다.

기존 명리 고전·MBTI 자료의 외부 링크를 이번에 모두 재열람한 것은 아니다. 기존 로컬 원천·원래 확인 상태·hash를 재검증했고 새 전통 사실·실증 사실은 0이다.
