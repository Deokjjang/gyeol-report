# 긍정·위험·팩폭·반전 전수 비교

각 항목은 같은 근거의 서로 다른 적용 각도이며 네 개 독립 사실이 아니다. 팩폭은 의도와 결과의 비용 차이, 반전은 약해 보이는 행동이 유리한 조건이다. 성공·승진·부·합격 보장은 생성하지 않았다.

## ckr:material:CH01.P1:request-framing

- 긍정: 요청을 실행 가능한 약속으로 바꿀 여지
- 과용: 기준 정리에 매달리며 질문을 미룰 수 있음
- 비용: 완벽한 양식을 기다리면 실제 누락을 배울 기회도 늦어짐
- 반전 조건: 규칙을 좋아해도 예외 질의 통로를 만들면 조정에 기여

## ckr:material:CH01.P1:hypothesis-first

- 긍정: 틀린 설명을 일찍 제외할 수 있음
- 과용: 가능한 원인을 모두 같은 깊이로 조사할 수 있음
- 비용: 조사한 양이 늘어도 다음 결정이 없으면 도움을 전달하기 어려움
- 반전 조건: 모른다고 말하는 태도가 성급한 단정보다 정확한 출발이 됨

## ckr:material:CH01.P1:draft-as-question

- 긍정: 불명확한 요구를 구체화할 여지
- 과용: 취향 피드백을 매번 새 방향으로 받아들일 수 있음
- 비용: 초안을 많이 만들수록 선택 기준이 없다는 문제를 가릴 수 있음
- 반전 조건: 빠른 초안도 폐기할 질문을 정하면 낭비가 줄어듦

## ckr:material:CH01.P1:people-entry

- 긍정: 처음부터 사용 가능한 지원을 설계할 수 있음
- 과용: 상대의 모든 요청을 우선시할 위험
- 비용: 좋은 출발을 돕다가 학습자의 몫까지 대신하면 결과를 확인하기 어려움
- 반전 조건: 도움을 줄이기 위해 먼저 충분히 묻는 경우도 있음

## ckr:material:CH01.P1:capacity-entry

- 긍정: 지속할 수 있는 작업 크기를 고를 여지
- 과용: 가용 자원을 지나치게 적게 잡아 실험을 모두 미룰 수 있음
- 비용: 절약만 남으면 무엇을 개선하려던 일인지 목적이 흐려짐
- 반전 조건: 작은 범위가 반복 검증의 기회를 늘릴 수 있음

## ckr:material:CH01.P2:source-review-link

- 긍정: 증상 확인 뒤 재발 조건을 살필 수 있는 조합
- 과용: 검토와 모델이 같은 root이면 독립 사실을 늘리지 않음
- 비용: 깊은 설명을 세웠다는 만족이 실제 오류 재현을 대신할 수 있음
- 반전 조건: 세부 확인과 큰 구조를 오가면 서로의 빈틈을 찾을 수 있음

## ckr:material:CH01.P2:source-expression-link

- 긍정: 관심 있는 내용을 바깥 결과로 시험할 여지
- 과용: 같은 표현 의미를 두 체계가 반복할 수 있음
- 비용: 출처가 둘이라는 이유로 전달 능력이 두 배 검증되지는 않음
- 반전 조건: 표현을 좋아해도 자료 검증을 더하면 설명의 신뢰가 생김

## ckr:material:CH01.P2:source-resource-link

- 긍정: 기여를 막연한 칭찬 밖으로 설명할 여지
- 과용: 성과 관심을 실제 재산 정보로 잘못 읽을 수 있음
- 비용: 값을 받고 싶다는 마음과 시장에서 그 값을 받는 사실은 다름
- 반전 조건: 보상을 묻는 태도가 과업 범위를 명확하게 만들 수 있음

## ckr:material:CH01.P2:source-help-boundary

- 긍정: 배우는 조건과 실제 지원 기능을 함께 점검
- 과용: 서로 다른 의미를 같은 돌봄으로 압축할 위험
- 비용: 친절하다는 해석만으로 전문 권한이나 안전 숙련을 인정할 수 없음
- 반전 조건: 도움을 받는 법을 아는 것이 질문할 시점을 찾는 장점이 될 수 있음

## ckr:material:CH01.P2:source-two-sided-tempo

- 긍정: 설명과 실습이 다른 질문에 답할 수 있음
- 과용: 차이를 모순된 성격이나 우열로 만들 수 있음
- 비용: 직접 해보기가 전문 안전 기준을 건너뛸 허가가 되지 않음
- 반전 조건: 짧은 실습 뒤 읽는 설명이 구체적으로 와닿을 수 있음

## ckr:material:CH01.P3:start-finish-contract

- 긍정: 세 단계의 판단을 인계할 수 있음
- 과용: 착수 때 정한 조건을 변경 불가능한 답으로 여길 수 있음
- 비용: 계획은 완벽해도 변경 이력이 없으면 완료 판단이 어긋남
- 반전 조건: 중간 예외를 기록하면 기준을 고집하지 않고 보존 가능

## ckr:material:CH01.P3:iterate-selected-idea

- 긍정: 발상이 납품 가능한 결과로 이어질 여지
- 과용: 후반에 새 콘셉트를 계속 끼워 넣을 수 있음
- 비용: 창의적인 변경이 이미 합의한 검토를 처음으로 되돌릴 수 있음
- 반전 조건: 미채택 아이디어를 따로 두면 완성과 새로움을 함께 지킬 수 있음

## ckr:material:CH01.P3:handoff-finish

- 긍정: 예측 가능한 연결을 남길 수 있음
- 과용: 모든 후속 문제를 자신의 책임으로 가져올 수 있음
- 비용: 끝까지 책임지려는 의도가 인계 없는 상시 대기로 바뀔 수 있음
- 반전 조건: 남은 문제를 공개하는 것이 미완성 숨기기보다 신뢰를 도움

## ckr:material:CH01.P3:timeboxed-inquiry

- 긍정: 불확실해도 쓸 수 있는 결과를 전달
- 과용: 질문이 흥미로울수록 종료를 늦출 수 있음
- 비용: 조사 미완료라는 이유로 쓸 수 있는 발견도 묻힐 수 있음
- 반전 조건: 한계를 남기면 확실한 척하지 않고도 다음 결정을 도움

## ckr:material:CH01.P3:feedback-loop-entry

- 긍정: 즉각적인 반응을 작업 개선 정보로 쓸 수 있음
- 과용: 상대의 기분만 따라 안내를 바꿀 수 있음
- 비용: 친절한 대화가 길어도 문제는 다음 단계에 그대로 남을 수 있음
- 반전 조건: 짧은 확인 질문이 긴 설명보다 빠른 해결을 도움

## ckr:material:CH01.P4:permission-to-correct

- 긍정: 오류 예방을 공동 작업으로 만들 여지
- 과용: 검토자에게 무제한 책임만 남을 수 있음
- 비용: 정확하라는 요구가 자료 접근을 대신하지는 못함
- 반전 조건: 질문이 허용되는 환경에서는 모름을 밝히는 것도 전문성

## ckr:material:CH01.P4:autonomy-with-checkpoint

- 긍정: 판단을 기다리는 시간을 줄일 여지
- 과용: 자기 방법을 설명하지 않아 연결 단계에서 오해 발생
- 비용: 간섭을 줄이려다 필요한 정보까지 닫으면 재량도 줄어들 수 있음
- 반전 조건: 중간 근거를 짧게 공유하면 더 큰 자율성을 지킬 수 있음

## ckr:material:CH01.P4:protected-depth-window

- 긍정: 끊어진 생각을 다시 잇는 낭비를 줄일 여지
- 과용: 집중 보호가 피드백 차단으로 바뀔 수 있음
- 비용: 혼자 오래 썼다는 사실만으로 독자에게 필요한 글이 되지는 않음
- 반전 조건: 예정된 짧은 피드백이 오히려 깊은 작업을 보호

## ckr:material:CH01.P4:change-with-baseline

- 긍정: 현장 반응을 제안 수정에 쓸 여지
- 과용: 승인 없는 예외 약속을 먼저 할 수 있음
- 비용: 좋은 대응 속도가 제공 팀의 야근으로 이전될 수 있음
- 반전 조건: 바로 모른다고 말하고 확인 시점을 정하는 것이 신뢰를 도움

## ckr:material:CH01.P4:mission-with-basics

- 긍정: 중요한 가치를 현실 과제로 옮길 여지
- 과용: 의미가 적어 보이는 기초 작업을 미룰 수 있음
- 비용: 도움을 주고 싶다는 마음만으로 전문 경계가 생기지는 않음
- 반전 조건: 기록을 남기는 조용한 일도 지원이 끊기지 않게 함

## ckr:material:CH02.P1:detect-mismatch

- 긍정: 재처리 전에 오류를 드러낼 여지
- 과용: 모든 흠을 같은 위험으로 다룰 수 있음
- 비용: 정확해 보이는 표도 원본 추적이 안 되면 다른 사람이 검증하기 어려움
- 반전 조건: 보기 좋은 정리보다 불명확한 칸을 남기는 것이 더 정확할 수 있음

## ckr:material:CH02.P1:causal-model

- 긍정: 근거를 따라갈 수 있는 설명을 만들 여지
- 과용: 자료가 늘수록 결론이 저절로 좋아진다고 생각할 수 있음
- 비용: 설명을 어렵게 만드는 것이 분석의 깊이를 보여주지는 않음
- 반전 조건: 짧은 한계 설명이 긴 확신보다 실무에 유용할 수 있음

## ckr:material:CH02.P1:make-alternative

- 긍정: 없는 선택지를 현실 검토 대상으로 만들 여지
- 과용: 개수가 많아지면 선택 비용도 커질 수 있음
- 비용: 열 가지 안을 만들었어도 차이를 설명하지 못하면 선택 부담을 넘김
- 반전 조건: 제약을 줄이는 대신 분명히 하면 발상의 차이가 더 잘 보일 수 있음

## ckr:material:CH02.P1:explain-to-use

- 긍정: 지식에 접근하는 문턱을 낮출 여지
- 과용: 좋은 분위기를 이해의 증거로 볼 수 있음
- 비용: 다들 고개를 끄덕였어도 아무도 다음 행동을 모르고 있을 수 있음
- 반전 조건: 짧고 낯선 질문이 긴 칭찬보다 설명을 개선

## ckr:material:CH02.P1:reliable-execution

- 긍정: 반복을 안정된 결과로 남길 여지
- 과용: 익숙한 방식의 효용이 줄어도 계속 지킬 수 있음
- 비용: 오래 했다는 말이 조건이 달라진 일까지 잘한다는 근거는 아님
- 반전 조건: 반복을 고치는 힘도 꾸준함의 일부

## ckr:material:CH02.P2:coordination-distinct

- 긍정: 여러 사람의 대기를 줄일 여지
- 과용: 맡긴 일을 다시 가져와 책임을 독점할 수 있음
- 비용: 혼자 끝낸 양이 많다는 사실은 팀을 움직였다는 증거와 다름
- 반전 조건: 덜 개입한 결과가 좋은 조정의 산출물일 수 있음

## ckr:material:CH02.P2:resource-distinct

- 긍정: 제한된 자원을 필요한 결과에 남길 여지
- 과용: 보이지 않는 배움·관계의 가치를 제외할 수 있음
- 비용: 당장 절약한 금액 뒤에 재작업이 남으면 효율을 과대평가
- 반전 조건: 지금 더 쓰는 선택이 유지 투입을 줄일 수도 있음

## ckr:material:CH02.P2:care-distinct

- 긍정: 접근 가능한 안내를 만들 여지
- 과용: 개인 응대에 모든 시간을 쓸 수 있음
- 비용: 도움을 많이 준 사실이 상대의 독립성을 늘린 사실과 같지 않음
- 반전 조건: 한 번 덜 도와주는 것이 사용 능력을 확인할 기회일 수 있음

## ckr:material:CH02.P2:opportunity-distinct

- 긍정: 기존 결과의 다른 사용처를 발견할 여지
- 과용: 새 요청을 모두 기회로 받아들일 수 있음
- 비용: 새 고객 관심을 얻는 활동이 기존 약속을 무너뜨릴 수 있음
- 반전 조건: 거절할 조건이 선명하면 탐색에 쓸 자원도 남음

## ckr:material:CH02.P2:technical-distinct

- 긍정: 구체적인 문제를 작업으로 풀 여지
- 과용: 잘된 요령의 적용 한계를 놓칠 수 있음
- 비용: 한 번 성공한 작업이 다른 재료에서도 안전하다는 보장은 아님
- 반전 조건: 실패 조건을 설명하는 기술도 전문성

## ckr:material:CH02.P3:precision-to-visual

- 긍정: 제작자의 표현을 해치지 않고 오류를 줄일 여지
- 과용: 정확성으로 취향까지 판단할 수 있다고 착각
- 비용: 규격을 지킨 시안도 전달 목적이 틀릴 수 있음
- 반전 조건: 창작을 제한하는 검토가 아닌 사용 조건을 지키는 검토

## ckr:material:CH02.P3:analysis-to-teaching

- 긍정: 개념의 빈틈을 드러내는 교육 자료를 만들 여지
- 과용: 전문 설명의 깊이를 학습자의 이해와 혼동
- 비용: 내게 쉬운 설명이 상대에게도 쉬운 것은 아님
- 반전 조건: 초보자의 질문이 전문가 설명의 생략을 찾아줌

## ckr:material:CH02.P3:care-to-process

- 긍정: 개인의 배려가 공동의 접근성으로 남을 여지
- 과용: 절차가 생겼다는 이유로 다른 필요를 듣지 않을 수 있음
- 비용: 좋은 안내를 만들고도 실제로 찾을 수 없다면 도움은 남지 않음
- 반전 조건: 개별 질문을 줄이는 것이 배려의 감소는 아닐 수 있음

## ckr:material:CH02.P3:execution-to-experiment

- 긍정: 아이디어를 실제 사용 조건과 대조할 여지
- 과용: 움직인 뒤 확인 질문을 잊을 수 있음
- 비용: 해봤다는 말만 남으면 다음 선택을 바꿀 정보가 적음
- 반전 조건: 작은 멈춤이 실행의 가치를 더 분명히 함

## ckr:material:CH02.P3:meaning-to-proposal

- 긍정: 좋은 의도를 구체적인 결정으로 남길 여지
- 과용: 모든 안이 목적에 완벽히 맞기를 기다릴 수 있음
- 비용: 멋진 방향을 말했어도 누가 다음에 무엇을 할지 없으면 일이 안 움직임
- 반전 조건: 작은 실행은 큰 뜻의 축소가 아닌 검증 방식

## ckr:material:CH02.P4:criterion-before-practice

- 긍정: 검토 능력을 관찰 가능한 작업으로 바꿀 여지
