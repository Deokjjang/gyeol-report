# 23개 직무의 실제 과제와 가상 장면

직업 프로필은 적성 판정이나 실제 고객 경험이 아니다. 현재 parser 관찰과 V4 최종 보강 결과를 구분한다.

## 사진가·프리랜서 사진가

- 과제: 사용 목적과 촬영 대상, 납품 형태를 의뢰인에게 각각 묻는다
- 과정: 목적 확인 → 촬영 설계 → 현장 촬영 → 선별 → 보정 → 납품 확인
- 산출물: 사용 매체에 맞춘 선별 이미지와 보정 범위 안내
- 협업: 의뢰인·모델·현장 담당자가 원하는 장면과 촬영 가능 조건을 합의
- 어려움: 작품으로 좋은 컷과 실제 사용할 수 있는 컷이 다를 수 있다
- 맞을 조건: 사진의 용도와 선정 기준을 공유하고 현장 판단을 허용하는 의뢰
- 불편할 조건: 참고 이미지 없이 취향 수정만 반복하고 변경을 모두 최초 비용에 포함하는 의뢰
- 추가 배움: 광원·움직임·색관리의 선택 이유를 비교할 테스트 촬영
- 검증: 장비 성능 대신 실제 납품 규격과 사용 목적 충족 여부로 검토
- 경제 질문: 보정 횟수·이동·준비·저장·사용 범위가 촬영 시간 밖의 투입이 될 수 있다
- 작은 실험: 연습 사진 두 장을 같은 용도로 골라 왜 한 장을 납품할지 설명
- 가상 장면: 촬영 전 상품 상세용 사진을 요청받았는데 포트폴리오의 분위기 사진을 참고로 받은 가상 상황
- 분류 관찰: freelancer: unknown → unknown / employee: unknown → unknown / self_employed: business_operations → business_operations
- 제한: 사진 분야 내 인물·상품·보도는 서로 다른 조건이며 실제 촬영 분야부터 확인

## 재무기획

- 과제: 집계 기간과 예산 가정이 같은지 원자료에서 확인
- 과정: 기간 통일 → 실적 대조 → 차이 분해 → 시나리오 비교 → 판단 자료 전달
- 산출물: 가정과 오차 범위가 보이는 손익 전망·예산 비교표
- 협업: 사업 부서의 운영 가정과 의사결정자의 비교 질문을 연결
- 어려움: 예측 오차를 모두 담당자의 실수로 볼 수 없다
- 맞을 조건: 가정 변경을 공개하고 불확실성을 함께 보고하는 조직
- 불편할 조건: 원자료 접근 없이 원하는 결론에 숫자만 맞추는 조직
- 추가 배움: 스프레드시트 검증·집계 기준·시나리오 민감도 연습
- 검증: 같은 수치에서도 가정 변화와 실제 사업 변화를 구분해 설명
- 경제 질문: 예산 절감이 미루는 활동과 다시 생길 비용을 함께 검토
- 작은 실험: 가상 매출표의 가격·수량·시점 가정을 각각 바꿔 비교
- 가상 장면: 매출은 늘었지만 회수 시점이 늦어진 가상 전망 검토
- 분류 관찰: employee: finance_planning → finance_planning
- 제한: 개인 투자 수익·회사의 실제 재무상태를 추정하지 않음

## 개발·IT 구현

- 과제: 사용자 요구와 현재 오류의 재현 조건을 나눈다
- 과정: 요구 정의 → 작은 구현 → 오류 재현 → 검증 → 연결 확인 → 인계
- 산출물: 작동 코드·검증 사례·변경 이유
- 협업: 요청자·검토 동료·운영 담당자에게 영향 범위를 전달
- 어려움: 기술적으로 가능한 구현과 당장 필요한 기능은 다르다
- 맞을 조건: 검토와 실험 시간을 주고 기존 동작을 확인할 환경
- 불편할 조건: 새 기능 수만 평가하며 유지보수 책임을 설명하지 않는 환경
- 추가 배움: 실패 입력·경계 조건·설계 대안 비교
- 검증: 예제와 다른 입력에서도 같은 약속이 지켜지는지 확인
- 경제 질문: 구현 외 유지보수·장애 대응·설명 시간을 별도 투입으로 본다
- 작은 실험: 작은 기능 하나에 실패 사례와 복구 기준까지 적기
- 가상 장면: 작동 화면은 같지만 입력 누락 때 결과가 달라지는 가상 구현
- 분류 관찰: employee: engineering → engineering / freelancer: engineering → engineering / job_seeker: engineering → engineering / student: engineering → engineering
- 제한: 현재 실력·서비스 운영 이력·특정 기술 사용을 입력만으로 인정하지 않음

## 브랜드·시각 디자인

- 과제: 독자·매체·전달할 정보의 우선순위를 묻는다
- 과정: 요구 정리 → 대안 시안 → 선택 근거 → 매체 적용 → 읽기 확인
- 산출물: 시안·매체별 적용안·핵심 표현 기준
- 협업: 의뢰인의 취향과 실제 이용자의 읽기 문제를 분리
- 어려움: 눈에 띄는 표현이 항상 필요한 정보 전달을 돕지는 않는다
- 맞을 조건: 초안의 목적을 듣고 다른 매체 적용까지 평가하는 환경
- 불편할 조건: 완성 후 결정자가 바뀌어 방향을 전부 뒤집는 환경
- 추가 배움: 정보 계층·대비·출력 매체의 제약을 비교
- 검증: 작은 화면에서도 핵심 문구가 먼저 읽히는지 확인
- 경제 질문: 새 방향 재제작과 같은 방향 수정의 범위를 구분
- 작은 실험: 같은 문구를 포스터와 작은 배너로 옮겨 비교
- 가상 장면: 보기 좋은 포스터가 작은 배너에서는 상품명을 가린 가상 시안
- 분류 관찰: freelancer: design → design / employee: design → design / student: design → design
- 제한: 디자인 전공과 상업 납품 경험은 구별

## 사용자 경험 설계

- 과제: 누가 어느 단계에서 무엇을 하려는지 관찰 질문을 정한다
- 과정: 문제 가설 → 사용 흐름 → 작은 시안 → 사용 확인 → 수정
- 산출물: 과제 흐름도·시제품·관찰 근거
- 협업: 개발·디자인·사용자의 서로 다른 제약을 비교
- 어려움: 말로 좋다는 반응과 실제 과제 수행은 다르다
- 맞을 조건: 실제 사용 상황을 볼 수 있고 문제 정의를 고칠 수 있는 팀
- 불편할 조건: 버튼 색 변경을 모든 사용 문제의 해답으로 요구하는 팀
- 추가 배움: 관찰 질문·과제 설계·편향을 줄이는 기록
- 검증: 도움 없이 목적을 달성한 단계와 멈춘 이유를 확인
- 경제 질문: 수정의 값은 화면 수보다 피할 수 있는 혼선과 검증 범위
- 작은 실험: 가상 예약 흐름에서 안내 없이 완료 가능한지 확인
- 가상 장면: 호감은 높지만 예약 날짜를 고르지 못하는 가상 시제품
- 분류 관찰: employee: project_creation → project_creation / freelancer: project_creation → project_creation / student: project_creation → project_creation
- 제한: 소수 관찰을 모든 사용자 성향으로 일반화하지 않음

## 영상·콘텐츠 편집

- 과제: 메시지·시청 맥락·원본 자료 상태를 구분한다
- 과정: 소재 확인 → 구성 → 초벌 편집 → 피드백 → 색·음향 → 출력
- 산출물: 버전별 영상·자막·출력 규격표
- 협업: 기획자·출연자·사운드 담당자와 장면 의도를 맞춤
- 어려움: 촬영 자료의 부족을 편집 기술만으로 모두 해결할 수 없다
- 맞을 조건: 검토 시점을 나누고 메시지 변경을 새 범위로 인정하는 환경
- 불편할 조건: 최종 단계에 이야기 전체를 바꾸면서 납기를 유지하라는 환경
- 추가 배움: 컷의 순서·음성 명료도·자막 가독성의 선택 비교
- 검증: 소리 없이도 핵심이 전달되는지, 실제 출력 환경에서 검토
- 경제 질문: 촬영 재요청·자료 정리·렌더링·추가 버전의 시간을 구분
- 작은 실험: 같은 소재로 길이가 다른 두 영상을 구성해 차이를 설명
- 가상 장면: 행사용 긴 영상을 짧은 세로 광고로 바꾸라는 가상 요청
- 분류 관찰: freelancer: unknown → unknown / employee: unknown → unknown / student: unknown → unknown
- 제한: 영상이라는 단어는 일부 시각 연출만 보강하며 편집 세부 function은 unknown

## 전문 번역·언어 중개

- 과제: 독자·전문 분야·용어 기준·사용 목적을 확인
- 과정: 원문 이해 → 용어 확인 → 초벌 → 대조 → 독자 검수 → 납품
- 산출물: 번역문·용어표·불명확한 원문의 질의
- 협업: 작성자와 이용자 사이에서 의미와 표현 제약을 중개
- 어려움: 매끄러운 문장도 핵심 조건을 바꾸면 좋은 번역이 아니다
- 맞을 조건: 질문할 담당자와 용어 결정 기준이 있는 의뢰
- 불편할 조건: 원문이 바뀌는데 최종 분량만으로 작업을 계산하는 의뢰
- 추가 배움: 병렬 문장 대조·용어 근거·분야별 문체
- 검증: 핵심 조건과 숫자를 원문에 되짚어 오류를 확인
- 경제 질문: 문자 수 외 조사·질의·검수·변경된 원문의 재작업을 구분
- 작은 실험: 짧은 안내문을 다른 독자용으로 옮기고 선택 이유 설명
- 가상 장면: 약어가 다른 뜻으로 쓰인 두 문서를 통일해야 하는 가상 의뢰
- 분류 관찰: freelancer: unknown → language_mediation / employee: unknown → language_mediation
- 제한: language_mediation 장면 자료는 있지만 현재 문자열 번역가의 직접 분류는 unknown

## 교육·강의

- 과제: 학습자가 지금 혼자 할 수 있는 것과 수업 목적을 묻는다
- 과정: 선행 이해 확인 → 설명 → 연습 → 오류 피드백 → 다른 문제 적용
- 산출물: 수업 자료·학습 과제·이해 확인 기록
- 협업: 학습자·보호자·동료와 기대하는 변화를 구분
- 어려움: 수업 만족도와 혼자 풀 수 있는 실력은 다르다
- 맞을 조건: 준비와 개별 피드백 시간을 인정하는 교육 환경
- 불편할 조건: 수업 시간만 계산하면서 상시 상담을 당연시하는 환경
- 추가 배움: 오개념 분류·설명 대안·평가 과제 설계
- 검증: 익숙한 예제 밖에서도 원리를 설명할 수 있는지 확인
- 경제 질문: 준비·채점·질문 응대가 강의 시간 밖의 비용
- 작은 실험: 같은 개념을 두 방식으로 설명하고 다른 문제를 제시
- 가상 장면: 설명을 따라 했지만 조건을 바꾸자 막힌 가상 학습자
- 분류 관찰: employee: teaching → teaching / freelancer: teaching → teaching / self_employed: teaching → teaching
- 제한: 자격 요건·과목·실제 학습자 나이는 입력 없이 확정하지 않음

## 의료·돌봄 지원

- 과제: 직무 권한과 안전 절차, 인계할 관찰 정보를 확인
- 과정: 상태 확인 → 정해진 지원 → 변화 기록 → 담당자 전달 → 인계
- 산출물: 허용된 범위의 관찰·인계 기록
- 협업: 대상자·보호자·다음 담당자에게 사실과 추정을 구분해 전달
- 어려움: 친절과 의료 판단 권한은 별개다
- 맞을 조건: 확인 절차와 인계·휴식 시간을 실제 보장하는 환경
- 불편할 조건: 안전 확인을 속도 문제로 취급하고 개인 희생으로 메우는 환경
- 추가 배움: 허용된 업무 절차·사례 기록·정확한 보고
- 검증: 누락 없는 전달과 확인 경로로 평가하며 치료 결과를 약속하지 않음
- 경제 질문: 인력·대기·응대 부담은 개인 성향만으로 해결할 문제가 아니다
- 작은 실험: 익명 가상 인계에서 관찰과 해석을 나누기
- 가상 장면: 기록과 대상자의 설명이 달라 재확인하는 가상 인계
- 분류 관찰: employee: care_operations → care_operations
- 제한: 건강 예측·진단·치료 조언 및 자격 없는 업무 추천 금지

## 상담·지원 업무

- 과제: 요청한 도움과 제공 가능한 지원 범위를 먼저 묻는다
- 과정: 경청 → 요청 명료화 → 지원 가능 범위 → 관련 기관 연결 → 종결 확인
- 산출물: 동의된 지원 계획·연결 정보
- 협업: 상대의 선택권을 남기며 전문 기관과 범위를 나눔
- 어려움: 잘 공감하는 것과 전문 치료를 할 수 있는 것은 다르다
- 맞을 조건: 비밀보호·슈퍼비전·역할 경계가 명확한 환경
- 불편할 조건: 모든 어려움을 한 담당자가 해결하도록 맡기는 환경
- 추가 배움: 질문·기록·경계·적절한 의뢰 절차
- 검증: 상대가 원하는 도움과 실제 연결이 맞는지 확인
- 경제 질문: 사례 준비·후속 연락·회복 시간을 업무 범위에 포함
- 작은 실험: 가상 요청에서 정보 제공과 전문 의뢰를 구분

- 분류 관찰: employee: unknown → unknown / freelancer: unknown → unknown

## 글·정보 콘텐츠

- 과제: 독자가 해결할 질문과 확인 가능한 자료를 나눈다
- 과정: 질문 → 취재 또는 자료 확인 → 구성 → 초고 → 검증 → 편집
- 산출물: 독자 질문에 답하는 글·출처·편집 기준
- 협업: 자료 제공자와 편집자의 뜻을 바꾸지 않고 독자에게 전달
- 어려움: 문장이 매끄러워도 근거 없는 내용이 정확해지지는 않는다
- 맞을 조건: 검증과 편집 시간을 구분해 주는 환경
- 불편할 조건: 조회만을 위해 과장된 결론을 요구하는 환경
- 추가 배움: 자료 대조·구성·퇴고·용어 설명
- 검증: 처음 보는 독자가 주장과 근거를 구분하는지
- 경제 질문: 조사·자료 사용 허가·수정과 매체 변경의 투입
- 작은 실험: 가상 설명문에서 사실·의견·예시를 표시
- 가상 장면: 인터뷰 인용과 편집자의 추론이 섞인 가상 초고
- 분류 관찰: freelancer: unknown → unknown / employee: unknown → unknown / student: unknown → unknown
- 제한: 작가가 visual 보강에 걸려도 실제 function unknown이며 경력 생성 금지

## 미용·공방 등 손기술 서비스

- 과제: 고객의 원하는 결과와 재료·시간·안전 제약을 확인
- 과정: 상담 → 가능 범위 설명 → 작업 → 중간 확인 → 관리 안내
- 산출물: 합의한 범위의 완성 서비스·이후 안내
- 협업: 고객의 취향과 가능한 작업 범위를 명확히 조율
- 어려움: 새로운 표현과 반복 가능한 품질은 별도 숙련이다
- 맞을 조건: 사전 확인과 중간 점검 시간을 인정하는 환경
- 불편할 조건: 고객 요청을 모두 가능하다고 답하게 하는 환경
- 추가 배움: 모형·연습 재료로 과정과 품질 비교
- 검증: 조건이 다른 재료에서도 같은 기준을 지키는지
- 경제 질문: 재료·재작업·예약 사이 준비·정리 시간을 구분
- 작은 실험: 가상 요청에서 가능한 결과와 어려운 부분 설명
- 가상 장면: 참고 결과와 실제 재료 조건이 다른 가상 요청
- 분류 관찰: self_employed: customer_service → customer_service / employee: customer_service → customer_service / freelancer: customer_service → customer_service
- 제한: 전문 시술이나 건강·위생 기준의 대체 지침이 아님
