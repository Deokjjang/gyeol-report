# 경제적 가치·수익·투입

실제 정형 자료는 신규 CH06 Materials에 있다. 아래는 전체 해당 재료의 읽기 문서이며 별도 신규 레코드 수로 합산하지 않는다.

## ckr:material:CH06.P1:wealth-not-balance

재성 상징·수입 선호·실제 자산 정보는 서로 다르다

반복 가치와 자원을 살피는 수익 활동 후보

정재의 계산 근거는 원국의 분류로 한정

ISTJ의 안정 수입 선호도 실제 소득 자료는 아님

누구에게 무엇을 계속 제공할지로 경제 질문 전환

경제: 반복 제공·유지·변경에 드는 투입 구분

학습: 같은 품질을 다른 조건에 제공할 과제

위험/팩폭: 재성을 실제 부나 안정 수입의 보증으로 읽음 / 돈을 차곡차곡 남기고 싶어도 확보한 돈의 양은 별도 사실

조건/반례: 자산·급여·수익률을 추정하지 않음

실행: 원국 재성·본인 유형·실제 과제를 따로 확인

## ckr:material:CH06.P1:opportunity-to-demand

새 기회 상징을 실제 수요를 묻는 과정으로 제한

수익 관련 질문은 관심을 제공 가능한 결과로 좁히는 것

편재 상징은 거래 성공이나 재산이 아님

ENTP 원천의 아이디어 수익 필터를 별도 선호로 확인

실제 필요한 사용처와 제공 조건을 질문

경제: 준비·제작·응대 투입과 실제 거래는 별도

학습: 작은 제안의 반응을 기록

위험/팩폭: 관심 반응을 매출 확정으로 볼 수 있음 / 좋은 아이디어가 많아도 누가 어떤 결과를 필요한지는 비어 있을 수 있음

조건/반례: 사주·MBTI로 사업 성공을 보장하지 않음

실행: 등록 조건과 실제 수요 자료를 확인

## ckr:material:CH06.P1:expertise-value

전문성을 돈으로 설명하려면 다른 사람의 판단에 쓸 결과가 필요

깊이 아는 것과 값을 지불할 결과를 구분

실제 MBTI 전문성 수입 원천도 시장 검증과 별개

가상 조사로 불확실했던 결정의 조건을 좁힘

시간 대신 해결할 질문과 결과의 한계를 설명

경제: 조사 범위·자료 접근·추가 확인 투입 분리

학습: 복잡한 설명을 결정 자료로 요약

위험/팩폭: 오래 조사한 것을 높은 가치로 동일시 / 노력한 시간이 길어도 의뢰인의 질문과 다르면 쓸 수 없음

조건/반례: 시장 가격·수입 규모·전문 자격은 보장하지 않음

실행: 실제 사용자·과제·사용 조건부터 확인

## ckr:material:CH06.P1:service-value

지원의 경제적 가치는 대신한 양보다 해결한 막힘에서 설명

서비스 선호를 실제 제공할 결과와 비교

친절 원천은 현재 수입이나 고객 만족 자료가 아님

가상 안내로 반복 문의의 원인을 없앰

제공 범위와 준비·후속 지원 조건이 있어야 지속

경제: 응대·자료 유지·후속 연결 시간을 구분

학습: 지원 전후에 혼자 할 수 있는 단계 확인

위험/팩폭: 고마움을 보상 합의로 착각 / 좋은 관계가 준비와 추가 응대의 투입을 자동 보상하지 않음

조건/반례: 현재 고객 수·실적·금액을 만들지 않음

실행: 값을 받을 결과와 호의를 구분

## ckr:material:CH06.P1:skill-to-use

기술을 안다는 사실과 사용할 결과를 제공하는 것은 다르다

기술 문제 해결을 수익 활동의 후보로 검토

기술 수입 원천도 실제 숙련과 거래를 증명하지 않음

가상 도구가 반복 작업의 어느 단계를 바꾸는지 확인

사용·유지·설명 범위를 정해야 기여를 설명

경제: 구현·설치·유지·지원 투입 구분

학습: 다른 입력과 환경에서도 검증

위험/팩폭: 작동하는 결과면 사용자는 저절로 생긴다고 생각 / 제작 후 지원과 유지가 비어 있으면 제공 약속을 지키기 어려움

조건/반례: 수입·계약·기술 자격 자동 확정 금지

실행: 필요한 문제와 제공할 범위를 먼저 질문

## ckr:material:CH06.P2:photo-use-value

사진 결과의 가치는 촬영량보다 실제 사용할 목적과 조건

검증한 표현 재능이 있을 때만 후보

식신 근거는 작품·납품 능력의 증명이 아님

가상 상세페이지에서 필요한 정보가 보이는 컷 선택

사용 매체·규격·수정 범위를 합의해야 제공 가치

경제: 준비·현장·보정·사용 범위·출력 버전의 투입

학습: 용도별 선정 기준을 작은 견본으로 설명

위험/팩폭: 작품 완성도만 대가의 근거로 사용 / 촬영이 빨라도 선별·보정·응대가 작업 전체를 늘릴 수 있음

조건/반례: 고객·가격·장비·이전 계약을 추정하지 않음

실행: 실제 의뢰의 목적을 확인한 뒤 범위 질문

## ckr:material:CH06.P2:employee-contribution

직장인 기여는 수행량과 의사결정 변화의 차이

검증된 검토 재능의 실제 역할만 설명

원천은 보상 수준의 근거가 아님

가상 예산 자료가 부서의 비교 질문을 명확히 함

어떤 자료로 무엇을 바꿨는지 남겨 평가에 쓸 수 있음

경제: 재처리 시간·자료 준비·검토 투입 분리

학습: 성과 설명에서 외부 조건과 자기 기여 구분

위험/팩폭: 모든 절감과 최종 성과를 자신의 공으로 귀속 / 큰 결과와 내 작업 사이의 기여를 따로 확인해야 함

조건/반례: 급여 인상·승진·실제 회사 절감액 보장 금지

실행: 실제 평가 기준과 관찰된 결과를 확인

## ckr:material:CH06.P2:cafe-unit-value

자영업의 상품 가치는 판매 뒤 남는 자원과 반복 품질을 함께 본다

검증된 운영 강점의 과제에 한정

재성은 실제 이익을 증명하지 않음

가상 메뉴의 준비·제공·폐기·정리 투입을 나눔

판매량과 운영 부담을 따로 확인해야 확대를 비교

경제: 재료·폐기·고정 부담·시간은 서로 다른 항목

학습: 조건 하나를 바꾼 운영 비교

위험/팩폭: 매출이 큰 상품이 항상 유리하다고 판단 / 많이 팔려도 다른 주문을 밀면 전체 기여는 다를 수 있음

조건/반례: 판매량·원가·이익 수치를 추정하지 않음

실행: 실제 자료가 있는 상품 하나부터 질문

## ckr:material:CH06.P2:learning-investment-value

배움에 쓴 자원은 제공 가능한 수행이 달라질 때 가치로 연결

검증된 학습 강점을 작은 설명 결과에 적용

성장 수입 원천이 교육비 회수를 보장하지 않음

가상 과제에서 새 설명 방식이 혼자 이해할 범위를 넓힘

수료보다 적용할 문제와 검증을 먼저 확인

경제: 과정비·재료·연습·기회비용을 나눔

학습: 같은 개념을 새 조건에서 설명

위험/팩폭: 교육 과정을 늘리면 경제적 가치도 늘 거라 기대 / 배운 분야가 많아도 실제 맡을 과제가 없으면 쓰임은 미확인

조건/반례: 학비 회수·채용·합격·수입 증가를 보장하지 않음

실행: 현재 필요한 수행을 먼저 정의

## ckr:material:CH06.P2:business-repeat-value

운영 전문성의 값은 대표 없이도 이어질 결과에서 설명

검증된 운영 기능과 실제 조직 조건이 있을 때

운영 수입 원천은 현재 사업 규모가 아님

가상 반복 업무를 다른 담당자가 같은 기준으로 완료

위임할 결과·질문·유지 책임을 명확히 함

경제: 자료 작성·유지·교육·대표 개입 투입 구분

학습: 기준을 처음 보는 사람이 수행하는지

위험/팩폭: 표준 문서의 양을 운영 가치로 착각 / 문서가 많아도 사용자가 찾지 못하면 대표 질문은 줄지 않음

조건/반례: 매출·직원 존재·확장 성공을 추정하지 않음

실행: 실제 사람과 권한을 먼저 확인

## ckr:material:CH06.P3:unpriced-revision

호의로 남긴 추가 수정이 보이지 않는 작업 범위가 될 수 있다

가능한 약점은 수정의 종류를 구분하지 않는 것

저평가 원천은 실제 손실 경험을 증명하지 않음

가상 납품 뒤 새 용도에 맞춘 재보정을 요청

같은 목적 수정과 새 목적 제작을 나눔

경제: 수정 횟수보다 목적 변경과 필요한 투입 확인

학습: 수정 요청을 작업 단계로 분류

위험/팩폭: 좋은 관계를 깨기 싫어 범위 확인을 미룸 / 조금만 고쳐달라는 말이 여러 버전과 재선별을 포함할 수 있음

조건/반례: 법적 계약 효력을 단정하거나 실제 단가 제시하지 않음

실행: 제공 범위와 새 요청의 차이를 설명

## ckr:material:CH06.P3:tool-demand-gap

장비·도구를 갖추는 것과 실제 수요를 충족하는 것은 다르다

가능한 위험은 도구의 향상을 수행 향상과 동일시

취미 도구 예산 원천은 실제 구매 사실이 아님

가상 새 렌즈가 해결할 납품 제약이 있는지 비교

현재 도구로 못 하는 과제부터 확인

경제: 구입·임차·관리·학습·사용 빈도의 투입 구분

학습: 장비 설명보다 실제 결과를 대조

위험/팩폭: 갖고 싶은 기능을 필수 업무 비용으로 설명 / 새 도구를 사도 선택·보정·설명 문제는 그대로일 수 있음

조건/반례: 장비 투자 수익·감가 금액·구매 추천을 제공하지 않음

실행: 필요와 욕구를 다른 질문으로 적기

## ckr:material:CH06.P3:fast-commitment

속도를 얻는 지출은 검증·변경 비용도 함께 비교

가능한 위험은 시간 절약을 무조건 효율로 보는 것

속도를 위한 소비 원천은 실제 지출 이력 아님

가상 도구가 준비를 줄이지만 바꾸기 어려운 조건을 만듦

되돌릴 범위와 사용 목적을 먼저 확인

경제: 초기·유지·전환·검증 투입 구분

학습: 대표 과제 하나로 실제 작동 시험

위험/팩폭: 급한 일정 때문에 불명확한 제공 범위를 수락 / 지금 빨라진 만큼 다음 선택의 자유가 줄어들 수 있음

조건/반례: 구매·투자 수익을 권하거나 실제 계약 조건을 단정하지 않음

실행: 취소·변경 가능한 조건은 실제 자료로 확인

## ckr:material:CH06.P3:many-opportunities-cost

새 기회마다 준비하면 미룬 약속과 시간이 비용이 된다

가능한 위험은 좋은 제안을 모두 병렬로 받는 것

프로젝트 비용 확장 원천은 실제 손실을 뜻하지 않음

가상 캠페인 세 개가 같은 제작 시간을 요구

이번 선택으로 하지 않을 일을 먼저 남김

경제: 기회비용은 예상 수익이 아니라 포기할 실제 활동으로 설명

학습: 가설 하나당 작은 완료 과제

위험/팩폭: 관심을 잃기 전에 시작해야 한다고 생각 / 시작이 늘어도 사용할 결과는 적을 수 있음

조건/반례: 소득 변동이나 실패를 유형의 운명으로 만들지 않음

실행: 동시에 할 수 있는 실제 범위를 질문

## ckr:material:CH06.P3:help-hidden-cost

지원 범위가 없으면 돈보다 먼저 시간이 소진될 수 있다

가능한 약점은 준비·후속 연락을 계산 밖에 두는 것

지원 한도 원천은 실제 과소득 근거가 아님

가상 정보 지원 뒤 여러 채널로 후속 요청

제공할 결과와 다음 전문 연결을 나눔

경제: 준비·응대·연결·회복의 투입 구분

학습: 정보 제공과 전문 지원을 구분하는 연습

위험/팩폭: 상대가 힘들다는 이유로 모든 후속 지원을 맡음 / 좋은 목적이 실제 자원 한도를 없애지는 않음

조건/반례: 진단·치료·금전 구제 책임을 추정하지 않음

실행: 도움 범위와 종료 기준을 먼저 확인

## ckr:material:CH06.P4:cashflow-timing

예상 의뢰·합의한 대가·실제 확보한 자원은 다르다

관리 원칙은 발생과 회수 시점을 구분

원천의 불규칙 수입 완충은 실제 수입 자료 아님

가상 의뢰 완료와 대금 확인 시점이 다른 상황

생활과 다음 작업에 쓸 자원을 따로 질문

경제: 작업 비용과 개인 생활비는 별도 확인

학습: 제작 일정과 자원 일정 함께 보기

위험/팩폭: 예상 수입을 이미 쓸 수 있는 돈으로 취급 / 바쁜 달의 의뢰량이 다음 달의 확보 자원을 보장하지 않음

조건/반례: 개인 금융 권고·저축 비율·금액 처방 금지

실행: 실제 계약 자료와 확보 상태만 사용

## ckr:material:CH06.P4:fixed-variable-time

고정 부담·상품별 투입·보이지 않는 시간은 다른 자원 항목

관리 원칙은 매출 합계 하나로 판단하지 않는 것

원국 재성은 비용 자료가 아님

가상 상품의 재료와 준비·마감 시간을 따로 기록

항목별 조정 가능성을 비교

경제: 고정·변동·시간을 구별하되 수치를 만들어내지 않음

학습: 작은 기간의 실제 투입 기록 연습

위험/팩폭: 시간을 무료 자원처럼 제외 / 판매가 늘어도 정리 시간이 밀리면 반복할 여유는 줄 수 있음

조건/반례: 세무·투자·특정 사업 손익의 결론으로 사용하지 않음

실행: 자료가 있는 항목만 비교

## ckr:material:CH06.P4:value-not-cheapest

싼 선택과 전체 부담이 적은 선택은 다를 수 있다

관리 원칙은 최초 가격과 사용할 조건의 분리

계약 비용 선호 원천은 실제 선택의 정답이 아님

가상 도구의 준비·유지·전환 시간을 비교

같은 결과를 제공할 조건이 맞는지 확인

경제: 초기·유지·변경의 자원 구분

학습: 대표 과제에서 혼자 사용할 수 있는지

위험/팩폭: 최초 가격만 비교해 장기 부담을 놓침 / 싸게 시작했어도 바꾸기 어렵다면 다음 비용이 커질 수 있음

조건/반례: 특정 상품 구매나 미래 절감액을 보장하지 않음

실행: 실제 가격·제공 범위·중단 조건을 확인

## ckr:material:CH06.P4:learning-budget-question

배움의 지출은 적용할 과제와 연습 시간을 함께 정한다

관리 원칙은 과정 선택과 활용 계획의 분리

가능성 소비 원천이 실제 지출 사실은 아님

가상 새 기법 과정에 과제·피드백·연습 시간 확인

이번 배움으로 할 수 있는 결과를 먼저 정의

경제: 과정·재료·도구·연습 투입을 분리

학습: 수강 전후 다른 조건의 수행 비교

위험/팩폭: 새 과정이 나타날 때 기존 연습을 미룸 / 수료증이 늘어도 도움 없이 만들 결과가 같을 수 있음

조건/반례: 교육비 회수·취업·합격을 보장하지 않음

실행: 필요한 기능과 실제 학습 여유를 확인

## ckr:material:CH06.P4:reserve-options

관리의 목적은 큰돈의 예측보다 다음 선택의 여지를 남기는 것

확보 자원과 기대를 나누는 원칙

축적 원천은 현재 자산의 양을 알려주지 않음

가상 새 역할에서 생활·배움·휴식의 제약을 비교

실제 제공된 자료로만 감당할 범위를 질문

경제: 생활 자원과 새 준비 투입을 별도로 확인

학습: 작은 검증 후 선택을 수정하는 연습

위험/팩폭: 모든 불확실성을 피하려 선택을 미룸 / 안정만 지키면 배울 기회도 계속 뒤로 갈 수 있음

조건/반례: 금융 자문·자산 예측·수익 보장으로 사용하지 않음

실행: 숫자 처방 대신 확인할 조건을 남김
