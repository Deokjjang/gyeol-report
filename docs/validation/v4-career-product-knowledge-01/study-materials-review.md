# 배움·기술·전문성

실제 정형 자료는 신규 CH07 Materials에 있다. 아래는 전체 해당 재료의 읽기 문서이며 별도 신규 레코드 수로 합산하지 않는다.

## ckr:material:CH07.P1:concept-structure

개념을 연결해 이해하는 방식과 실제 적용을 구분

학습 특징 후보는 개념 사이의 관계를 묻는 것

INTJ의 깊은 프로젝트 학습 원천을 실제 입력에서 확인

정인의 배움 상징은 지능·학력의 증명이 아님

자료를 덮고 다른 조건의 문제에 적용

경제: 읽기·자료 수집·실습 투입을 따로 봄

학습: 같은 개념의 반례를 설명

위험/팩폭: 원리를 모두 이해할 때까지 수행을 미룸 / 잘 이해한 느낌이 도움 없이 답할 능력은 아닐 수 있음

조건/반례: 원국이나 실제 유형 없으면 양측 결합을 보류

실행: 명리와 MBTI의 범위를 나눠 확인

## ckr:material:CH07.P1:learn-by-doing

실습으로 익힌 요령을 원리와 적용 조건으로 남기는 학습

직접 해보는 선호를 낮은 위험의 과제에 적용

ISTP 원천은 실제 손기술 수준이 아님

식신 상징과 원래 Fusion feature 조건을 확인

잘된 조건·안 된 조건을 설명으로 남김

경제: 실습 도구와 배우는 시간 투입

학습: 실패 조건을 원리 이름과 연결

위험/팩폭: 작동한 한 번으로 원리를 안다고 판단 / 도구를 쓸 수 있어도 왜 실패했는지 모르면 전이가 어려움

조건/반례: 안전 위험이 있는 실전 시행착오 권장 금지

실행: Fusion 원조건과 허용된 실습 범위 확인

## ckr:material:CH07.P1:learn-by-explain

함께 설명하며 배운 이해를 혼자 쓸 수 있는지 확인

사회적 학습 선호를 짧은 설명 과제에 연결

실제 학업 원천을 확인하되 성적 예측은 하지 않음

인성 상징은 배움 조건으로만 읽음

대화 뒤 자료 없이 자기 답안을 작성

경제: 모임 시간과 개인 연습 시간을 구분

학습: 다시 설명할 때 빠진 전제를 찾기

위험/팩폭: 모두 이해한 느낌을 자기 이해로 오인 / 친구의 설명을 따라 말하는 것과 혼자 원리를 쓰는 것은 다름

조건/반례: 타인의 실제 성과·유형을 만들어내지 않음

실행: 함께 학습과 혼자 수행을 따로 확인

## ckr:material:CH07.P1:story-to-rule

이야기로 붙인 관심을 정확한 개념과 풀이로 연결

낯선 개념을 구체 상황으로 바꾸는 선호

INFP의 이야기 학습 원천은 언어 점수 근거가 아님

식신 표현 상징은 실제 학습 행동 확인이 필요

예시를 벗어난 조건에서도 같은 원리를 설명

경제: 자료 제작과 필수 연습의 시간 구분

학습: 예시에서 바뀌면 답이 달라질 조건 찾기

위험/팩폭: 흥미로운 이야기만 남고 정의를 놓칠 수 있음 / 재미있게 기억해도 풀이에 필요한 조건은 빠질 수 있음

조건/반례: 학업 성과·지능·언어 능력을 유형으로 단정하지 않음

실행: 정의·예시·반례를 세 칸으로 작성

## ckr:material:CH07.P1:structured-practice

분량의 완료와 이해의 확인을 다른 학습 기록으로 남기기

꾸준한 학습 선호를 단계별 과제에 연결

ISFJ 원천은 시험 결과가 아님

관성 상징은 현재 규칙 분류·원국 조건 확인

같은 문제의 조건을 바꾸어 혼자 풀이

경제: 정리·반복·응용 연습의 시간 구분

학습: 기존 문제와 새 문제를 나란히 검토

위험/팩폭: 분량을 채운 날이면 이해도 끝났다고 느낌 / 반복한 시간이 많아도 새로운 질문에서는 막힐 수 있음

조건/반례: 정확한 출생시간이 있어도 학업 능력을 보장하지 않음

실행: 완료량과 혼자 설명한 범위를 따로 기록

## ckr:material:CH07.P2:photo-light-comparison

사진 기술은 조명 선택과 납품 목적을 같은 과제로 비교

흥미는 실제 촬영 과제를 통해 확인

실습 선호는 촬영 숙련의 근거가 아님

같은 대상의 광원 방향 하나만 바꿔 비교

바뀐 정보·분위기와 사용 조건을 설명

경제: 장비·연습·선별·보정 투입 구분

학습: 동일 목적에서 한 조건만 바꾸기

위험/팩폭: 새 기법의 화려함을 목적 충족으로 착각 / 기법을 배웠어도 사용자가 필요한 디테일이 사라질 수 있음

조건/반례: 실제 수요·장비 보유·고객 반응을 추정하지 않음

실행: 학습 전후 납품 기준으로 비교

## ckr:material:CH07.P2:dev-new-input

개발 학습 환경은 실패 입력을 시험하고 이유를 물을 수 있어야 함

흥미 분야와 혼자 수행하는 능력은 분리

원천의 수학·과학 관심을 지능 판정으로 쓰지 않음

예제 밖의 누락 입력에서 코드가 달라지는지 확인

실패를 설명할 피드백과 질문 통로를 찾음

경제: 강의·실습·재현·피드백 시간 구분

학습: 의도한 결과와 실제 실패 이유를 설명

위험/팩폭: 예제를 따라친 것을 새 문제 해결로 인식 / 강의를 이해해도 입력이 바뀌면 같은 함수를 못 만들 수 있음

조건/반례: 고객 서비스·실전 데이터로 위험한 실험 금지

실행: 다른 조건에서 도움 없이 수행

## ckr:material:CH07.P2:design-constraint-learning

디자인 학습은 매체 제약을 바꿔 표현의 이유를 확인

예술 흥미는 전공 적합성 확정이 아님

실제 원천과 과제 목적을 함께 확인

같은 내용을 큰 포스터와 작은 화면에 옮김

다른 조건에서도 전달할 정보를 지키는 연습

경제: 도구·제작·피드백 투입 구분

학습: 작은 화면의 읽기 순서 비교

위험/팩폭: 좋아하는 표현만 반복 / 많은 기법이 있어도 읽히지 않는 결과의 이유는 따로 확인해야 함

조건/반례: 학생에게 고객·계약 경험을 만들지 않음

실행: 매체·대상·필수 정보부터 정리

## ckr:material:CH07.P2:finance-scenario-learning

재무 학습은 같은 합계에서 다른 가정을 구별하는 과제

학습 근거는 새 유형에 적응하는 원천

현재 재무 전문성은 별도 확인

가격·수량·시점을 바꾼 가상 전망을 비교

숫자뿐 아니라 왜 달라졌는지 설명하는 환경

경제: 교재·자료 정리·검증 투입 구분

학습: 가정을 한 개씩 바꿔 설명

위험/팩폭: 익숙한 답의 형태만 반복 / 계산 결과가 같아도 의사결정의 조건은 다를 수 있음

조건/반례: 실제 사업 전망·투자 판단을 예측하지 않음

실행: 새 조건의 반례와 피드백 확보

## ckr:material:CH07.P2:field-anomaly-learning

현장 학습은 정상 순서와 이상을 전달할 조건을 같이 익히기

반복 확인 원천을 허용된 훈련에 한정

손기술 선호는 안전 능력의 증명이 아님

가상 지연 기록에서 어느 단계에 전달할지 고름

실습과 피드백은 실제 권한·안전 조건 안에서만

경제: 교육·확인·인계 투입의 구분

학습: 표준과 예외를 비교하는 사례 검토

위험/팩폭: 대응 속도가 빠르면 확인을 생략할 수 있다고 생각 / 개인이 고쳤다고 다음 공정의 안전이 확인된 것은 아님

조건/반례: 설비·위험 작업을 임의 시험하는 행동 금지

실행: 실제 교육 담당과 허용 범위 확인

## ckr:material:CH07.P3:collecting-not-learning

새 자료 수집의 즐거움이 실제 수행 연습을 밀 수 있다

가능한 실수는 모으는 것을 익히는 것으로 보는 것

관심 전환 원천과 실제 학습 습관은 구분

가상 자료 탭은 늘지만 설명 초고는 비어 있음

작은 완성 과제로 배운 범위를 확인

경제: 수집·읽기·작성 시간 구분

학습: 자료 없이 핵심을 다시 설명

위험/팩폭: 새 주제가 생길 때 필수 반복을 미룸 / 자료 목록이 길어도 도움 없이 쓸 내용은 적을 수 있음

조건/반례: 새로운 자료가 실제 필수 정보일 때는 수집을 무조건 줄이지 않음

실행: 이번에 완성할 결과 하나 정하기

## ckr:material:CH07.P3:familiarity-trap

익숙함과 원리 이해의 차이를 확인하는 약점 연구

가능한 실수는 답을 알아보는 느낌에 의존

연결 학습 필요 원천은 개인의 낮은 능력 판정 아님

가상 예제의 조건이 바뀌면 답의 이유를 못 찾음

답을 가리고 다른 조건의 풀이를 설명

경제: 반복·오답·전이 연습의 시간 구분

학습: 왜 답이 달라지는지 설명

위험/팩폭: 아는 문제만 더 오래 반복 / 연습량이 많아도 바뀐 전제를 읽지 못하면 새 문제는 다름

조건/반례: 실제 성적·시험 불안·학습 장애를 추정하지 않음

실행: 조건 하나를 바꾼 문제 추가

## ckr:material:CH07.P3:perfection-start

충분히 이해해야 시작한다는 기준이 수행 기회를 늦출 수 있다

가능한 실수는 준비를 제출의 선행 조건으로 끝없이 확대

완벽주의 시작 원천은 실제 지연 경험이 아님

가상 분석 자료가 늘지만 작은 결과를 작성하지 않음

필수 설명부터 만들고 미확인 질문은 따로 남김

경제: 추가 읽기와 결과 작성 시간의 균형

학습: 필수 주장 하나를 자료 없이 설명

위험/팩폭: 모르는 것을 전부 해결해야 결과가 유효하다고 느낌 / 한계가 남아도 쓸 수 있는 발견을 숨길 수 있음

조건/반례: 안전·정확성상 필수 검증을 생략하라는 뜻이 아님

실행: 작은 제출 기준을 먼저 정하기

## ckr:material:CH07.P3:activity-to-language

직접 했던 선택을 용어와 이유로 남겨 다른 조건에 옮기기

가능한 실수는 잘된 장면의 느낌만 기억

짧은 오류 기록 원천은 필기 능력의 판정이 아님

가상 촬영에서 빛을 바꿨지만 왜 나아졌는지 설명이 없음

잘된 조건·안 된 조건을 짧게 비교

경제: 실습·선별·재시험 투입

학습: 실패 컷에서 바꿀 한 조건 설명

위험/팩폭: 기록은 실습을 방해하는 일이라고 여김 / 새 장비에서도 같은 결과를 내려면 손의 요령 밖의 설명이 필요

조건/반례: 실제 사진 촬영 경험과 장비를 보충하지 않음

실행: 실습 뒤 짧은 이유 기록

## ckr:material:CH07.P3:social-solo-gap

함께 잘 설명해도 혼자 꺼낼 지식은 따로 확인해야 한다

가능한 실수는 모임의 이해를 개인 수행과 동일시

보호된 개인 공부 시간 원천은 내향성 판정 아님

가상 학습 대화는 끝났지만 개인 풀이에서 막힘

모임 뒤 짧은 독립 과제와 다시 설명을 연결

경제: 모임·개인 연습·후속 질문의 시간 구분

학습: 자기 풀이의 누락 전제를 찾기

위험/팩폭: 다른 사람을 도우며 자기 약점을 확인할 시간을 잃음 / 공부를 오래 함께해도 내 답안의 빈칸은 남을 수 있음

조건/반례: 실제 친구·학습 모임이 있다고 추정하지 않음

실행: 함께 학습 후 혼자 확인 구간 확보

## ckr:material:CH07.P4:certificate-requirement

자격의 이름과 맡을 업무에 필요한 조건을 분리

발전할 능력은 분야 기준을 과제에 적용하는 것

매뉴얼 학습 원천이 합격·자격을 증명하지 않음

가상 공고의 요구와 교육 과정의 실습을 대조

필요한 제도 요건은 실제 최신 자료로 별도 확인

경제: 교육비·시험 준비·실습 시간 구분

학습: 설명 없이 새로운 사례를 처리하는 연습

위험/팩폭: 자격을 따면 수행과 취업도 자동 해결된다고 기대 / 증서는 필요 조건일 수 있어도 모든 업무 능력을 보장하지 않음

조건/반례: 특정 자격 취득 권고·합격·채용 보장 금지

실행: 실제 공고·과정·권한의 조건부터 확인

## ckr:material:CH07.P4:portfolio-decision

포트폴리오는 좋은 화면뿐 아니라 판단 과정을 보여주는 자료

발전할 능력은 목적·대안·선택·검증 설명

전략 자산 원천은 실제 포트폴리오 보유 정보가 아님

가상 시안에서 왜 한 안을 버렸는지 정리

과제의 조건과 개인 기여를 구분해 보여줌

경제: 자료 정리와 새 제작 투입을 구분

학습: 다른 사람이 이유를 따라갈 수 있는지

위험/팩폭: 선택 결과를 실제 고객 성과로 과장 / 예쁜 완성 화면은 요구와 자신의 판단을 모두 설명하지 않음

조건/반례: 없는 의뢰·고객·계약·성과를 경력으로 쓰지 않음

실행: 가상 과제임을 표시하고 수행한 범위만 적기

## ckr:material:CH07.P4:work-based-upskill

일하면서 배울 기술은 실제 빈틈과 안전한 연습을 연결

발전할 능력은 익힌 도구를 기존 문제에 맞게 사용하는 것

실습 연결 원천은 현재 업무 경험 아님

가상 반복 오류를 작은 연습 환경에서 재현

기존 방식보다 무엇이 나아졌는지 확인

경제: 연습·검토·도입·유지 투입을 구분

학습: 다른 입력의 실패 조건 확인

위험/팩폭: 새 도구를 배우자마자 실전 전부를 바꿈 / 기술을 안다고 연결부·유지 조건까지 확인한 것은 아님

조건/반례: 고객 데이터·실전 시스템 임의 변경 지침 금지

실행: 실전 권한과 안전한 검증부터 확인

## ckr:material:CH07.P4:career-change-learning

전환을 위한 배움은 현재 생활과 다시 할 수 있는 범위를 먼저 확인

발전 과제는 새 역할의 작은 수행부터

이 상태들이 같은 생활이나 경험을 뜻하지 않음

가상 관심 분야의 입문 과제를 짧게 수행

흥미·부담·필요 지원을 기록한 뒤 다음 학습 선택

경제: 배움 시간·생활 역할·외부 도움은 실제 정보 필요

학습: 짧은 독립 과제 후 다시 할 범위 확인

위험/팩폭: 현재 생활을 모두 바꿔야 배울 수 있다고 생각 / 큰 과정 등록이 반복 가능한 시간과 같지는 않음

조건/반례: 가족·질병·경력 단절·구직 의사 추정 금지

실행: 상태별 프로필의 질문으로 분리 적용

## ckr:material:CH07.P4:skill-repeatability

전문성은 한 번의 성공보다 조건과 한계를 설명하며 다시 수행하는 것

발전할 능력은 문제 해결을 반복 가능한 절차로 남기는 것

기술 문제 해결 원천은 숙련 등급이 아님

가상 이상 사례의 다른 조건에서 같은 판단이 통하는지 검토

자기 권한과 확인할 전문 영역을 함께 밝힘

경제: 재수행·검토·훈련 투입 구분

학습: 새 조건의 사례를 허용 범위에서 비교

위험/팩폭: 익숙한 해결을 모든 예외에 적용 / 오래 한 요령도 새 조건에서는 다시 확인해야 함

조건/반례: 안전 기준과 자격을 대체하는 요령 제작 금지

실행: 결과·조건·한계를 함께 설명
