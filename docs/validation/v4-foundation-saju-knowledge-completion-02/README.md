## 장간·운성·위치

장간 12집합/28저장 천간은 내부 상수와 정확히 같다. 子癸·卯乙·酉辛 같은 고정 집합은 人元司事의 사령일수표와 같지 않다. 丑辰未戌의 雜氣 절은 같은 성분을 말하지만 巳/己 전사 문제와 순서·가중치는 별도 교감 대상이다. 이 확인을 외부에서 28개 가중치까지 인증했다고 표현하지 않는다.
