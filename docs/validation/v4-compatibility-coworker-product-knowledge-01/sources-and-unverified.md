# 출처와 검증의 층위

source-locator-audit.json의113선택 원천은 sourceKind·owner 요구·실제 locator·record/file hash·원래 review/sourceCoverage를 보존한다. knowledge source ID와 실제 계산 Evidence ID는 다르다. 기존2991연구 record·1213primary trait·164Fusion 연구와44/96규칙은 byte/record hash로 재검증했다. 기존 자료의 내용·계보·실증 수준을 새로 승인한 것은 아니다.

외부9문서는 실제로 페이지 본문을 열어 확인했다. author/기관·게시/검토일·접근일·확인 구간·적용 범위는 external-source-access.json에 기록한다. 게시일이 없으면 null이다. 초기 AHRQ 단수 brief URL 접근 실패 후 실제 briefs.html 링크로 확인했다. 실패 URL을 검증 자료로 세지 않았다.

AHRQ의 brief/huddle/debrief/check-back/handoff/task-assistance는 의료 팀 교육 지침이다. 일반 문서·개발·디자인 등의 업무 장면은 편집자의 조건부 전이이며 의료 효과나 법적 책임 규칙을 일반 업무의 사실로 승격하지 않았다. CCL은 관찰·영향·의도 질문의 피드백 모델이다. HSE는 작업 조건을 확인하는 조직 안내이며 한국 법률 판단이 아니다. Myers & Briggs Foundation은 선호와 능력의 사용 경계 참고이며 저장소 Pair 계보·성과 법칙의 독립 검증이 아니다. 외부 원문을 대량 복제하지 않았다.
