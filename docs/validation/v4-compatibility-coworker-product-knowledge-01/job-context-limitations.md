# 실제 직장·직무·권한 미확인

현재 compatibility payload는 personA/personB/productKey/productSlug/relationshipType/compatibilityRoleVersion이다. 각 사람의 생일·출생시간·성별·이름·MBTI와 관계 카테고리는 실제 회사·팀·직업·직급·경력·업무 실적을 증명하지 않는다. 기존 adapter의 jobStatus/detailJob은 빈 context이며 새로운 입력을 강제로 추가하지 않았다.

23직무 프로필·24세부 질문·10직업 상태·192커리어 후보를 실제 원천·hash로 재검증했다. 직무 source의 taskBasis와 외부 인용은 기존 저장 자료이며 이번에 외부 직업 원문 전체를 다시 열람한 것은 아니다. 신규23협업 응용은 작업 단계·정보·산출물·품질·문제·인계·수정·다음 절차를 독립 작성했다. 현재 두 사람이 그 직무라는 주장은 아니다.

사진은 컷 목적·색·규격, 개발은 요구·재현·검토·배포 권한, 디자인은 표현·매체·가독성, 번역은 의미·용어·수치, 재무는 관측·가정·민감도, 돌봄은 실제 자격·전문 지시·상태 전달로 서로 다른 질문을 가진다. 직무명만 바꾼 능력 추천을 하지 않았다.

추가 확인: 실제 두 직무/공동 과제/분야/현재 단계/산출물 목적/정보 접근/가용 시간/자원/자격/담당 범위/결정권/조직 규정. UNKNOWN은 그대로 유지한다. A/B의 가상 단계는 유형별 고정 배정이 아니며 실제 분담·수락 없이는 적용 보류다. 업무 지원은 책임 인수와 다르다. 검토는 인사 평가와 다르다. 단품 결과물 협업은 사업 지분·손실 책임과 다르다.
