# A–AI 입력 및 업무 장면 감사

35시나리오·43실제 생성 변형. 평가 시각은2026-10-12 12:00 KST다. 실제 기존 생성기 실행은 불변 검증용이며 새 연구 DB는 실행에 연결하지 않았다. 상세 payload는 input-cases.json에 있다. Y/Z/AA/AB 업무 과정·마감 변경·인계 누락·피드백 오해는 payload 바깥 hypotheticalContext이며 실제 업무 경험이 아니다.

A–I는 양쪽/한쪽/미상 MBTI·각 시간 미상·같은/다른 유형. J–M은 실제 합·충·관계 미검출·미지원 정의. N/O는 다른/같은 수신 십성. P는 전체 순서 교환, Q는 이름만 교환, R은 deterministic replay. S–V는coworker와managerReport/businessPartner/friendship 비교. W는 raw source→semantic→projection→candidate→reader 근거를 따로 관찰한다. X/AE는 업무·권한 UNKNOWN. Y–AB는 가상 업무 상황. AC/AD는 실제 signed 차이/공통을 관찰하되 능력으로 쓰지 않는다. AF는 domain 승인 부족의 연구 보류, AG는 기존 fallback, AH는 다른6카테고리 격리, AI는 Book 불변이다.

35시나리오를43개의 독립 연구 사실로 세지 않는다. 같은 입력을 여러 맥락에서 실행한 경우 실제 계산은 같아야 한다. A/B 순서 교환은 실제 개인 root와 방향을 맞바꾸며 coworker 역할은A/B로 남는다. 이름 교환은 person ID만 바꾸고 natal/MBTI 개인 digest와 수신 십성은 유지한다. 같은 양방향 십성은 없는 차이를 만들지 않았다.

한쪽 MBTI 미상은 그 개인 MBTI/Fusion·Pair 연구 적용을 보류한다. 일반 업무 질문은 미상인 개인의 확정 성향이 아니다. 출생시간 미상은 실제 남은 기둥만 계산하고 시주·관계 refs를 보충하지 않는다. 새 업무 입력 parser·직업 분류·나이 계산·권한 판별을 만들지 않았다.
