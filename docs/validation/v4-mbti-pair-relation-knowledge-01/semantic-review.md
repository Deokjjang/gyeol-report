# 의미 다양성 독해 기록

136개 공동 원고의 공통점·차이·도움·마찰·의도 후보·오해·질문·합의·반전·반례를 비교했다. 양방향은 공통 사실을 공유하고 각자의 관점을 전환한다. 같은 단어가 없다고 고유 지식으로 인정하지 않으며, 아래 예시는 출발 유형 하나의 trait를 모든 상대에게 반복 나열한 것과 실제 상호작용 조건의 차이를 구분하기 위한 독해 기록이다. 배타적인 유형 법칙은 아니다.

| 출발 유형 | 비교한 두 상대 | 전달 정보의 차이 / 정당한 재사용 |
|---|---|---|
| INTJ | ENFP / ISTJ | ENFP와는 새 제안을 약속으로 받아들이는 문제, ISTJ와는 전례와 새 구조의 검증 기준을 다룬다. 둘 다 변경 범위 합의지만 약속 성립과 증거 비교는 다른 정보다. |
| INTP | ESTJ / INFP | ESTJ와는 기한·방법 재량, INFP와는 논리적 납득과 양보할 수 없는 가치의 구분이다. 단순히 INTP가 분석적이라는 반복으로 끝내지 않는다. |
| ENTJ | ISTJ / ESFP | ISTJ와는 기록을 건너뛴 변경, ESFP와는 휴식까지 목표로 관리하는 조건이다. 책임·약속은 공통 실천이며 상대가 필요로 하는 조건을 따로 둔다. |
| ENTP | INTJ / ISFJ | INTJ와는 닫은 결론을 다시 여는 토론, ISFJ와는 변경 뒤 정리 부담의 전가다. 반론의 동의와 추가 노동의 담당은 다른 합의다. |
| INFJ | INFP / ESTP | INFP와는 진심을 대신 설명하는 해석, ESTP와는 활동 전 동의와 경험 후 해석을 다룬다. 상대 마음을 안다는 주장을 두 경우 모두 금지한다. |
| INFP | ENFP / ISTJ | ENFP와는 개인 이야기의 공개 범위, ISTJ와는 의미와 일정의 필수 조건을 다룬다. 가치 존중이라는 말만 반복하면 빠지는 실제 조율 지점이다. |
| ENFJ | INTP / ESFJ | INTP와는 즉답·감정 확인 요구의 리듬, ESFJ와는 분위기를 지키느라 이견을 미루는 공동 실수를 다룬다. 전자는 대화 시간, 후자는 이견의 표면화다. |
| ENFP | ISTJ / ESFP | ISTJ와는 고정 일정 변경, ESFP와는 새 제안이 쌓여 현재 약속을 놓치는 상황이다. 선택·약속 확인은 공통 조언으로 재사용한다. |
| ISTJ | INTJ / ESTP | INTJ와는 구조의 설명력과 전례 기록, ESTP와는 합의 없는 현장 변경이다. 검증 방식과 현장 재량의 차이를 분리했다. |
| ISFJ | ENTP / ESFJ | ENTP와는 잦은 변경의 정리 부담, ESFJ와는 넓어지는 초대·거절의 예의 문제다. 돌봄이나 행사 준비를 ISFJ의 고정 의무로 만들지 않는다. |
| ESTJ | INTP / ISFP | INTP와는 결과 기준과 방법의 자율성, ISFP와는 침묵을 승인으로 읽는 문제가 다르다. 실질적 권한·거절 가능성은 두 경우 모두 먼저 확인한다. |
| ESFJ | INTJ / ENFP | INTJ와는 안부와 집중 시간의 신호 차이, ENFP와는 초대 증가와 뒷정리 부담이다. 따뜻함만 나열하지 않고 시간 합의와 업무 분배를 구분했다. |
| ISTP | INFJ / ESTP | INFJ와는 경청과 해결 중 원하는 도움, ESTP와는 작업 참여 범위와 교류 시간이다. 간결한 답을 관심 부족이라고 단정하지 않는 제한은 공통이다. |
| ISFP | ENTJ / INFP | ENTJ와는 수정 제안의 허락, INFP와는 완곡한 불편 속 감상과 실제 선택의 확인이다. 선택권 보호는 정당한 공통 실천으로 센다. |
| ESTP | INFJ / ESFP | INFJ와는 활동 속도와 숙고·해석, ESFP와는 경험담을 농담이나 핵심 요구로 끊는 조건이다. 직접 경험 선호 자체와 상대가 원하는 대화 방식을 분리했다. |
| ESFP | ISTJ / ENFP | ISTJ와는 기존 준비를 바꾸는 즉흥 활동, ENFP와는 오늘의 선택과 계속 늘어나는 후보를 구분한다. 고정 약속 확인은 두 조합에 공통으로 유용하며 새 사실 두 개로 세지 않는다. |

## 같은 표현과 비슷한 표현의 판정

- `duplication-audit.json`의 11 동일 표현 그룹은 개인 trait나 공통 실천을 정당하게 재사용한 항목이다. 동일한 문장 전체를 조합에 이름만 바꿔 넣은 dossier는 없다.
- 유사 합의 1쌍은 ENTJ/ENFJ와 ENTP/ESTJ다. 결과 기준을 정한다는 뜻은 같고, 전자는 참여자가 부담을 말할 통로, 후자는 결정 뒤 새 근거 없는 재논의가 마찰 조건이다. 공통 실천은 유지하지만 두 합의 문장을 독립적인 관계 발견으로 집계하지 않는다.
- 7개 공통 실천 검색군은 의미 중복을 없앴다는 증명이 아니다. 합의·확인·경계는 많은 조합에 정당하게 필요하다. 문자열 검사로 포착되지 않은 유사 의미도 이 범주에서 검토한다.
- 동일형 16개는 같은 trait로 개인의 목표·가치·경험·휴식 시간을 구분할 수 없다고 명시한다. 두 질문은 토의를 나누는 방법이며 누가 어느 성향을 가진다는 새 사실이 아니다.
- 두 방향의 공통 장면을 512개의 독립 장면으로 세지 않는다. 고유 장면 272개, 방향 참조 512개다.

## 해석의 제한

양쪽 실제 trait는 로컬 원문에 존재한다. 그 일반화의 외부 사실성은 별도 문제이며, 두 특성이 만난다는 이유만으로 제시한 행동이 실제로 나타났다는 증거도 아니다. 모든 후보는 두 사람이 해당 선호를 실제로 보이는지, 역할·환경이 더 적절한 설명인지 확인해야 한다. 새로운 상호작용 설명을 확보한 상태와 실증 관계 법칙을 확보한 상태를 구분한다.
