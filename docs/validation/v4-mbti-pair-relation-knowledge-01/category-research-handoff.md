# 후속 궁합 7유형 연구 인수 — 이번 작업에서 실행하지 않음

이번 registry는 타입 선호의 조건부 상호작용이다. 궁합의 점수·역할·원고와 연결하지 않았다. 자료가 많다는 이유로 고객 승인을 자동 부여하지 않는다.

| 카테고리 | 이번에 남긴 기초 참고 조건 | 후속 전문 연구에서 별도 확인할 사항 |
|---|---|---|
| 연애 | 표현·만남·개인 거리와 상호 동의 | 실제 관계 상태, 기대·거절·안전한 경계 |
| 결혼 | 공동생활·도움·일정의 합의 | 공동 재정·돌봄·주거·책임, 변화하는 필요 |
| 부모·자녀 | 관찰된 선호·발달 단계 우선 | 자녀 나이·안전·권리·실제 역할; 성인 타입 역추론 금지 |
| 직장 동료 | 실제 업무·기한·협업 재량 | 직무 전문성·정보 전달·기여 평가 |
| 상사·팀원 | 공식 권한과 거절의 불이익 우선 | 평가·책임·권력 비대칭; 갈등을 성격 탓으로 축소 금지 |
| 사업 파트너 | 계약·책임·전문성 우선 | 지분·의사결정권·법적 책임·정산은 MBTI 근거로 판단 금지 |
| 친구 | 참여·공개·연락 선택권 | 실제 친밀도·상호성·생활 제약 |

사용 전 인수할 자료:

- `mpr:A:B`와 `mpr:B:A` 양쪽 원문 pointer/hash 및 sourceCoverage.
- 두 사람 각각 실제 trait 참조와 `jointReviewId`의 공유 내용. 공유 장면·합의는 독립 사실 수로 중복 계산하지 않는다.
- nameReview의 미확인 MBTI 대응, 특히 Benefit/Supervision의 역할 배정 금지.
- 적용 게이트·반례·가상 장면·반려 주장·고객 미승인 상태.
- A/B 실제 역할은 신규로 추정하지 않고 기존 입력 계약을 확인한다.

누락된 역방향이나 미상 유형은 채워 넣지 않는다. 기능 연결을 승인받기 전까지 lookup/barrel/추천·점수/원고 import를 만들지 않는다. 기존 source-local direct를 실증 직접 근거로 읽지 않는다. 새 연구 ID는 기존 trait/Evidence ID를 대체하지 않는다.
