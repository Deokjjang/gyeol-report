# 결리포트 v5 SPEC — 원고·설계 작업 전에 반드시 읽는다 (제1원칙)

## 1. 제품 원칙
- 사주 × MBTI 엔터형 개인화 리포트. 키워드는 "타고난"(타고난 사주, 타고난 성격). 핵심 가치는 재미.
- 차별점: 읽다가 "이 명리 특징 때문에 내 MBTI가 이렇구나", "완전 내 얘기다, 소름"을 느끼게 한다(바넘 효과 포함).
- 장점·좋은 기운은 직설 단정형("당신에게는 ~가 있어서 ~한 운입니다"), 팩폭은 근거와 함께 따뜻하게 끝낸다(신뢰용).
- 쉬운 단어(초·중등도 이해), 직설·직관. 용어는 그림 별명이 아니라 뜻으로 설명한다(P6b·P6c: 그림 별명·농사 비유 금지, 뜻 공식 "식신(食神)은 ~을 뜻해요"는 책당 4회, "명리학에서" 금지). 진부하고 애매한 표현 금지. 장마다 현실 장면 1개 이상, 비유는 장당 1개까지.
- 근거 안에서 해석한다. 그 사람에게는 다를 수 있다는 전제는 두되, 근거 없이 지어내지 않는다.
- 금지: 날짜·시기·사건 확정 예언, 입력에 없는 사실 단정(직업 형태·연인·자녀), 출생시간 미상일 때 시주 사용, MBTI 없을 때 MBTI·Fusion 날조, 내부 용어·id·DB명·출처의 고객 본문 노출, 비하 표현.
- 시점(P6d E): 책은 발행일 기준이다. 1장에 "이 책은 YYYY년 M월 D일 기준으로 썼어요"를 한 줄 넣고, 그 날 이전의 해·달은 돌아보기로 쓴다. "지금 우리가 있는·이번 달·올해 남은" 금지(대운·세운은 "지금"도), 세운 본문은 간지월 이름만.
- 십성 묶음(비겁·식상·재성·관성·인성) 세기는 만세력 오행 칸의 가중값(원국 + 지장간) 하나에서만 계산한다(P6d A, `saju/groupStrength.ts`: 3 이상 강, 1.5 미만 약). 같은 고객의 모든 책이 같은 단계로 쓴다.
- 문체: 존댓말이되 가볍게(~입니다/~예요 혼용). 이름은 제목·1장·마지막 장·전환부에서 친근하게.
- 분량은 정보량의 결과이며 충분히 읽을 만해야 한다. **장 목표 1,000~1,250자(공백 포함) 고정**(P3). 상품 총량: 종합 13장 13,000~16,250자, 커리어·연애·궁합 9장 9,000~11,250자, 대운 4장 + 14년(연도당 450~600자) 10,300~13,400자, 세운 4장 + 12개월(월당 450~650자) 9,400~12,800자. 초과 허용. 장마다 소제목 3~5개, 문단 4~6문장.

## 2. 상품 (Book 계약 유지)
종합 13장 / 커리어·돈·학업 9장 / 연애·결혼·자녀 9장 / 궁합 9장(7유형) / 대운 14년 / 세운 12개월
- 종합: 전체 균형(기질·오행·음양·재능·팩폭·좋은 패·일·돈·사랑·사람·지금의 흐름·활용법)
- 커리어(P6d G, 종합과 다른 심화 상품, 전용 설계기 `brief/design/career.ts`): 일의 엔진 → 지금 자리 진단 → 맞는 일과 길 → 나를 보여 주는 법 → 일터의 사람들 → 평가·승진·문서·자격 → 돈의 길 → 투자와 자산 성향(성향 해석, 종목·상품·시점 금지) → 타이밍과 3년 로드맵. 상태(직장인·자영업·프리랜서·학생·구직/무직·육아/주부·기타)마다 2·3·4·6·7장이 달라지고, 미입력이면 단정하지 않는다.
- 연애(P6d G, `brief/design/love.ts`): 사랑의 엔진 → 내 매력 사용설명서 → 맞는 사람과 끌리는 사람 → 호감·연락·고백 → 연애할 때의 나 → 갈등과 회복 → 결혼관과 함께 살기 → 부모 역할 → 인연의 흐름과 로드맵. 관계 상태(솔로·썸·연애 중·기혼)마다 3·4·7·8·9장이 달라진다. 배우자성(남=재성, 여=관성)·배우자궁(일지), 자녀성(남=관성, 여=식상)·자녀궁(시지, 시간 미상이면 유보).
- 심화 상품: 장마다 반드시 써야 하는 근거 종류(REQUIRED 표)를 브리프·원고에서 검사하고, 같은 고객의 종합이 있으면 근거 항목의 60% 이상은 종합에서 쓰지 않은 것이어야 한다(고객 원장 `meta.ledger`).
- 궁합: 잘 맞는지·부족한 점·보완법. A→B와 B→A 구분. 유형별 현실(결혼=생활·역할·돈, 상사/팀원=권한·속도, 부모/자녀=기대·독립, 친구=거리·빈도, 사업=지분·책임, 직장 동료=협업·경쟁, 연애=감정·표현). 점수는 "타고난 맞물림"이며 본문과 일치.
- 대운: 인생 흐름 설계. 지나온 3년의 마음가짐 변화 → 지금 → 미래 10년의 연결 서사
- 세운: 올해 설계. 절기 월 기준 12개월 연재형, 앞달과의 차이
- 공통: 현재 연도 기운 한 줄(종합·커리어·연애), 아직 쓰지 못한 기운 안내, 음양 분포 해석(성별 결합), 오행 과부족 → 보완 행동(수 부족=물가 산책·독서·사색 등)·보완 상대·만남 장소

## 3. 구조
①엔진(계산·DB·Fusion, 진실) → ②브리프(결정론 취재 노트, V4 문장 없음) → ③작가(LLM, 책 1권 = 호출 1회, 스트리밍) → ④안전망(결정론, 호출 0) → Book 저장·발행.
- 발행 경로의 LLM 호출은 원고 1회(정상 시)에 더해, 필요할 때만 ⓐ 짧거나 빈 장 재요청 1회 ⓑ 결정론 검사(lint)에 걸린 문단·소제목·카드 줄만 모은 수리 1회(P6c A5·I)다. LLM 판정·채점·책 전체 재작성은 없다.
- 계산 정확성은 엔진이, 문장력은 작가가 맡는다. 작가는 브리프에 없는 사실을 만들지 않는다.
- 해석 다양성은 지식 DB에서 나온다. 요소마다 이미지, 영역별 장면, 좋은 면·과사용, MBTI 연결(공명·긴장)을 가진다.
- 작가에게는 DB 문장이 아니라 재료(상황 씨앗·적용 방향·핵심 뜻, `knowledge-v5/materials.json`)와 이 고객의 입력만 간다(P6c A1). 고객 문장에 브리프 글이 20자 이상 이어서 들어가면 검사에 걸린다.

## 4. 100% 제공과 품질 격차 최소화 (방어 4겹)
1) 출력 전 실패(연결·429·5xx, 출력 0)는 비용이 없으므로 시간 예산 내 재시도 허용
2) 중간 끊김은 받은 장을 저장하고 누락 장만 이어쓰기(총 생성량은 책 1권 이내, 정상 시 호출은 1회). 안전망이 짧다·비었다고 본 장은 1회 다시 요청(P6c I)
2-1) 검사(사실 정합·개인화·반복·문형)에 걸린 문단만 1회 수리한다. 안전망은 문장을 지우지 않는다(P6d B: 문장 삭제가 조각 문장을 남겼다). 수리 뒤에도 사실·금지 규칙에 걸리면 그 문단을 통째로 빼고, 문체·반복 규칙은 문단을 그대로 두고 기록한다(사용자 결정 2026-11-04). 빈자리를 DB 원문·안전망 문장으로 채우지 않는다. 문단이 다 빠진 연·월 key·장은 그 묶음을 한 번 더 다시 쓰고, 그래도 비면 발행을 보류한다(AM2-3 6-1, 덕짱님 결정 2026-11-12 — 결정론 문단으로 채워 내보내지 않는다)
3) 결정론 대체본은 어느 상품도 고객에게 내보내지 않는다(AM2-3 6-1, 덕짱님 결정 2026-11-12): 빈 원고 재호출 1회 → 빠진 장·묶음 재시도 1회 → 첫 실패 직후 임시본(OpenAI) → 그래도 실패면 발행 보류 + 처리 봇 경보 + 고객 지연 안내(24시간 안에 못 만들면 자동 환불). 결정론 작가 글은 형식 확인·개발 도구용으로만 남는다.
4) 장 단위 부분 저장 + 회수 크론으로 함수 종료·크래시에서도 Book을 완성한다
- 책 전체 폴백 또는 보충 장 3개 이상이면 재생성 이용권 자동 지급(P7). 목표 폴백률 1% 미만. 장별 source를 기록한다.

## 5. 대운·세운 표시
엔진이 결정론으로 TimelineEntry를 만든다: 키(연도 또는 절기월), 간지(예: 戊辰 무진)와 오행 색, 십성, 합충형해 배지(쉬운 한 줄), 부족 오행을 채우는지, 흐름 세기(설명 가능한 규칙 기반 1~5, "참고" 표기), 키워드 2~3개, 추천 행동 한 줄.
작가는 키별 ### 소제목 아래 본문만 쓴다. 간지 같은 사실은 작가가 쓰지 않고 UI가 카드로 표시한다. 본문이 누락된 키는 결정론 문단으로 채워 내보내지 않는다(§4 3 — 그 묶음 재시도 → 임시본 → 보류).
P6d D: 키 본문의 머리 문장은 결정론 형식("YYYY년 간지(한자)는 천간 십성이 하늘에, 지지 십성이 땅에 들어오는 해예요", 대운 전환 해는 새 대운 이름과 십성)으로 조립 때 넣는다. 대운 연도마다 엔진이 계산한 "대운 안 몇 번째 해"를 주고 위치 말은 그 값으로만 쓴다. 카드의 해 볼 것(발행일 전은 돌아보기 질문형)·살필 점은 작가가 그 해·달의 실제 십성·관계 조합으로 쓰고, 같은 십성 해라도 같은 문장을 쓰지 않는다(겹침 검사, 결정론 대체 줄도 조합에서 고르고 앞 항목과 다른 문장).

## 6. 개발 중 LLM
공급자 교체형 어댑터. 개발 중에는 OpenAI로 스트림·잘림·실패·안전망 배관만 검증한다(한 번 호출→확인→수정, 반복 호출 금지, 총 $8 상한, 호출마다 docs/v5/api-cost-log.md에 비용 기록). 문체 반복은 Claude Code 서브에이전트로 한다. Anthropic 실호출은 P6 최종 단계에서만.
