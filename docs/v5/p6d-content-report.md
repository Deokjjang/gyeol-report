- **B** "하는 물음이 자주 올라와요": 문장 나누기가 `"…?" 하는`의 물음표에서 끊었고, 안전망·enforce가 앞 인용 문장만 지웠다. → 나누기 수정, 안전망은 문장을 지우지 않는다(뜻을 바꾸지 않는 정리·경향형 바꿈만). 안전망 문장 규칙은 lint "safety"로 수리에 보내고, 수리 뒤 사실·금지 규칙이면 문단째 뺀다(빈 연·월 key·빈 장만 결정론). 결정론 장은 규칙에 걸린 DB 문장을 처음부터 고르지 않는다.
