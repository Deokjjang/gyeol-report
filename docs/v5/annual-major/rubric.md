# 세운·대운 판독 잣대(고정 꼴 목록)

## 1. 머리말

- 2026-11-12에 고정했다(AM2-5 3부). 같은 날 AM2-6 7부에서 덕짱님 결정(15-6 답 3 · 5)대로 다섯 줄을 고쳤다. 바꾼 줄과 까닭은 1-1절에 적는다. 고침은 의도한 변경이다. P4 판독 두 건(`P4-annual-1/reading.md` · `P4-major-1/reading.md`)의 차단·경계·경미 표에서 꼴을 모았다. P3 판독은 0이 된 꼴을 찾는 데만 썼다.
- P5부터 세운·대운 판독은 사람이든 서브에이전트든 이 목록으로만 한다. 판마다 수를 맞대려는 것이다.
- **쓰는 법**
  - 판독은 아래 꼴 목록에 있는 것만 차단·경계·경미 수에 넣는다.
  - 목록에 없는 새 꼴은 「참고」 칸에만 적고 판정 수에 넣지 않는다.
  - 목록 정의에 맞으면 센다. 「주의」로 따로 빼지 않는다. 정의가 「세지 않는다」고 한 것만 뺀다.
- **셈(P4와 같다)**
  - 차단·경계는 장소마다 하나로 센다. 같은 표기 꼴이 여러 곳에 있으면 한 줄로 센다.
  - 경미는 꼴 단위로 센다. 곳 수는 따로 적는다.
    - 되풀이 꼴(R-M2·M3·M10·M11·M14·M17)은 두 번째부터 곳으로 센다.
    - R-M4는 한도를 넘은 수, R-M1은 갈래마다 걸린 key 수의 합이다. 나머지는 결함 문장 수다.
  - 한 곳에 꼴이 여럿이면 등급이 높은 꼴 하나로 센다(차단 > 경계 > 경미). 등급이 같으면 id가 작은 꼴이다. 나머지는 꼴 id 칸 괄호에 적는다.
- **넣지 않는 것**
  - 시스템 머리 문장(달·해 key 첫 문장, 시스템이 넣음)은 본문 판정에 넣지 않는다. 반복·틀 셈에서도 뺀다.
  - 화면 카드(결정론)는 본문 판정에 넣지 않는다. 화면 결함은 「화면」 칸에 따로 적는다(4-2 R-S).
  - book.md의 key 소제목(「### 2027-M04」)은 화면에서 이름표로 나오므로 세지 않는다.
- **P4를 이 목록으로 다시 센 값(맞대기 기준)**
  - 세운: 차단 4 · 경계 9 · 경미 18꼴. 대운: 차단 0 · 경계 11 · 경미 18꼴 · 화면 1.
  - 판독 원문은 세운 경미 30꼴 · 대운 17꼴이었다. 처방·근거 되풀이를 내용마다 따로 세던 것을 한 꼴로 묶고, 화면 꼴을 뺐기 때문이다.
  - 판독이 「주의」·「세지 않음」으로 둔 곳은 다시 판단하지 않았다.

## 5. 판정 칸

차단·경계 표는 장소마다 한 줄, 경미 표는 꼴마다 한 줄이다. 모든 줄에 아래 칸을 채운다.

| 칸 | 적는 것 |
|---|---|
| 위치 | 「세운 2.1 ¶1」 「대운 5 · 2032 ¶1」처럼 책 · 장.소제목 순번 ¶문단. key는 이름표로 적는다(「세운 7 · 10월 · 경술월 ¶2」). 경미는 곳 수와 위치 목록 |
| 인용 | 결함 문장 그대로. 60자 안, 줄이면 「…」 |
| 꼴 id | 이 목록의 id 하나(1절 셈). 함께 걸린 꼴은 괄호. 목록에 없으면 「—」 |
| 원인 층 | 카드 / 설계도 / 작가 입력 / 작가 규칙 / 작가 / 결정론 검사 / 화면 가운데 하나 |
| 고객이 알아챌 것 | 예 / 아마 / 아니오 + 한 줄 |
| 참고 | 새 꼴(목록 밖)은 여기에만 적는다. 세지 않은 까닭, 첫 원고(raw first)와 다른지도 적는다 |

- **원인 층**
  - 카드: card.txt 줄 값·문구가 결함을 실어 왔다.
  - 설계도: 근거 배정·각도·장면 씨앗·핵심·처방 배분이 불렀다.
  - 작가 입력: 작가가 받은 자리표시·틀이 그대로 나왔다.
  - 작가 규칙: 규칙 문구로 막을 수 있는 꼴이다. 규칙이 있는데 어겼으면 「작가 규칙(어김)」으로 적는다.
  - 작가: 규칙과 상관없는 작가 단독 실수다. 다시 쓰기가 첫 원고의 맞는 문장을 바꾼 것이 여기 든다.
  - 결정론 검사: 지우기·주석·고치기가 만들었다.
  - 화면: 결정론 화면 문구다(R-S만).
- **고객 기준**: 사주를 모르는 20~30대 독자다. 화면 카드는 보지만 엔진 값은 대조하지 않는다(P4 판독과 같다).
- **권마다 요약 줄**: 「차단 n · 경계 n(예 n · 아마 n) · 경미 n꼴(약 n곳) · 화면 n · 참고 n」.

## 6. 가치 지표

key마다 넷을 적는다. 같은 사람의 같은 key를 P3·P4·P5로 나란히 적는다. 판정 수에는 넣지 않고, ①만 출시 관문 ③에 쓴다.

- **① 「이 사람만의 문장」 유무**
  - key 본문(머리 문장 뺌)에 아래 가운데 하나를 쓴 문장이 하나라도 있으면 「있음」이다.
    - (가) 연결 고리: 그 key 관계가 닿는 원국 자리 뜻(엔진)과 이 사람의 입력(연애 상태·일·적은 바람과 바람 영역·자녀)을 **둘 다** 써서 잇는다. 그 key의 영역 신호, 책 안 다른 key와의 겹침(「정미년에 걸린 오미합이 이 달에 한 번 더」)은 이 둘에 덧붙을 때만 센다(덕짱님 지시 AM2-5 1부 「엔진 값과 입력, 두 근거가 다 있을 때만」).
      - **입력으로 고른 자리 말 셈 조건(2026-11-13 고침 — 까닭: P6 major-p5 판독이 물었다. 입력 말(「기혼」 「프리랜서」) 없이 입력에서 고른 자리 뜻(「일과 섞인 하루」)만 쓴 문장을 셀지에 따라 8/10과 6/10으로 갈렸다)**: 입력 낱말이 문장에 없어도, 아래 셋을 **모두** 채우면 (가)로 센다.
        1. 입력을 바꾸면 그 말이 달라진다(엔진이 입력으로 고른 자리 뜻 — 설계도 고리 재료의 「자리 = …(입력: …)」 칸).
        2. 고객이 자기 처지로 알아본다(그 사람의 일 · 관계 · 생활 장면으로 읽힌다).
        3. 그 key 관계 뜻(맺힘 · 부딪침 · 다듬음 …)과 한 문장에 있다.
        - 든다: 프리랜서 기혼 「일과 섞인 하루에 부딪침이 걸려, 작업 순서가 자주 흔들리기 쉬운 해예요」(입력으로 고른 「일과 섞인 하루」 + 충의 부딪침 · 한 문장).
        - 안 든다: 「가까운 사람과의 사이가 움직이는 달이에요」(입력과 관계없이 누구에게나 같은 자리 기본 뜻) · 「일과 섞인 하루가 바빠지기 쉬워요」(관계 뜻이 없다) · 「태어난 날 자리에 오미합이 걸려요. 일과 섞인 하루예요」(두 문장으로 나뉨).
    - (나) 명리×MBTI 짝: 설계도 짝을 그 key 근거와 잇는다.
    - (다) 입력 반영: 인물 카드의 사실을 그 key 근거와 이어 쓴다.
  - 관계의 일반 뜻이나 카드 뜻만 다시 말한 문장은 세지 않는다. 「당신」을 붙였을 뿐인 것도 같다.
  - 「있음」이면 그 문장과 (가)~(다)를 아래 둘째 표에 적는다.
- **② key 장면 수**: 생활 장면이 조건(「…할 때」 「…라면」)이나 비유(「…처럼」 「…듯」)로 문장 안에 든 수다. 같은 장면은 한 번 센다.
- **③ key MBTI 등장 수**: MBTI 유형 이름이나 MBTI 카드 줄(B 줄) 뜻이 나온 문장 수다.
- **④ key 본문 길이**: 시스템 머리 문장을 뺀 글자 수다. **공백 포함**이다(P4 판독·am2.md 14-1과 같다).

|---|---|---|---|---|
| 세운 1월 · 신축월 | · · | · · | · · | · · |
| 세운 2월 · 임인월 | · · | · · | · · | · · |
| … (세운 13 key · 대운 10 key) | | | | |
| **합** | 있음 n/13 · n/13 · n/13 | 합 · 합 · 합 | 합 · 합 · 합 | 평균·최소 · · |

| key | 판 | 「이 사람만의 문장」 인용 | 쓴 것 |

| 세운 1월 · 신축월 | P5 | 「…」 | (가) 자리 + 입력 / (나) / (다) |
