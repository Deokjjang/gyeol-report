# P6 8권 다시 쓰기 층 순익 — 사람 눈 · 깃발 규칙별

대상: 다시 쓰기 층(문단 교체 + 잠금 되살림·거절 + 되돌림 + 지우기 + 결정론 이름 치환)이 첫 원고 대비 바꾼 것. 사람 판단은 각 권 reading.md §2 · §3 · §8(필요한 곳은 §4 · §5)을 따랐다.

- 책 약칭: A1 annual-1 · A5 annual-p5 · A6a annual-p6a · A6b annual-p6b · M1 major-1 · M5 major-p5 · M6a major-p6a · M6b major-p6b
- 근거 약칭: R2/R3/R4/R5/R8 = reading.md 절 · **F** = 첫 원고 깃발(AM2-7 작업 중 검사 코드로 첫 원고를 다시 셈 — 작업 파일, 저장소 밖) · **L** = review.locks · **D** = review.deleted · **V** = review.reverted · **raw** = meta.raw first ↔ rewrite 블록 대조 · net = net.md
- 판정: **고침** · **만듦**(차/경/미 = 차단/경계/경미·참고) · **잃음**(맞던 내용·분량이 빠짐) · **헛**(교체가 되돌려지거나 잠겨 결함이 그대로)
- 주의
  - 교체 요청에 실린 깃발 목록은 snapshot에 없다. 그래서 「그 문단의 첫 원고 깃발 + raw 대조 + 판독 진술」로 원인 규칙을 정했다. 같은 문단에 깃발이 여럿이면 「공동」으로 적었다. 공동 규칙은 집계에서 양쪽에 다 셌다.
  - F는 지금(fb4d6620 뒤) 코드로 센 값이다. 실행 때(P6 전 코드)와 몇 개는 다르다. 예: M5 2.0.1은 실행 때 fact_ganji, 지금은 dayun_claim. A1 1·2월 key 전체(`*`) 교체는 지금 코드로는 깃발이 안 잡힌다(미상, key_paras로 추정).
  - net.md의 7장 · 5장 「고침/만듦」은 묶음 번호와 책 번호가 달라 부풀었다(판독 A5 · A6a · M1 · M6b가 지적). 이 표는 판독과 raw로 다시 맞췄다.
