## A. 작가와 대체 경로

- 실패 주입(실호출, 커리어 c1): Sonnet 키를 틀리게 → `http_401`(비용 0) → terra 1회 전환 → 11,167자 발행, 82초, $0.0433. 목업 시험 3개(전환·대체도 실패 시 결정론·출력 뒤 끊김은 전환 안 함).

## D. 상품별 설계 (장 id는 `p6b-fields.md` 6)

- 종합: 나를 한 줄로(핵심 이미지) → 성격 → 기질의 뿌리 → 재능 → 두 방향 → 단점 → 좋은 기운과 귀인(이름·뜻 직설) → 일 → 돈 → 연애 → 가족 → 관계 → 실행 전략.

- 연애: 스타일 → 호감·연락 → 표현·밀당 → 만나야 할 사람 2~3유형(부족 오행·배우자 별·배우자 자리·MBTI) → 잘 맞는/어려운 조합 → 다툼 → 함께 산다면 → 부모가 된다면 → 관계 상태별 지향점.
- 궁합: 한 줄 판정(점수 항목마다 이유) → 각자의 바탕 → 잘 맞는 부분 → 두 방향 → 안 맞는 부분 → 현장 → 보완 → 조화 방법. 장면 역할(`compatibility.roles`, E/I·J/P·T/F·N/S 또는 십성), 관계 쉬운 문장(`relationsPlain`).
- 대운: 지난 3년 돌아보기 → 지금 대운 → 10년 영역별 설계 → 연도별 지침(연도마다 문단 3개: 기운 → 영역별 → 할 일·피할 일, 같은 십성 해 비교) → 전환 대비.
- 세운: 올해 설계도 → 영역별 설계 → 월별(지난 달은 돌아보기 질문형) → 눈여겨볼 달 → 올해 지침.

2. 대운 카드 살필 점: 조건을 구조화(`when: 강약·십성 개수·묶음`)하고 원국으로 판정, 해당 문장만. 없으면 null.
3. 만 나이: 카드 = 그해 − 출생 연도, 대운 구간도 만 나이(`draft.timeline.cycles[].ages`), 본문 대운 "만 a~b세".
4. 카드 그림 줄 `imageLine`(독립 필드). 5. `todo`(앞으로)·`review`(지난 기간)·`period`.
6. 내부 라벨: 축 이름 나열·양끝 이름 인용·"배지"·"제시되지 않습니다"·지침 누출 문장 삭제, 작가 입력의 `badges` 키도 `marks`로.
7. 배우자·자녀 자리: 자리마다 용어 나열 대신 쉬운 문장. 8. 지운 문장 뒤 지시어 문장 삭제·연결어 제거.
