# P3.5 A1 지식 DB 보강 브리프 (서브에이전트용)

목적: 같은 명리 요소를 가진 고객들의 책에 **같은 그림·같은 장면**이 반복되지 않게, 자주 나오는 요소(감지 빈도 상위 30%)에 이미지 변형과 장면을 더한다.

## 작업 방식 (패치 모드 — 원본 JSON을 직접 열거나 고치지 않는다)
1. 입력: `tools/p35/enrich/in/<group>.json` 하나만 읽는다. 요소마다 `imagesNeeded`(새 이미지 변형 수), `scenesNeeded`(영역별 더할 장면 수), 기존 `image`·`scenes`·`strengths`가 있다.
2. 출력: `tools/p35/enrich/out/<group>.json` 하나만 쓴다.
   ```json
   { "images": [["요소 id", "metaphor", "visual"]],
     "add": [["요소 id", "영역", "장면 문장", "relationship/children/job"]] }
   ```
3. 검사: `node tools/p35/enrich.mjs check <group>` → `errors: 0`이 될 때까지 고친다. 다른 파일은 고치지 않고, git 커밋도 하지 않는다.
4. 끝나면 요소 수, 이미지 수, 장면 수와 check 결과 한 줄만 보고한다.

## 이미지 변형 (요소마다 imagesNeeded개, 보통 3개)
- **기본 이미지의 핵심 대상은 유지**하고 틀·때·장소·동작을 바꾼다. 예) 천문성 기본 "증상을 듣고 수십 개 약초 서랍 중 하나를 정확히 여는 약방 주인" → 변형 "새벽 약방에서 손님 걸음걸이만 보고 차를 먼저 달여 내놓는 주인", "장날 약초 좌판에서 한 줌 쥐어 냄새로 묵은 것을 골라내는 할머니"(핵심 대상 = 약방·약초).
- `metaphor`: "~하는 ~" 꼴의 그림 한 줄(6~90자). 기본 이미지·다른 변형과 같은 문장 금지.
- `visual`: 오늘날 일상에서 그 기운이 보이는 사람 한 장면(6~90자, 한 문장). 직업·연인·자녀를 전제하지 않는다.
- 세 변형은 서로 다른 장소·계절·시간대를 쓴다.

## 장면 (scenesNeeded의 영역마다 그 수만큼)
- 20~140자, 1~2문장, 문장당 90자 이하. 사람·상황·행동이 눈에 보이게. 초·중등도 아는 쉬운 말.
- 경향형으로 쓴다("~하는 편입니다", "~합니다"). **경험 단정 금지**: "~해 본 사람", "~을 겪어 본", "~했던 사람", "~한 적이 있습니다". 과거 단정도 금지.
- 그 요소의 뜻(oneLiner·strengths)이 장면 안의 행동으로 드러나야 한다. 기존 장면과 상황이 겹치지 않게(같은 장소·같은 소품 반복 금지). 흔한 모티프(노트 빌리러 줄 서기, 단톡방 공지, 회식 자리)는 피한다. 장소를 넓게: 부엌, 버스, 시장, 공원, 헬스장, 병원 대기실, 명절 상, 이삿날, 여행지, 동네 가게, 전화 통화 등.
- 태그 `relationship/children/job` 기본은 `any/any/any`. 이 경우 직업 낱말(회사·팀장·상사·출근·퇴근·손님·가게·월급·수업·선생님 등), 연인·배우자 낱말(연인·애인·데이트·배우자·남편·아내·부부), 자녀 낱말(아이·자녀·아들·딸)을 쓰면 안 된다.
  - love 영역에서 "연인"을 쓰면 `dating/any/any`. "좋아하는 사람", "마음에 둔 사람"은 `any`로 써도 된다.
  - marriage 영역: 기혼 장면은 `married/any/any`(배우자·부부 가능), 언젠가형("함께 살게 되면", "결혼하면")은 `unmarried/any/any`.
  - 직업을 꼭 써야 하면 `any/any/employed`(회사), `any/any/business`(가게), `any/any/student`(학교). 가능하면 직업 없이 쓴다(직업 맞춤은 작가가 따로 한다).
- 금지: 한자, MBTI 코드, 명리 용어(사주·오행·십성·신살·귀인·일간·대운 등), 날짜·사건 확정, 진부한 칭찬("특별한 존재", "무한한 가능성"), 옛 부정 낱말(흉·액운·재앙 등), 비하.

## 품질 기준
- 장면 하나만 읽어도 "아, 이런 사람" 하고 그려져야 한다. 라벨형 문장("책임감이 강합니다")은 장면이 아니다.
- 같은 묶음 안에서도 같은 장소·소품·대사 패턴을 되풀이하지 않는다. 쓰기 전에 out 파일을 다시 훑어 겹침을 지운다.
