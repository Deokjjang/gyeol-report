읽으면서 볼 것:
- 1장 첫 문장 "이 책은 2026년 11월 4일 기준으로 썼어요", 본문에 "지금 우리가 있는·이번 달·올해 남은"이 없는지.
- 다섯 힘(비겁·식상·재성·관성·인성)의 강·보통·약이 만세력 쪽 오행 칸(가중값)과 맞는지. 커리어 권태오: 비겁 강·식상 강·재성 약·관성 약·인성 보통.
- 커리어 9장(일의 엔진 → 지금 자리 진단 → 맞는 일과 길 → 보여 주는 법 → 일터의 사람들 → 평가·문서·자격 → 돈의 길 → 투자 성향 → 3년 로드맵)이 종합과 다른 근거로 채워졌는지, 구직 상태 장면(지원 순서·공백기·자기소개서·처우)이 맞는지. 투자 장에 종목·시점이 없는지.
- 연애 9장(사랑의 엔진 → 매력 → 맞는 사람 → 호감·연락 → 연애할 때 → 갈등 → 결혼관 → 부모 역할 → 인연의 흐름)이 연애 중 상태(관계 점검·대화 리듬·함께 살게 된다면)로 쓰였는지, 자녀 장에 결혼·양가 이야기가 없는지.
- 궁합 "둘 다 ~" 문장이 두 사람 모두에게 맞는지(둘 다 인성 약·물 부족·현침살 = 엔진 값과 같음), 점수 쪽(v2.1)과 본문이 같은 말을 되풀이하지 않는지.
- 조각 문장("하는 ~", 예고만 하는 문장, 개수가 안 맞는 "이 세 가지")·장 번호 참조("7장에서")·괄호 속 자기 정정이 없는지.
- 대운·세운(P6c 저장본): 카드의 해 볼 것/돌아보기·살필 점, 세운 달 "N번째 달 · 간지월". 새 머리 문장·연도별 대운 위치·조합별 살필 점은 다음 생성부터 원고에 들어간다(이번에는 브리프·검사·시험으로만 확인).
- 장소담 ↔ 하람: 같은 일주의 다른 고객이라 특성이 겹친다. 문장이 얼마나 다른지(보고서 표).
