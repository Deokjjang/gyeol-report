### 2-4. Anthropic 잔액·인증 경보 — PASS(로컬)

- 감지(`watchFetch`, 응답 본문·코드): **잔액·결제** = HTTP 402 또는 본문에 `billing_error`·「credit balance is too low」·「spend limit」 / **인증·권한** = 401·403 또는 `authentication_error`·`permission_error`. 529·400(그 밖)은 아님.
  - 근거 [사실, 공식 문서 platform.claude.com/docs/en/api/errors, 11-14 확인]: 401 `authentication_error`, 402 `billing_error`(결제·지불 정보 문제), 403 `permission_error`, 400 `invalid_request_error`는 「조직·워크스페이스 지출 한도에 닿을 때」도, 429는 등급 월 지출 상한(재시도 헤더 없이 계속 실패)도 포함.
  - OpenAI 소진 정규식에 `credit_balance_exhausted`·`*_spend_limit_exceeded`·`organization_usage_limit_exceeded` 추가(research-w2 3-4).
- 경보: 처리 봇 「🚨 Anthropic 잔액/인증 — 모든 생성 실패 중」 + 원인 한 줄 + [다시 열기]. **1시간 1번, 쿨다운은 OpenAI `api_credit`과 따로**(`ops_settings 'anthropic_alarm'`, `ops_sales('alarm')`). 경보가 나면 **판매 자동 멈춤도 같이**(이미 멈췄으면 그대로). OpenAI 경보는 예전 대기표 그대로.
- **잔액 조회 API [사실, 공식 문서 11-14]: 남은 선불 잔액을 돌려주는 API는 없다.** 있는 것은 지난 사용·비용 보고뿐 — `GET /v1/organizations/usage_report/messages`·`/cost_report`(레거시)와 `GET /v1/organizations/analytics/usage`·`/cost`(베타). 모두 **관리자 키(sk-ant-admin…)** 필요, 데이터는 보통 5분 안 반영, 비용 `amount`는 「할인 뒤·크레딧 적용 전」. → 잔액은 콘솔에서만 보이고, 우리는 오류로 알아챈다(지금 설계).
