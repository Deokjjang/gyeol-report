# 원고 채점 기준표 (P6, 반복 새 정의)

P3.8 편집자 채점 프롬프트(10항목)를 이어 쓰되 **7. 반복**의 정의를 바꿨다. 나머지 항목은 같다.
안전망 지표 `infoRepeats`(src/lib/writer/safety/metrics.ts)와 작가 지침 v5-13이 같은 정의를 쓴다.

| # | 항목 | 5점 기준 |
|---|---|---|
| 1 | 직설 | 장점을 단정형으로, 흐린 말 없음 |
| 2 | 이미지 | 처음 나온 기운은 "쉬운 말(용어)"로 이름을 붙인 그림 하나. 같은 대상(불·창고 등)은 대표 그림 하나 |
| 3 | 장면 | 이 고객의 사실(나이·직업·관계)에 맞는 구체 장면. 궁합은 그 관계 유형의 생활 장면만 |
| 4 | 사주×MBTI | 원인-결과로 잇고, 같은 잇는 말을 되풀이하지 않음 |
| 5 | 팩폭 | 근거가 있고 따뜻하게 끝남 |
| 6 | 분량 | 장마다 targetChars 범위(초과는 정보량의 결과면 허용) |
| 7 | **반복** | 아래 정의로 센다. 5 = 0건, 4 = 사소한 것 2건 이하, 3 = 여러 건 |
| 8 | 금지 위반(건수) | 확정 예언·인연 시기·forbiddenFacts 밖 사실·빈 값 채움·MBTI 날조·내부 용어·경험 단정·책 안 모순·조건 단정·궁합 한쪽 평가 |
| 9 | 상품 핵심 가치 | 커리어 3단 직무(줄마다 문장 모양이 다름)·지금 일 적합도·투자 원칙 / 대운 연도 순서 / 궁합 자리·점수 / 종합 장마다 새 각도 |
| 10 | 정확성 | 자리·관계·연도·배지·십성 뜻이 브리프와 같음 |

## 7. 반복 — 무엇을 세나

**같은 정보가 다시 나온 것만 반복이다.** 세 종류:

| 종류 | 예 | 세지 않는 것 |
|---|---|---|
| 같은 주장 | 2장 "지금 대운은 사람과 거래를 들여온다" → 5장 같은 문장 | 같은 성향이 다른 영역에서 **새 근거·새 장면**과 함께 다시 불리는 것("앞에서 본 등불"이 돈 장에서 새 장면으로) |
| 같은 장면 | 7장·9장 모두 "걱정인지 평가인지 가늠하며 신발을 벗는다" | 같은 소품이 다른 장면 안에서 다시 나오는 것(장면 자체가 다르면) |
| 같은 처방 | "한 줄 먼저 말하기"가 세 장의 마무리 | 같은 성향에서 나온 서로 다른 행동 조언 |

- 반복 1건 = 다른 소제목(###)에서 같은 정보가 다시 나온 한 쌍. 목록에는 장.절 두 곳과 50자 이하 인용을 적는다.
- 행동 축(예: "말을 삼킨다")이 여러 장에 나오는 것 자체는 반복이 아니다. 같은 문장·같은 장면·같은 조언일 때만 센다.
- 문장 틀 반복(직무 줄마다 "A는 ~과 ~이 함께 쓰이는 일이에요")은 반복이 아니라 **9. 상품 가치**와 **1. 직설**에서 깎는다.
- 브리프 배정의 축 상한(책 3회)은 참고 경고(plan.warnings)일 뿐 채점 근거가 아니다.
