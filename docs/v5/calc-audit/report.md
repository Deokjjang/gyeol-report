1. **대운수 ↔ 「만 X~Y세」**: 무작위 3,000명(`consistency.json`) 중 같음 2,104, 대운수 = X+1 319, 대운수 = X−1 577(**29.9% 다름**). X(교운 해 − 출생 해)가 교운 순간의 실제 만 나이와 같은 경우 51.5%, 대운수가 같은 경우 60.1%. 예: 「기미 대운: 2013년 12월 무렵부터 (대운수 1) · 만 0~9세」, 「무술 대운: 1944년 1월 무렵부터 (대운수 7) · 만 8~17세(교운 때 실제 만 7세)」. 작가가 `ages`를 본문에 쓰면 부록의 대운수와 다르게 보인다.
2. **대운 표 해마다 「만 N세」(그해 − 출생 해) ↔ 본문 `person.age`(생일 반영)**: 생일 전 날짜에는 1 차이(예: 12월생, 2026-11-05 발행: 카드 「만 22세」, 본문 21세).
3. **V4·V3 저장 책(세는 나이) ↔ v5 새 책(만 나이)**: 같은 고객이 두 권을 보면 1~2 차이.
4. **수리 힌트**: 「대운수는 5(만 나이)」 → 본문이 「만 5세」처럼 고쳐질 수 있다.

### 6-3. 고칠 문구 제안(Q)

- 대운 줄: 「만 X~Y세」를 쓰지 않거나, 교운 순간의 실제 만 나이로 바꾼다(`labels.ts:84,89`). 권장: 대운 줄에는 「교운 연·월 + 대운수」만 쓰고 나이는 빼기(작가 브리프 `ages`도 빼기, `prompt/index.ts:68`).
- 해마다 줄: 「만 26세」 → 「그해 생일이 지나면 만 26세」 또는 「26세(그해 생일 기준)」(`book.ts:385`).
- 수리 힌트: 「대운수는 N(만 나이)」 → 「대운수는 N」(`check.ts:181`).
- **12월 1일 대운·세운 상품 오픈 전**: 두 상품은 `LAUNCH_V5_PRODUCTS`(`writer/flags.ts:12`)에 없어 지금 열면 V4로 만들어지고 V4는 세는 나이(표시 없음)를 쓴다. v5에 넣거나 V4 표기를 만 나이로 맞춰야 한다.
- 대략 시간대 라벨(8a): 입력한 생년월일의 당시 시계로 라벨을 만들거나(예: 1987년 여름생 유시 = 「18:30~20:29」), 서머타임·UTC+8:30 시기 생년월일이면 「정확」 입력을 권하는 안내를 붙인다(`BookInput.tsx:30`, `birthTimePrecisionTypes.ts:23-33`).
- 「올해」 기준(11): `sajuYearAt`이 기준일 정오 대신 발행 시각(`baseAt`)을 쓰게(`chart.ts:60-65`).
