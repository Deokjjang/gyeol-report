## 남은 문제

1. **MBTI 연결 밀도**: c1 trait 10개 중 MBTI 연결 4개. 일주·반안·정관 × ENTJ/Te/Ni Fusion이 없다(데이터). "소름" 포인트가 장마다 고르게 나오려면 유형별 Fusion 확대가 필요하다.
2. **분량 초과 경향**: 시험 장 1,160~1,270자로 상한 1,100을 넘는다(SPEC 초과 허용, 종합 전체 15천 자 안팎 예상).
3. **팩폭 조건 검사 범위**: 신강·신약·십성 묶음 조건만 원국과 맞춘다. 특정 자리 조건("바로 옆에서 누르면")은 미검사.
4. **대운·세운 브리프 15~17k 토큰**: 항목 14·12개가 장 재료라 종합 목표(10k)는 적용하지 않았다. UI 전용 필드(오행 색)는 P3 작가 입력에서 뺄 수 있다(약 1k).
5. **판정 기본값 검토 필요**: 감지 강약 중 DB 규칙에 수치가 없던 것(지지·천간 자리 가중, 십성 균형, 기존 신살 27)은 엔진 작업자가 정한 기본값이다(정책 §5.1).
6. **같은 MBTI 연결 반복**은 한 작가가 여러 장을 쓸 때 다시 나온다 — P6 실호출에서 책 단위로 확인.
