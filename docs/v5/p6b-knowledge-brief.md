# P6b 지식 DB 작업 지침 (서브에이전트용)

목표: 고객 문장에서 그림 별명(easyName·image)을 없애고, 명리 용어를 **뜻**으로 설명한다. 작가(LLM)는 앞으로 trait마다
`이름(한자) + meaning + forYou(조건별 하나) + shadow + life`를 받고 "식신(食神)은 명리학에서 ~를 뜻해요. 그래서 당신에게는 ~" 형식으로 쓴다.
easyName·image·imageVariants·oneLiner는 **내부 별칭**으로만 남는다(지우지 말고 고치지도 말 것).

## 1. 새 필드 (myeongri/*.json 의 features[] 마다)

| 필드 | 모양 | 규칙 |
|---|---|---|
| `meaning` | 문자열 40~280자, 2~3문장 | 명리학에서 그 용어가 **뜻하는 바**. 무엇을 기준으로 정해지는지 한 구절 + 뜻. 십성·오행·신살처럼 개수가 의미 있는 것은 "많을 때/없을 때"를 한 문장으로 구분. 한자 금지(한글만), 비유 금지("처럼·마치·듯·~같은 사람/기운"), 별명 금지 |
| `forYou` | `{ base, strong?, weak?, many?, none? }` 각 10~220자 | 이 사람에게 그 기운이 **주는 힘**(일·관계·돈·생활에서 실제로 무엇을 잘하게 되는지). "당신"을 쓰지 않는 평서문(작가가 2인칭으로 바꾼다). 조건 키는 아래 표의 가족만. 비유 금지 |
| `shadow` | 문자열 10~220자 | **지나치게 쓰일 때**의 모습. 조건을 문장 안에("~가 지나치면", "~이 둘 이상이면"). 근거 있는 팩폭, 비하·옛 부정 낱말 금지 |
| `life` | 문자열 20~140자, 1~2문장 | **현대 생활 장면** 하나. 누구에게나 맞게: 직업·학교·사무실 소품 금지(기획서·회의실·팀장·성적표·교과서·매점 등), 가족 구성원 금지(엄마·아빠·형·누나·동생·시댁 등), 농촌·고전 소품 금지, 명리 용어·MBTI 코드 금지, 지난 경험 단정 금지("~했었다" ✗, "~하는 편이다/~합니다" ○). 쓸 만한 소품: 단톡방, 배달 앱, 지하철, 장보기, 카페, 헬스장, 주말 약속, 택배, 넷플릭스, 메모 앱, 캘린더, 중고 거래 |

조건 키(`forYou`):

| 가족 | 키 | 브리프가 고르는 조건 |
|---|---|---|
| tenGod | base, strong, weak, none | strong=2개 이상이거나 월지 본기, weak=하나뿐이고 눌림, none=원국에 없음(아직 안 쓴 기운) |
| tenGodBalance, element, climate, structure, yinYang, stem, branch | base | 조건이 id에 이미 들어 있다 |
| dayMaster, dayPillar | base, strong, weak | strong=신강(일간이 강함), weak=신약(일간이 약함) |
| shinsal, gwiin, twelveStage, relation | base, strong?, weak?, many? | strengthRules에 strong·weak·duplicate가 있으면 그 뜻대로(many=같은 것이 둘 이상) |

## 2. 기존 글 고치기 (같은 파일 안)

`pnpm exec tsx scripts/knowledge-lint.ts --only <파일>`이 잡는 **"농촌·고전 소품(P6b)"·"그림 별명 노출(P6b)"** 을 모두 고친다.
대상: scenes·strengths·overuse·strengthRules·positionNuance·mbtiLinks.why·variants(nuance·oneLiner)·remedy, Fusion why·scene 등 고객에게 가는 글.
- 별명은 **용어 이름(한글)** 이나 쉬운 풀이로 바꾼다. 예: "꽃길은 눈길이 먼저 오는 기운" → "도화살은 사람들의 눈길을 먼저 끄는 기운", "손 내미는 어른과 맞습니다" → "천을귀인의 도움과 맞습니다".
- 소품은 현대 생활로 바꾼다. 예: "곳간" → "비상금 통장", "우물을 채워 줍니다" → "마음을 채워 줍니다", "처마 밑" → "가게 차양 밑".
- 뜻은 바꾸지 않는다. 문장 길이 ≤ 90자, 한자 금지, 다른 lint 규칙 유지.

## 3. 건드리지 않는 것

id·family·name·easyName·image·imageVariants·oneLiner(내부)·sources·engineKey·engineSupport·dimensionTags·confidence·aliases·score 등 구조 값. 맡은 파일 밖은 수정 금지. git 명령(commit·stash·reset·checkout) 금지.

## 4. 정확성 기준 (반드시 이 기준으로)

- **십성**(일간 기준 생극·음양): 비견=같은 오행·같은 음양, 겁재=같은 오행·다른 음양, 식신=일간이 생하는 오행·같은 음양, 상관=일간이 생하는·다른 음양, 편재=일간이 극하는·같은 음양, 정재=일간이 극하는·다른 음양, 편관=일간을 극하는·같은 음양, 정관=일간을 극하는·다른 음양, 편인=일간을 생하는·같은 음양, 정인=일간을 생하는·다른 음양.
  묶음 뜻: 비겁=나와 같은 힘(자립·동료·경쟁), 식상=표현·생산·기술·밥벌이, 재성=재물·현실 감각·결과 관리, 관성=규칙·책임·직장·명예, 인성=배움·보호·문서·자격.
  식신=온화하고 꾸준히 만들어 내는 쪽, 상관=틀을 깨고 날카롭게 말하는 쪽. 편재=유동·큰돈·사업 감각, 정재=고정·저축·성실한 관리. 편관=압박을 견디는 돌파·결단, 정관=질서·신뢰·정해진 길. 편인=비주류 탐구·직관, 정인=정통 배움·돌봄 받음.
- **천간 오행 물상**(뜻으로 써도 되는 명리 기본 뜻): 갑목=곧게 뻗는 큰 나무, 을목=휘며 자라는 풀·덩굴, 병화=태양, 정화=등불·촛불, 무토=큰 산·둑, 기토=논밭의 부드러운 흙, 경금=무쇠·원석, 신금=다듬은 보석, 임수=큰 강·바다, 계수=비·이슬. (이건 별명이 아니라 명리의 기본 뜻이다. 단, 이것을 비유 문장으로 늘이지 말 것.)
- **오행이 맡는 것**: 목=성장·시작·배려, 화=표현·열정·드러냄, 토=믿음·중재·버팀, 금=결단·원칙·정리, 수=생각·지혜·유연함·저장.
- **십이운성**: 기운의 한살이 단계(장생→목욕→관대→건록→제왕→쇠→병→사→묘→절→태→양). 병·사·묘·절은 "약해지고 멈추고 거두어 저장하고 끊겼다 다시 잇는" 단계로 쓰고, 질병·죽음·무덤 이미지는 금지(lint가 잡는다). 묘=거두어 모아 두는 창고.
- **신살·귀인·관계 판정 기준**: `docs/v5/shinsal-rules.md` 한 줄씩(엔진 기준). meaning에 기준을 쓸 때 이 문서와 다르면 안 된다(예: 도화·역마·화개는 연지 삼합 기준, 홍염·천을·문창·학당은 일간 기준, 괴강은 庚辰·庚戌·壬辰·戊戌 기둥).
- **일주 표**(일지 본기·십성·십이운성): 아래 표가 정답이다. 일주의 meaning은 "○○일주는 ○○(일간)이 ○(일지) 위에 앉은 날로, 일지는 ○○(십성)이라 ~" 식으로 표와 맞게.
- 확정 예언 금지(결혼·이혼·승진·사고·질병 시기·사건). 성별 고정관념 금지. 옛 부정 낱말(흉·액·재앙 등) 금지.
- 확신이 없는 정의는 지어내지 말고 보고에 "불확실: id — 이유"로 적는다(메인이 검수한다).

## 5. 일하는 법

- 파일 하나씩: 기능 몇 개 쓸 때마다 **바로 저장**(네트워크가 끊겨도 남게). 끝나면 `--only`로 0건 확인.
- `--only`의 "중복 문장"은 같은 파일 안 기준이다. 다른 파일과 같은 문장을 쓰지 않게 표현을 매번 새로.
- 끝나면 보고: 파일별 채운 기능 수, 고친 lint 수, 불확실 목록(있으면). 20줄 이내.
