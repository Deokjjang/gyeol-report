# 감지 강약·판단 기본값 — 판정용 표 (P3 A6)

DB 규칙에 수치가 없어 작업자가 정한 값이다. 바꾸려면 `판정` 칸에 적어 주면 그대로 반영한다. 코드 위치를 함께 적었다.

## 1. 감지 강약 (P2에서 정함, `src/lib/brief/featureHits.ts`, 정책 §5.1)

| # | 항목 | 현재 값 | 근거 | 대안 | 판정 |
|---|---|---|---|---|---|
| 1 | 같은 요소 여러 자리 | 한 건으로 합침: 자리 합집합, 강약은 가장 센 것, count = 자리 수 | 한 고객 책에 같은 요소가 두 번 나오지 않게 | 자리마다 따로 hit(장 배정이 늘어 반복 위험) | |
| 2 | 일간·일주 strong/weak | 일간 rule 점수(월령 + 도움 글자 − 극하는 글자 × 1.5)와 structureAnalysis 점수의 부호가 같을 때만 strong/weak, 다르면 medium | 두 계산이 엇갈리면 단정하지 않는다 | structureAnalysis 하나만 따름 | |
| 3 | 천간 위치 가중 | 투출 1자리당 1(년·월·시 같음) | rule에 위치별 수치 없음 | 월간 1.5, 시간 0.8 | |
| 4 | 지지 strong | 월지이거나, 제철(월지와 같은 계절)이거나, 2개 이상이면 strong / 충을 받으면 weak | 월령이 지지 세력의 기준 | 일지도 strong에 포함 | |
| 5 | 신살·귀인(기존 27종) | 월·일 자리 또는 2자리 이상이면 strong. 현침살은 글자 수 1/2/3+ → weak/medium/strong, 월덕이 시간에만 있으면 weak | 월·일이 본인·생활 자리 | 일지만 strong | |
| 6 | 십성 균형 | STRONG(그룹 점수 ≥2.5)은 ≥3이면 strong, WEAK(<1)는 0이면 strong, 나머지 medium | extractSajuTags 임계값(≥2.5 강, <1 약)과 맞춤 | STRONG ≥3.5만 strong | |
| 7 | 음양 | 한쪽이 0이면 strong | 극단만 강조 | 6:2 이상 strong | |
| 8 | 구조 코드 | 해당 그룹 ≥2.5 strong(흐름 3코드는 두 점수 모두), 신약 계열은 VERY_WEAK만 strong, 관살혼잡은 둘 다 ≥1 strong·작은 쪽 <0.5 weak | 그룹 임계값 통일 | 흐름 코드 임계 1.5 → 2.0 | |
| 9 | trait 점수 위치 가중 | 일 1.5 · 월 1.25 · 년·시 1 (`src/lib/brief/traits.ts`) | 일주·월령이 가장 '내 얘기' | 시 1.1(자녀·말년 제품에서) | |
| 10 | 음착양차 | 일주만(기본) | 네 기둥 전부 보면 표본 55%에 떠 정보량 없음(P2 결정 11) | 월·시주 포함(학파) | |
