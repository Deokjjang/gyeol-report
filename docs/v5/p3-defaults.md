# 감지 강약·판단 기본값 — 판정용 표 (P3 A6)

DB 규칙에 수치가 없어 작업자가 정한 값이다. 코드 위치를 함께 적었다.

**판정(P3.5 A8, 2026-10-29)**: 국내 교재·대중 만세력 앱 기본 표시와 대조했다. 근거 없는 임의값은 통용값으로 바꾸고, 학파 차이는 설정값으로 남겼다. 변경 1건(#7). 나머지는 통용과 일치하거나 명리 통용 기준이 적용되지 않는 내부·지시값이다.
